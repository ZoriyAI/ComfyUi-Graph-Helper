# NodeWise Studio

**Создавайте графы ComfyUI, разбирайтесь в них и учитесь на практике**

Начните с задачи, готового шаблона или своего workflow. Настройте ноды вручную либо попросите помощника собрать и изменить граф, затем экспортируйте его для запуска в ComfyUI. Мастера задач, объяснения и уроки помогают понять каждый этап.

В программе есть 115 встроенных blueprint-шаблонов, 95 уроков, 50 пошаговых маршрутов решения проблем, конструктор субграфов и инструменты для своих уроков. Телефон и планшет открывают интерфейс работающего приложения через браузер по Wi-Fi. Помощник подключается отдельно; уроки и ручное редактирование доступны без модели.

NodeWise — независимый экспериментальный проект, не связанный с Comfy Org. Чтение каталога сохраняет файлы ComfyUI; выбранные вами медиафайлы загружаются в его input. Генерацию вы запускаете в ComfyUI. [Возможности и границы](start/What-It-Is.ru.md).

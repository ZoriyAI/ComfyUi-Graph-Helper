# Заметки, reroute и primitive

Вспомогательные ноды, которые не работают с картинкой, но делают граф понятнее и удобнее в управлении.

## Note и Markdown Note
**Note** это поле с текстом на холсте; **Markdown Note** понимает заголовки, списки и ссылки. При запуске графа они ничего не делают. Авторы шаблонов пишут в них, «какие файлы нужны и куда их класть», и указания. Открыли чужой workflow, читайте их первыми.

## Reroute
**Reroute** это маленькая точка, через которую одна связь проходит без изменений. Она держит длинные связи аккуратными, позволяет развести один выход из удобного места и принимает тип того, что к ней подключено. На результат она не влияет.

Некоторые паки дают ноды «Set» и «Get», которые передают значение по имени, без видимой связи; граф становится аккуратнее, но путь данных прячется.

## Primitive
**Primitive** держит одно значение (число, текст или выбор) и подаёт его в поле, ставшее входом. Подключите один Primitive к `seed` трёх сэмплеров, и у них всегда будет общий seed; подключите к `width` нескольких нод, и у них будет общий размер. Если он держит число, у него есть свой `control_after_generate`.

Primitive существует только в редакторе ComfyUI. В формате API, который ComfyUI на самом деле выполняет, его значение вписано прямо в ноды, которые он питает. В новом ComfyUI есть и обычные ноды значений (Int, Float, String, Boolean), которые в формате API остаются.

## Группы
**Группа** (group) это цветная рамка с заголовком вокруг нескольких нод. Она двигает свои ноды вместе, и в ComfyUI её можно целиком обойти или выключить. На выполнение графа она не влияет.

## Частые ошибки
- Удалить Reroute и оставить две половины связи неподключёнными.
- Менять поле ноды, которую питает Primitive: побеждает значение Primitive.
- Пропустить заметки шаблона и потом не найти файл модели.

## Как помогает приложение
Приложение рисует заметки, reroute, primitive и группы из импортированных файлов и объясняет их во вкладке **Объяснение**, как любые другие ноды.

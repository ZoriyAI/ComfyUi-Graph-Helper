# Workflow и форматы его файлов

Файл workflow, формат API и картинки с workflow внутри.

## Простыми словами
**Workflow** это граф, сохранённый в файл. В нём ноды, их поля, связи, места на холсте, группы и заметки. Передайте workflow, и другой человек получит весь ваш граф, но не ваши файлы моделей: их у него должно быть своих.

## Какие бывают форматы
- **Workflow (формат редактора), `.json`.** То, что ComfyUI сохраняет командами «Save» и «Export». Он описывает холст: ноды с местами и размерами, связи отдельной таблицей, группы, заметки, определения субграфов. Этим форматом делятся, его приложение открывает и сохраняет.
- **Формат API, `.json`.** То, что редактор на самом деле отправляет серверу по нажатию Run: только выполняемые ноды, у каждой класс и входы, по номерам нод. Нет мест на холсте, нет заметок, нет нод Primitive (их значения вписаны прямо в ноды, которые они питают). ComfyUI сохраняет его командой «Export (API)». Им пользуются скрипты и сервисы.
- **Картинка или ролик, в которых лежит workflow.** Save Image записывает workflow и задание API в метаданные PNG. Перетащите такой PNG в ComfyUI, и откроется граф, который его сделал. Некоторые другие форматы, которые сохраняет ComfyUI (анимированный WebP, видео), тоже могут его нести. Многие сайты стирают метаданные, поэтому картинка из интернета часто ничего не несёт.
- **Файл проекта приложения.** Graph Helper хранит ещё и свой файл проекта рядом с обычным workflow: в нём объяснения и заметки, сделанные в приложении. ComfyUI он не нужен.

Как отличить формат редактора от формата API: в первом наверху есть `"nodes": [...]` и `"links": [...]`, второй это список пронумерованных записей с `"class_type"` и `"inputs"`.

## Частые ошибки
- **Открыли файл API, а раскладки нет**: в формате API нет мест на холсте, программе приходится расставлять ноды самой.
- **«Missing models» в чужом workflow**: файл называет модели по именам файлов. Нужны файлы с теми же именами в нужных папках, или выберите свои файлы в загрузчиках.
- **Нет нод**: workflow использует паки, которых у вас нет.
- **Ждать workflow от JPEG**: Save Image в ComfyUI пишет PNG, а при переводе в JPEG метаданные теряются.

## Как помогает приложение
- **Файл ▸ Открыть workflow…** читает файлы редактора. После импорта приложение говорит, что нашло и чего не хватает в вашем ComfyUI.
- **Файл ▸ Сохранить workflow для ComfyUI…** пишет обычный workflow, который ComfyUI открывает, без того, что понимает только приложение.
- **Проверка** идёт перед сохранением и перечисляет недостающие ноды и файлы моделей.

# OpenAI

OpenAI это облачный поставщик языковых моделей. Помощник отправляет ваш вопрос и граф в OpenAI по защищённому соединению и получает ответ. Нужен ключ от OpenAI, и OpenAI берёт плату за использование; цена зависит от модели и от длины вопросов и ответов. Цен приложение не показывает: смотрите свой кабинет на сайте OpenAI.

## Как настроить

1. Создайте ключ в своём кабинете на сайте OpenAI (platform.openai.com). Скопируйте его.
2. В приложении: «Настройки ▸ Помощник» ▸ **OpenAI**.
3. Вставьте ключ в поле **Ключ OpenAI**. Приложение сразу его проверит: «Проверяю ключ…», потом «Ключ принят: доступно 24 модели. Действует, пока приложение открыто.»
4. Чтобы ключ сохранился после перезапуска, отметьте **Запомнить на этом компьютере** (системное хранилище паролей). См. [Ключи и где они хранятся](Keys.ru.md).
5. **Модель**: выберите из списка, который открыл ключ, или одну из подсказок: `gpt-5`, `gpt-5-mini`, `gpt-4.1`. Выбирайте модель, которая умеет вызывать инструменты.
6. **Проверить связь**: «Модель ответила за 900 мс.»
7. **Сохранить настройки**.

Карточка **OpenAI** после этого показывает **Готово** (или **Ключ на этот сеанс**, если ключ не запомнен).

## Адрес сервера

Оставьте **Адрес сервера (необязательно)** пустым: приложение пойдёт на официальный адрес OpenAI. Заполняйте его только для своего прокси и только с `https`. Ключ работает только с тем адресом, для которого его вставили: «Этот ключ вставлен для … и на другой адрес не отправляется. Для адреса выше вставьте его собственный ключ.»

## Поиск в интернете

Свой поиск в интернете, на официальном адресе. Его можно выключить: «Настройки ▸ Помощник» ▸ **Разрешить поиск в интернете**. См. [Поиск и страницы в интернете](Web-Search.ru.md).

## Что может пойти не так

- «Выбран OpenAI, но ключа нет. Помощник не ответит, пока вы не добавите ключ в настройках.»
- «Провайдер не принял этот ключ. Проверьте его и вставьте снова.»
- «Сервер не принял ключ. Проверьте ключ в настройках помощника.»
- «Сервер просит подождать. Повторите вопрос через минуту.» Учётная запись упёрлась в предел или на ней кончились деньги.
- «Не выбрана модель у облачного помощника. Выберите её в «Настройки ▸ Помощник».»
- «Облачный ключ не отправляется на адрес http. Укажите адрес, который начинается с https.»

# Память диалога и контекст модели

В окне контекста одновременно помещаются инструкции, граф, описания инструментов, разговор и ответ. Токены — части текста. Если места мало, сервер может отбросить начало запроса. Приложение показывает фактически сообщённое окно и предупреждает об обрезке или недостаточном запасе.

## Настройка через приложение

1. Откройте **Настройки → Помощник**, выберите сервер и установленную модель.
2. Оставьте **Объём памяти диалога → Автоматически**, если не нужен определённый режим. Автоматика учитывает недавний запрос, место для инструментов и ответа, заявленный предел модели. Другие варианты — разговор/небольшие графы, сложные графы и долгие сеансы.
3. **Стиль ответа → Оставить настройки модели** сохраняет её параметры, шаблон и стоп-слова. «Сдержанный» уменьшает вариативность; «Идеи» увеличивает. У каждого режима объяснены действие и ограничения.
4. Для локальной Ollama нажмите **Применить режим диалога к Ollama**. Приложение создаст конфигурацию на существующих весах, загрузит её, проверит реальное окно и явно выбранные параметры генерации. Веса не скачиваются, служба системы не редактируется. Кнопка **Сохранить настройки** выбирает проверенную конфигурацию для помощника.
5. В предупреждении чата кнопка **Настроить автоматически** выполняет ту же проверку и сразу сохраняет результат. После успеха повторите вопрос.

Большему контексту нужно больше памяти. Автоподбор не гарантирует достаточную свободную RAM/VRAM: он проверяет предел модели и результат загрузки. Если загрузка не удалась, выберите меньший режим/модель или освободите память через монитор моделей. Ошибка или неподтверждённое применение не переключает помощника на новую конфигурацию.

## Мониторинг и остановка

Блок **Модели на этом сервере** обновляется, пока открыт раздел помощника. Он показывает реально загруженные модели, выделенную им память, видеопамять и сообщённый контекст. Это показатели выбранного сервера, который может находиться на другом компьютере. Неизвестные значения так и обозначаются.

**Остановить ответ помощника** отменяет текущий ответ приложения. **Выгрузить и освободить память** освобождает модель без удаления файлов; новый запрос может загрузить её снова. **Загрузить выбранную модель** загружает её пустым запросом. Успех проверяется по списку сервера; во время ответа загрузка/выгрузка недоступны. Выгрузка может повлиять на другие приложения, использующие тот же сервер.

## Другие провайдеры и маленькие окна

Приложение читает сведения об окне, которые предоставляют Ollama, LM Studio, llama.cpp и vLLM. Настройка и загрузка/выгрузка в этой версии требуют native API Ollama. Обычный OpenAI-совместимый адрес чата не меняет контекст загруженной сервером модели. Интерфейс сообщает о недоступном управлении, не объявляя успех. У облачной модели Ollama окно задаётся провайдером.

Для других провайдеров выбранный объём ограничивает отправляемый приложением разговор. Меньшее фактическое окно сервера имеет приоритет. При маленьком или неизвестном окне помощник использует сокращённый набор инструментов, сохраняя оценку ресурсов и инструменты запрошенного шаблона/субграфа. Режим «Спросить» по-прежнему не редактирует граф напрямую. Короткий вопрос, новый разговор или модель с большим контекстом уменьшают нагрузку на окно.

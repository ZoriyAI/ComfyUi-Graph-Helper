# Ollama

Ollama запускает языковые модели на вашем компьютере. Приложение говорит с ней через её адрес, совместимый с OpenAI. Ничего не уходит с компьютера, ключ не нужен. Саму Ollama ставят с её сайта; эта страница начинается с того места, где она уже установлена.

## Как настроить

1. Запустите Ollama и скачайте модель, которая умеет вызывать инструменты, в терминале, например: `ollama pull qwen2.5:14b` (или `llama3.1`, `mistral`). Модели побольше строят лучше.
2. Увеличьте окно контекста хотя бы до 16 384 токенов (см. ниже). У самой Ollama по умолчанию оно маленькое.
3. В приложении: «Настройки ▸ Помощник» ▸ **Свой сервер**.
4. Приложение само ищет локальные серверы (**Найти локальные серверы** ищет снова). Ollama находится по адресу `http://127.0.0.1:11434/v1` и появляется в списке поля **Адрес сервера** с пометкой «найден на этом компьютере». Выберите её или впишите адрес.
5. **Модель**: выберите из списка («Выбрать из 3 моделей на сервере»). Список отмечает **инструменты**, **зрение**, **рассуждение**.
6. **Проверить связь**: «Модель ответила за 900 мс.» и окно контекста: «Окно контекста на сервере (в токенах): 16384. Запросы помощника помещаются.»
7. **Сохранить настройки**.

## Окно контекста

Ollama загружает модель с постоянным окном и молча отбрасывает то, что не поместилось. Приложение читает настоящее окно у Ollama, пока модель загружена, и предупреждает, если оно слишком маленькое. Чтобы увеличить его в Linux, когда Ollama работает как служба:

```
sudo systemctl edit ollama.service
```

Добавьте в редакторе эти две строки, сохраните и закройте:

```
[Service]
Environment="OLLAMA_CONTEXT_LENGTH=16384"
```

Потом перезапустите её:

```
sudo systemctl daemon-reload && sudo systemctl restart ollama
```

Если вы запускаете Ollama вручную: `OLLAMA_CONTEXT_LENGTH=16384 ollama serve`. Большему окну нужно больше памяти; если модель стала медленной или не загружается, выберите размер поменьше или модель поменьше. Те же команды с кнопкой **Скопировать** приложение показывает, когда ответ обрезан. Подробнее: [Окно контекста](Context-Window.ru.md).

## Ollama на другом компьютере

Впишите его адрес, например `http://192.168.1.50:11434/v1`. Ollama должна слушать сеть (`OLLAMA_HOST=0.0.0.0`). Ваши сообщения и граф тогда идут по сети, а по `http` без шифрования.

## Что может пойти не так

- «Ни один локальный сервер не ответил. Запустите Ollama, LM Studio или vLLM либо впишите адрес сами.»
- «Сервер модели не отвечает. Проверьте, что он запущен, и адрес в настройках помощника.»
- «Выберите модель на своём сервере: её можно взять из списка под полем в разделе «Помощник».»
- «Модель прочитала только часть запроса»: окно слишком маленькое.

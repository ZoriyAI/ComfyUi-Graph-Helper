# Сервисы, совместимые с OpenAI

**Совместимый с OpenAI** это любой облачный сервис с интерфейсом чата OpenAI: шлюз перед несколькими моделями или региональный провайдер, например там, где OpenAI, Anthropic и Google недоступны. Нужны собственный адрес сервиса и его собственный ключ, а счёт выставляет сервис. Сервер на ваших собственных компьютерах настраивается как **Свой сервер**: см. [vLLM и другие совместимые серверы](vLLM.ru.md).

## Как настроить

1. «Настройки ▸ Помощник» ▸ **Совместимый с OpenAI** («Другой облачный сервис по своему адресу. Нужен его ключ.»).
2. **Адрес сервиса**: его адрес, совместимый с OpenAI, целиком, с https, обычно оканчивается на `/v1`. Сервис называет его в своей документации.
3. Вставьте собственный ключ сервиса. Поле ключа ждёт адреса: «Сначала впишите адрес сервиса выше: ключ принадлежит этому адресу.» Ключ уходит только на этот адрес.
4. **Модель**: выберите её из списка сервиса или впишите название. Выбирайте модель, которая умеет вызывать инструменты.
5. **Проверить связь**, потом **Сохранить настройки**.

**Запомнить на этом компьютере** хранит ключ в системном хранилище паролей, как у других облачных провайдеров. См. [Ключи и где они хранятся](Keys.ru.md).

## Правила

- Адрес должен начинаться с https: «Адрес сервиса нужен целиком, с https, например https://api.example.com/v1.» Облачный ключ никогда не отправляется на адрес http.
- Ключ принадлежит своему адресу. Для другого адреса вставьте его собственный ключ.
- Цен такого сервиса приложение не показывает. Смотрите страницу самого сервиса.
- Если вашей сети нужен прокси, задайте его в «Настройки ▸ Помощник» ▸ **Сеть** ▸ **Прокси (необязательно)**.

## Что может пойти не так

- «Сервису, совместимому с OpenAI, нужен его адрес https. Впишите его в «Настройки ▸ Помощник».»
- «Сервер не принял ключ. Проверьте ключ в настройках помощника.»
- «На сервере нет такой модели, или её сняли. Выберите другую модель в настройках помощника.»
- «Сервер ответил, но не как модель. Проверьте адрес в настройках помощника.»

См. [Неудачные ответы](Failed-Answers.ru.md).

# Materials for a lesson

Open **Materials for a lesson** on the welcome screen or from **Help**. Prepare text resources for a classroom lesson. Editing and printing do not require ComfyUI or an AI model. Your configured assistant can draft content for your topic.

## Choose a small result

| Type | Result |
| --- | --- |
| Topic cards | Short texts for reading, discussion or matching |
| Worksheet | Instructions, a supported task and independent practice |
| Quick understanding check | Questions, with separate teacher answers |
| Explain a topic | An idea, an example and a short practice task |
| Story sequence | Events and captions; images are created separately for now |
| Different levels of support | Supported, independent and further-challenge tasks |

Select **Continue**, then enter a topic, class or age group, and objective. For example: “Year 2, seasons, explain differences between seasons”. You can add your source text. You do not need pupils’ names or personal information.

## Fill and review

**Open editable scaffold** creates empty blocks with hints. Write your content, add blocks or remove unused ones. Each block has separate **Answers and teacher notes** fields.

**Prepare with assistant** sends your topic, goal, current material and source text to the selected model. The request and progress appear in the assistant panel. A cloud model sends these data to the chosen provider; review the [assistant settings](../assistant/Assistant.md). Use **Review classroom material** on the result. Your current draft stays until you select **Open this material**. Save your current editable copy first if you need both versions.

If no assistant is configured, **Set up an assistant** opens its settings. Your wizard fields stay. You can try the manual scaffold first.

Review wording, facts, answers and suitability for your class. Empty blocks remain a scaffold. A model response does not establish curriculum alignment or pedagogical approval. The preview shows pupil text without answers and teacher notes.

## Save and print

- **Download pupil sheet** saves HTML with the tasks. Answer and teacher-note fields are absent from this file.
- **Download teacher copy** saves HTML with tasks, answers and notes.
- **Save editable copy** saves JSON for further work in NodeWise. It includes answers and notes; share it with colleagues who should receive them.

Open HTML in an ordinary browser and select **Print**. The browser’s print dialog can save PDF. NodeWise does not rename HTML to PDF. Review the pages before handing them out, especially long tasks and cards. A recipient can read the HTML or PDF without NodeWise or ComfyUI.

## Return later or share with a colleague

Your current draft is saved automatically on this device. A phone browser and the desktop app hold separate copies. To move a material, use **Save editable copy**, then **Open material file** on the other device. A colleague’s edits do not replace your copy.

The wizard stores one current draft. Before **Start another material**, save the file if you will need it again. Clearing browser data removes local drafts. If automatic saving is unavailable, the wizard explains this and asks you to save a file.

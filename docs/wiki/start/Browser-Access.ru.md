# Доступ из браузера по Wi-Fi

Оставьте приложение запущенным на компьютере. Телефон, планшет или другой компьютер смогут работать с тем же проектом через браузер. Отдельное приложение для телефона не требуется.

1. На компьютере откройте **Настройки → Доступ по сети**.
2. Включите **Разрешить доступ из браузера**. Выберите адрес компьютера в локальной сети и порт от 1024 до 65535. Адрес `127.0.0.1` работает только на самом компьютере.
3. Сохраните настройки и снова откройте этот раздел. Статус **Доступно** и адрес означают, что сервер запущен. Если порт занят, здесь появится ошибка: выберите другой и сохраните.
4. Подключите телефон к той же доступной сети Wi-Fi. Откройте показанный адрес или отсканируйте QR-код.
5. На компьютере нажмите **Подключить устройство**, затем введите на телефоне шестизначный код. Он действует пять минут для одного подключения.

Граф и сохранённая переписка принадлежат текущему проекту компьютера. Изменения видны на обоих устройствах. Устаревшая правка получит конфликт и не перезапишет более новую. Раскладка панелей телефона хранится в его браузере. На узком экране переключайте **Холст**, **Библиотеку**, **Помощника** и **Свойства**. Уроки находятся в режиме **Учиться** у помощника. Касания позволяют перемещать и масштабировать граф.

При открытии файла браузер выбирает его на телефоне. Сохранение проекта и экспорт workflow скачивают файл на телефон. Загрузка через браузер ограничена 11 МиБ; более крупные файлы открывайте на компьютере. Системные папки компьютера, сохранённые ключи и настройки сетевого доступа управляются на компьютере. Ключи провайдеров остаются в процессе приложения.

Используйте доверенную сеть Wi-Fi: HTTP не шифрует трафик. Подключение даёт управление этим проектом, включая работу настроенного помощника. Сессия истекает через восемь часов и забывается при выключении доступа или выходе из приложения. Кнопка **Отключить** сразу отзывает доступ устройства. Перезагрузка и переподключение читают актуальный проект, не повторяя прежние команды.

Если телефон не подключается, проверьте, что приложение запущено, устройства видят друг друга, выбранному интерфейсу всё ещё назначен этот адрес, а firewall компьютера разрешает порт. Гостевая Wi-Fi сеть может изолировать устройства. Приложение не меняет роутер или firewall. После смены сетевого адреса выберите новый и сохраните. Эта функция не настраивает доступ из интернета.

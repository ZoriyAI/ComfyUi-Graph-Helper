# Обновление

Новая версия ставится поверх старой. Ваши настройки, сохранённые ключи, проекты и история графа сохраняются.

## Как узнать о новой версии

Приложение не проверяет новые версии, пока вы его об этом не попросите. «Настройки ▸ Приватность ▸ Проверять новые
версии» (по умолчанию выключено) раз в день спрашивает страницу выпусков проекта и показывает спокойное уведомление,
когда есть новая версия; оно ничего не скачивает. Или посмотрите сами: «Справка ▸ Новые версии» открывает страницу
выпусков. «Справка ▸ Что нового» показывает заметки к вашей версии.

## Поставьте новую версию

1. Скачайте новый `nodewise-studio_<версия>_amd64.deb` (и `SHA256SUMS`, чтобы его проверить, см.
   [Установка](Installing.ru.md)).
2. Закройте приложение («Файл ▸ Выход»).
3. Установите так же, как в первый раз:

   ```bash
   sudo apt install ./nodewise-studio_*_amd64.deb
   ```

4. Запустите приложение снова.

На Windows и macOS запустите скрипт установки ещё раз: он соберёт новый выпуск и заменит приложение на месте.
[Установка на Windows](Installing-On-Windows.ru.md), [Установка на macOS](Installing-On-macOS.ru.md)

## Что происходит с данными

- Всё остаётся в [папке с данными](../reference/Data-Folder.ru.md). Пакет (и скрипт установки) её не трогает.
- Если новой версии нужно новое устройство базы, она сначала пишет копию старой базы рядом с ней,
  `comfyui-desktop.db.before-v<N>.bak` (хранится одна копия), и только потом обновляет базу.
- Сохранённые ключи остаются в хранилище паролей системы под тем же именем.
- Файлы проектов и workflow остаются там, куда вы их сохранили.

## С версии 0.9 на 1.0

До версии 0.9 у приложения было другое название. С 1.0 оно называется NodeWise Studio, а его пакет, программа и
папка с данными называются `nodewise-studio`. Что это значит при обновлении:

- **Пакет.** Новый `.deb` (и `.rpm`) заменяет пакет версии 0.9: при установке старый удаляется, и в меню приложение
  одно. Копию, которую `install.sh` поставил в вашу домашнюю папку, удаляет новый `install.sh`.
- **Ваши данные.** При первом запуске NodeWise переносит папку с данными версии 0.9 в `~/.config/nodewise-studio`:
  настройки, проекты, разговоры, история графа и журналы переезжают вместе с ней. Папка переносится, а не копируется
  и не удаляется. Если `~/.config/nodewise-studio` уже есть, обе папки остаются как есть. Если версия 0.9 ещё открыта,
  окно «Версия 0.9 ещё открыта» просит её закрыть и запустить NodeWise снова. Затем окно «Ваша работа в NodeWise
  Studio» один раз говорит, где теперь ваша работа. Если старую папку прочитать нельзя, окно «Старые настройки не
  прочитать» говорит об этом, и NodeWise начинает с новыми настройками, а ваша работа из 0.9 остаётся нетронутой.
- **Ключи, сохранённые в системном хранилище паролей, нужно ввести заново.** Хранилище паролей (GNOME Keyring,
  KWallet) держит секрет, которым они зашифрованы, под названием приложения, и под новым названием NodeWise не может
  их открыть. Введите их снова в настройках; старая запись остаётся в хранилище, удалить её можно в менеджере паролей
  (например, «Пароли и ключи»). Ключи, которые хранились в файле на этом компьютере (`model-key.json`,
  `mcp-token.json`), переезжают и работают.
- **Файлы проектов.** Файлы, сохранённые версией 0.9, открываются как раньше. «Сохранить проект» записывает их обратно
  под тем же именем; новые проекты сохраняются как `*.nodewise.json`.
- **Уведомление 0.9 о новой версии.** Версия 0.9 ищет файлы выпуска по своему старому имени пакета, поэтому её
  уведомление, скорее всего, предложит страницу выпуска, но не прямое скачивание. Пока не проверено. Скачайте файл 1.0
  со страницы выпуска сами.

## Как вернуться к старой версии

Старая версия не открывает базу, которую обновила новая: она пишет «Ваши данные сохранены более новой версией
приложения» и ничего не меняет. Чтобы вернуться:

1. Закройте приложение и поставьте старый `.deb`.
2. В папке с данными уберите `comfyui-desktop.db`, `comfyui-desktop.db-wal` и `comfyui-desktop.db-shm`.
3. Переименуйте копию `comfyui-desktop.db.before-v<N>.bak` в `comfyui-desktop.db`.
4. Запустите старую версию.

Чтобы вернуться с 1.0 на 0.9, нужно ещё старое имя папки: сначала удалите новый пакет
(`sudo apt remove nodewise-studio`), поставьте `.deb` версии 0.9 и переименуйте `~/.config/nodewise-studio` так, как
начинается имя файла пакета 0.9 (часть до первого `_`). Затем сделайте шаги 2–4 в этой папке.

Изменения, сделанные в новой версии, при этом пропадут; сохранённые файлы проектов останутся.

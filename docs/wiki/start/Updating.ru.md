# Обновление

Новая версия ставится поверх старой. Ваши настройки, сохранённые ключи, проекты и история графа сохраняются.

## Как узнать о новой версии

Приложение само не проверяет новые версии (по своей воле оно в интернет не ходит). Смотрите страницу выпусков проекта:
её открывает «Справка ▸ Новые версии». «Справка ▸ Что нового» показывает заметки к вашей версии.

## Поставьте новую версию

1. Скачайте новый `cozygraph_<версия>_amd64.deb` (и `SHA256SUMS`, чтобы его проверить, см.
   [Установка](Installing.ru.md)). <!-- verify: technical rename -->
2. Закройте приложение («Файл ▸ Выход»).
3. Установите так же, как в первый раз:

   ```bash
   sudo apt install ./cozygraph_*_amd64.deb
   ```
   <!-- verify: technical rename -->

4. Запустите приложение снова.

## Что происходит с данными

- Всё остаётся в [папке с данными](../reference/Data-Folder.ru.md). Пакет её не трогает.
- Если новой версии нужно новое устройство базы, она сначала пишет копию старой базы рядом с ней,
  `comfyui-desktop.db.before-v<N>.bak` (хранится одна копия), и только потом обновляет базу.
  <!-- verify: technical rename -->
- Сохранённые ключи остаются в хранилище паролей системы под тем же именем.
- Файлы проектов и workflow остаются там, куда вы их сохранили.

## Как вернуться к старой версии

Старая версия не открывает базу, которую обновила новая: она пишет «Ваши данные сохранены более новой версией
приложения» и ничего не меняет. Чтобы вернуться:

1. Закройте приложение и поставьте старый `.deb`.
2. В папке с данными уберите `comfyui-desktop.db`, `comfyui-desktop.db-wal` и `comfyui-desktop.db-shm`.
3. Переименуйте копию `comfyui-desktop.db.before-v<N>.bak` в `comfyui-desktop.db`.
4. Запустите старую версию.

Изменения, сделанные в новой версии, при этом пропадут; сохранённые файлы проектов останутся.

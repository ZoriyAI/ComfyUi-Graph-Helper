# Материалы к уроку

Откройте **Материалы к уроку** на первом экране или через меню **Справка**. Здесь можно подготовить текстовый материал для школьного занятия. Для заполнения и печати ComfyUI и модель не нужны. Настроенный помощник может предложить черновик по вашей теме.

## Выберите небольшой результат

| Вид | Что получится |
| --- | --- |
| Карточки по теме | Короткие тексты для чтения, обсуждения или сопоставления |
| Рабочий лист | Инструкция, совместная проба и самостоятельное задание |
| Проверка понимания | Вопросы и отдельные ответы для учителя |
| Объяснить тему | Главная мысль, пример и короткая практика |
| История по кадрам | План событий и подписи; изображения пока создаются отдельно |
| Разные уровни поддержки | Задания с опорой, для самостоятельной работы и дополнительная задача |

Нажмите **Продолжить**, укажите тему, класс или возраст и цель. Например: «2 класс, времена года, объяснить различия между сезонами». При желании добавьте свой исходный текст. Имена и другие сведения об учениках для этого не нужны.

## Заполните и проверьте

**Открыть заготовку для правки** создаёт пустые блоки с подсказками. Напишите свой текст, добавьте нужные блоки или удалите лишние. У каждого блока есть отдельные поля **Ответы и заметки учителя**.

**Подготовить с помощником** отправляет тему, цель, текущий материал и исходный текст выбранной модели. Запрос и ход работы появятся в панели помощника. Для модели в облаке эти данные передаются выбранному провайдеру; условия видны в [настройках помощника](../assistant/Assistant.md). Результат откройте кнопкой **Открыть материал для правки**. До нажатия **Открыть этот материал** текущий черновик сохраняется. Если нужны обе версии, сначала скачайте текущую редактируемую копию.

Если помощник не настроен, кнопка **Настроить помощника** откроет его настройки. Введённые поля останутся в мастере. Сначала можно попробовать заготовку вручную.

Проверьте формулировки, факты, решения и пригодность для класса. Пустые блоки остаются заготовкой. Ответ модели не означает соответствие вашей учебной программе или проверку педагогом. Предпросмотр показывает ученический текст без ответов и заметок.

## Сохраните и распечатайте

- **Скачать лист ученика** — HTML с заданиями. Поля ответов и заметок учителя в этот файл не включаются.
- **Скачать копию учителя** — HTML с заданиями, ответами и заметками.
- **Сохранить редактируемую копию** — JSON для дальнейшей работы в NodeWise. Он содержит также ответы и заметки; передавайте его коллегам, которым они нужны.

Откройте HTML обычным браузером и выберите **Печать**. В диалоге браузера можно сохранить PDF. NodeWise не переименовывает HTML в PDF. Перед раздачей просмотрите страницы: особенно длинные задания и карточки. Получатель обычного HTML или PDF может прочитать материал без NodeWise и ComfyUI.

## Вернитесь позже или передайте коллеге

Текущий черновик автоматически сохраняется на этом устройстве. В браузере телефона и в настольном приложении это отдельные копии. Для переноса нажмите **Сохранить редактируемую копию**, затем **Открыть файл материала** на другом устройстве. Изменения у коллеги не заменяют вашу копию.

В мастере хранится один текущий черновик. Перед **Начать другой материал** сохраните файл, если он ещё понадобится. Очистка данных браузера удаляет его локальные черновики. Если автосохранение недоступно, мастер сообщает об этом и предлагает сохранить файл.

Это редактор школьных материалов. Для создания обучающего курса по сборке графов используйте [свои уроки NodeWise](../lessons/README.ru.md).

# Установка

Приложение рассчитано на Linux x64. Скачивайте формат, действительно приложенный к выбранному выпуску. Наличие сборщика в исходниках не означает, что формат уже опубликован или проверен на вашем рабочем столе. Сборок ARM нет.

| Формат в исходниках | Установка или запуск |
|---|---|
| `.deb` | В Debian-подобной системе: `sudo apt install ./comfyui-graph-builder_*.deb` |
| `.rpm` | Установите скачанный файл менеджером пакетов системы, например `sudo dnf install ./comfyui-graph-builder-*.rpm` |
| AppImage | Разрешите исполнение скачанного файла и откройте его; запуск проверяет поддержку sandbox |
| `.tar.gz` | Распакуйте; `./run.sh` запускает на месте, `./install.sh` устанавливает для текущего пользователя, `./uninstall.sh` удаляет эту установку |

Для сборки из исходников нужны Node 22 и существующий Electron Forge. Для `.deb` нужны `dpkg` и `fakeroot`; для `.rpm` дополнительно `rpmbuild`. AppImage требует `mksquashfs` и runtime AppImage type 2. Команды сборки и проверки пакетов: [Разработка](../../DEVELOPMENT.md).

При обновлении профиль остаётся в `~/.config/comfyui-graph-builder`. Проекты и workflow остаются там, куда вы их сохранили. Удаление пакета не удаляет профиль. Для сохранения зашифрованных ключей нужно работающее системное хранилище паролей. Проверки ОС, keyring, масштаба экрана и настоящего рабочего стола выполняются отдельно от тестов исходников.

Запустите ComfyUI отдельно, затем [подключитесь по его браузерному адресу](../connect/Connecting.ru.md). MCP необязателен. Уроки работают без модели-помощника.

# Установка

Для Linux на 64-битных x86 NodeWise Studio выходит пакетами в четырёх форматах: `.deb`, `.rpm`, AppImage и `.tar.gz`,
который ставится только для вашего пользователя. Скачивайте только файлы, которые действительно приложены к
выбранному выпуску. Пакетов для Linux на ARM нет.

Для **Windows** и **macOS** пакета нет: скрипт из выпуска одной командой собирает приложение на вашем компьютере из
исходного кода проекта и устанавливает его для вас.
[Установка на Windows](Installing-On-Windows.ru.md), [Установка на macOS](Installing-On-macOS.ru.md)

| Система | Как |
|---|---|
| Linux (x64) | Пакет со страницы выпуска, как описано ниже. |
| Windows 10 22H2 или 11 (x64) | `install-windows.ps1` из выпуска собирает и устанавливает приложение. |
| macOS 13 или новее (Apple silicon или Intel) | `install-macos.sh` из выпуска собирает и устанавливает приложение. |

Пакеты для Linux для каждого выпуска собираются, устанавливаются и запускаются на сервере сборки. Скрипты установки
для Windows и macOS появились в 1.0.0 и на настоящих компьютерах **ещё не проверены** (проверка на машинах GitHub с
Windows и macOS есть и ещё доводится до успешного прохода). Если попробуете, сообщите, пожалуйста, что получилось, в
обращениях (Issues) проекта, приложив файл журнала, который скрипт назовёт в конце, и версию системы.

## Что нужно

- Linux, 64 бита, x86. Для `.deb`: Ubuntu 22.04 и новее, Debian 12 и новее, Linux Mint 21 и новее и другие на их
  основе; для `.rpm`: Fedora, openSUSE и другие с пакетами rpm; AppImage и `.tar.gz` работают в большинстве
  дистрибутивов.
- Около 320 МБ на диске для приложения.
- Рабочий стол (X11 или Wayland).
- По желанию: хранилище паролей (GNOME Keyring, KWallet), чтобы приложение помнило ключи между запусками.

## Установка .deb

1. Откройте страницу выпусков проекта и скачайте файл `nodewise-studio_<версия>_amd64.deb` последней версии.
2. По желанию, но разумно: скачайте `SHA256SUMS` из того же выпуска в ту же папку и проверьте файл:

   ```bash
   sha256sum -c SHA256SUMS --ignore-missing
   ```

   Должно быть написано `OK`.
3. Установите через apt, он заодно поставит то, что нужно приложению из вашего дистрибутива:

   ```bash
   sudo apt install ./nodewise-studio_*_amd64.deb
   ```

   `./` важно: так apt ставит именно этот файл, а не ищет пакет по имени.

## Другие форматы

| Формат | Как |
|---|---|
| `.rpm` | `sudo dnf install ./nodewise-studio-*.rpm` (или менеджером пакетов вашего дистрибутива). |
| AppImage | Сделайте файл исполняемым (`chmod +x`) и откройте его. |
| `.tar.gz` | Распакуйте. `./run.sh` запускает приложение на месте; `./install.sh` ставит его только для вашего пользователя, без root; `~/.local/share/nodewise-studio/uninstall.sh` удаляет (`--purge` удаляет и папку с данными). |


`.deb` и `.rpm` сохраняют песочницу Chromium. Распакованные форматы (AppImage, `.tar.gz`) в Ubuntu 24.04 и новее
запускаются без неё и при запуске говорят почему. Установка `.rpm` через dnf и готовый файл AppImage проверены только
автоматическими сборками проекта, на настоящем рабочем столе ещё нет.

## Запуск

- Из меню приложений: «NodeWise Studio».
- Из терминала: `nodewise-studio`.

`nodewise-studio --version` печатает версию, `nodewise-studio --help` перечисляет параметры
([Командная строка](../reference/Command-Line.ru.md)).

Не запускайте его через `sudo`: от имени root приложение не работает. См.
[Решение проблем](../reference/Troubleshooting.ru.md).

## Что и куда кладёт пакет

| Где | Что |
|---|---|
| `/usr/lib/nodewise-studio/` | Сама программа. |
| `/usr/bin/nodewise-studio` | Ссылка для запуска из терминала. |
| `/usr/share/applications/` | Пункт в меню. |
| `/usr/share/icons/hicolor/` | Значок размером от 16 до 512 точек. |
| `/usr/share/doc/nodewise-studio/copyright` | Лицензия и список сторонних компонентов. |

Ваши настройки, ключи, проекты и журналы в пакет не входят: приложение хранит их в домашней папке, см.
[Папка с данными](../reference/Data-Folder.ru.md).

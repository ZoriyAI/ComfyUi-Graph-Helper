# Что это за приложение

NodeWise Studio — мастерская для создания графов ComfyUI и обучения работе с ними. Вы выбираете результат, собираете граф вручную, через мастер или вместе с помощником, затем сохраняете обычный workflow для ComfyUI.

## Для кого

- Для новичка: понятные объяснения, готовые стартовые задачи и уроки с проверкой шагов.
- Для автора графов: импорт настроек и связей, свои субграфы, варианты обработки, проверка зависимостей и экспорт.
- Для преподавателя: свои уроки, материалы для учеников и разделение проверки структуры от оценки полученного изображения.

Знание программирования для обычной работы не требуется. Для генерации нужен запущенный [ComfyUI](ComfyUI.ru.md) с необходимыми моделями; для помощника — выбранная локальная или облачная модель.

## Как начать

1. [Установите приложение](Installing.ru.md) и [подключите ComfyUI](../connect/Connecting.ru.md).
2. Выберите [мастер задачи](../graph/Task-Wizards.ru.md), первый [урок](../lessons/README.ru.md) либо откройте свой workflow.
3. Настройте ноды, связи и модели. [Помощник](../assistant/Assistant.ru.md) может объяснить или выполнить просьбу; результат можно отменить через историю.
4. [Проверьте граф](../graph/Checking-A-Graph.ru.md), сохраните workflow и [запустите его в ComfyUI](../graph/Running-In-ComfyUI.ru.md).

Для работы с телефона включите [доступ через браузер по Wi-Fi](Browser-Access.ru.md) на компьютере. Отдельное мобильное приложение не нужно; компьютер с NodeWise остаётся включённым.

## Что входит

- 115 официальных blueprint-шаблонов из зафиксированной версии каталога: изображения, видео, звук, 3D, текст и сочетания этапов.
- Конструктор субграфов с входами, выходами, внешними настройками и редактируемыми внутренними нодами.
- 95 уроков в 16 группах и 50 маршрутов разбора типовых затруднений.
- Каталог моделей, метаданные и описания LoRA, повторное чтение и объяснения проблем синхронизации. Русский перевод описаний использует настроенного помощника.
- Подсказки в меню ноды, сенсорное управление, загрузка выбранного файла, отмена и история правок.
- Проверка зависимостей и оценка ресурсов, экспорт workflow и освобождение памяти моделей помощника перед запуском ComfyUI.

## Как приложение обращается к данным

Каталог ComfyUI читается без изменения моделей, расширений и очереди. Выбор медиафайла явно загружает его в папку input; существующие файлы не перезаписываются. NodeWise не устанавливает сгенерированные расширения и не запускает workflow: вы просматриваете код и запускаете результат в ComfyUI. [Подробности доступа](../trust/Read-Only.ru.md).

Уроки, ручной холст и мастера доступны без модели ИИ. Помощник обращается к выбранному вами серверу; облачный провайдер может брать плату. [Приватность](../trust/Privacy.ru.md) описывает отправляемые данные.

## Что подтверждает проверка

Проверка графа находит структурные проблемы и отсутствующие зависимости. Она не подтверждает качество изображения, совместимость каждого стороннего расширения или точное пиковое потребление GPU. Это проверяется реальным запуском. [Известные ограничения](../reference/Known-Limits.ru.md).

Приложение доступно в пакетах Linux x64; для Windows и macOS есть скрипты сборки и установки из исходников конкретного выпуска. [Установка](Installing.ru.md). NodeWise — независимый экспериментальный проект; [автор и принципы](../trust/Author.ru.md).

# Открыть workflow

Workflow это файл `.json`, который сохраняет ComfyUI: граф без объяснений. Откройте его здесь, чтобы разобраться, изменить или поучиться на нём. Приложение покажет его на холсте и сразу скажет, чего не хватает вашему ComfyUI, чтобы его запустить. Форматы файлов: [Форматы workflow](../concepts/Workflow-Formats.ru.md).

## Как открыть

1. **Файл ▸ Открыть workflow…** (`Ctrl+I`), **Импорт** на панели или **Открыть workflow из ComfyUI** на карточке «Добро пожаловать».
2. Выберите файл `.json` в окне **Открыть workflow**.
3. Граф заменит холст. Сообщение скажет, чего не хватает, например:
   «Workflow открыт. Не хватает нод: WanVideoSampler, WanVideoDecode. Не хватает моделей: loras/detail.safetensors.»
   или «Workflow открыт. Все ноды на месте. Все модели на месте.»
4. Разберитесь в нём: нажмите **Экскурсия** или выделите ноду и посмотрите её карточку.

Открытие это один шаг истории: `Ctrl+Z` вернёт прежний граф.

## Что значит сообщение

- **Не хватает нод**: классов нод, которых нет в вашем ComfyUI. Они остаются в графе с отметкой; проверка называет их «Не установленные ноды». Поставьте пак в ComfyUI сами и синхронизируйте.
- **Не хватает моделей**: файлов моделей, которые названы в workflow, но которых нет в ваших папках.
- «Для ComfyUI сохранится как было, но здесь показано иначе: групповые ноды показаны одной неизвестной нодой: 2.» Кое-что приложение не умеет рисовать так, как ComfyUI, но сохраняет и записывает обратно без изменений.

## Сохранить снова

Когда вы сохраните его через **Файл ▸ Сохранить workflow для ComfyUI…**, он вернётся в ComfyUI точно таким, каким был, кроме того, что вы изменили: расположение, цвета, группы, связи и значения, которых вы не трогали, остаются прежними.

## Что может пойти не так

- «Это файл для API, а не workflow холста: откройте файл, сохранённый из ComfyUI кнопкой Save.» Файл сохранён экспортом для API; откройте обычный workflow.
- «Этот файл не похож на workflow ComfyUI (ожидается формат 1 или старый 0.4). Откройте workflow, сохранённый из ComfyUI.»
- «Файл workflow не удалось прочитать.» Файл повреждён или это не JSON.
- «Этот файл слишком большой, чтобы его открыть.»
- Файл проекта этого приложения открывается через **Файл ▸ Открыть проект**, а не здесь.

# Copy and paste

Today the app has no copy, cut, paste or duplicate of nodes. `Ctrl+C` and `Ctrl+V` work only in text fields.

## What to do instead

- **The same part used several times**: select it, make a subgraph (`Ctrl+G`), then insert more copies from the **Subgraphs** tab of the library or right-click ▸ **Insert subgraph**. All copies share one inside. See [Subgraphs](Subgraphs.md).
- **One more node of the same kind**: add it again from the library or the search (`Ctrl+K`) and set its fields.
- **A part of another graph**: note that a new project or an opened workflow replaces the canvas. The earlier graph stays in the [history](History-And-Undo.md).
- **A prompt or a value**: select the text in a field, `Ctrl+C`, and paste it into the other field with `Ctrl+V`.

# Поля нод

Поля это настройки ноды: сколько шагов, какой сэмплер, какой файл модели, какой промпт. Их задают прямо на ноде или в [Свойствах](../interface/Properties.ru.md); и там и там одно и то же значение. Варианты берутся из вашего ComfyUI, поэтому список показывает то, что предлагает ваш ComfyUI. Что значит поле: правый щелчок по ноде ▸ **Объяснить порты** или вопросительный знак рядом с полем в «Свойствах».

## Виды полей

| Вид | Как задать |
|---|---|
| Целое число (steps, width, seed) | впишите или нажимайте **Уменьшить** / **Увеличить**. «Свойства» показывают диапазон: «От 1 до 10000». |
| Дробное число (cfg, denoise) | так же; значение держится шага поля. |
| Seed с кнопкой **Случайное** | **Случайное значение для seed** выбирает новое число. См. [Seed](../concepts/Seed.ru.md). |
| Переключатель | **вкл** / **выкл**. |
| Список (sampler_name, scheduler) | откройте и выберите; **Найти в списке** сужает длинный список, «Ничего не нашлось», если ничего не подходит. |
| Файл модели (ckpt_name, lora_name) | список ваших файлов с отметкой, насколько каждый подходит. См. [Выбор файла модели](Model-Files.ru.md). |
| Текст (промпт) | пишите в поле. См. [Промпт](../concepts/Prompt.ru.md). |

## Отметки у поля

- «не задано»: у поля нет значения. Если нет и значения по умолчанию, проверка и сохранение предупредят: «У поля … ноды «…» нет значения и значения по умолчанию; задайте его до сохранения для ComfyUI.»
- «нет в списке»: «Этого значения нет среди вариантов, которые ComfyUI предлагает для этого поля.» Часто бывает в workflow, сделанном на другом компьютере.
- «← связь»: значение приходит по связи от другой ноды.
- «Это поле настраивается в самом ComfyUI.»: такое поле приложение показать не может; его значение хранит ComfyUI.

## Как сохраняется каждое изменение

Каждое изменение поля это один шаг истории: `Ctrl+Z` возвращает его, а кнопка отмены называет его («Отменить: значение KSampler.steps»).

## Что может пойти не так

- У ноды, чей класс ещё не прочитан, полей нет: «У этой ноды есть сохранённые значения, но приложение пока не знает её полей…» Синхронизируйте, и поля появятся.
- «Приложение не знает точный порядок полей этой ноды, поэтому эти значения не попадут в сохранённый workflow.» Так бывает с нодой, которую ваш ComfyUI описывает не полностью; задайте значения в ComfyUI.

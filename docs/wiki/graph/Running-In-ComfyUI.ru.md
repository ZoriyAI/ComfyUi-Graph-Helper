# Запуск в ComfyUI

Это приложение никогда не запускает граф: оно собирает и объясняет. Чтобы получить картинку или видео, откройте сохранённый workflow в ComfyUI и запустите его там. Эта страница и есть мост.

## Перед тем как идти

1. **Проверить граф** (`Ctrl+Shift+C`), пока не будет «Проблем не найдено.» или пока вы не поймёте, почему находка не страшна. См. [Проверка графа](Checking-A-Graph.ru.md).
2. **Файл ▸ Сохранить workflow для ComfyUI…** и запомните, куда сохранили файл `.json`. См. [Сохранить workflow для ComfyUI](Saving-Workflows.ru.md).
3. По желанию: **Файл ▸ Сохранить проект**, чтобы сохранить объяснения.

## Карточка «Запустите в ComfyUI»

После каждого **Файл ▸ Сохранить workflow для ComfyUI…** открывается карточка **Запустите в ComfyUI**. Она говорит: «Workflow сохранён. Это приложение графы не запускает: это делает ComfyUI. Три шага:»

1. **Открыть ComfyUI** открывает в браузере адрес ComfyUI из «Настройки ▸ Подключение» или адрес, который сообщил ваш MCP-сервер. Если приложение не знает адреса, шаг говорит об этом, а кнопка называется **Настройки подключения**.
2. Перетащите сохранённый файл в окно ComfyUI или откройте его там через **Workflow ▸ Open**. **Показать файл** показывает его в файловом менеджере. **Скопировать workflow** копирует workflow в том виде, в каком он записан; затем нажмите `Ctrl+V` на холсте ComfyUI.
3. Нажмите **Run** (`Ctrl+Enter`) в ComfyUI. Результат появится под нодой сохранения и в папке output ComfyUI.

Внизу **Разобрать ошибку ComfyUI…** открывает карточку ошибки (см. [Ошибка в ComfyUI](ComfyUI-Errors.ru.md)).

- Чтобы карточка не открывалась после каждого сохранения, снимите отметку **Показывать после каждого сохранения**. В сообщении о сохранении останется **Как запустить**.
- **Справка ▸ Запустите в ComfyUI** открывает ту же карточку в любой момент.
- Браузер приложение открывает только по нажатию кнопки.

## В ComfyUI по шагам

1. Откройте ComfyUI в браузере по адресу, которым всегда пользуетесь (например, `http://127.0.0.1:8188`).
2. Перетащите файл `.json` из файлового менеджера на страницу ComfyUI. Или откройте файл workflow через меню самого ComfyUI.
3. Граф появится в ComfyUI таким же, как здесь: те же ноды, связи и значения.
4. Нажмите кнопку запуска ComfyUI (**Run**, в старых версиях **Queue Prompt**).
5. Пока ComfyUI работает, ноды подсвечиваются одна за другой. Результат появится в ноде Save Image (или Save Video).
6. Файл запишется в папку `output` ComfyUI, его имя начнётся с `filename_prefix` этой ноды.

Первый запуск дольше: ComfyUI загружает модели в память.

## Если не получилось

ComfyUI покажет красное сообщение и обведёт ноду, на которой случилась ошибка. Скопируйте сообщение и принесите его сюда через **Справка ▸ Разобрать ошибку ComfyUI…**. См. [Ошибка в ComfyUI](ComfyUI-Errors.ru.md).

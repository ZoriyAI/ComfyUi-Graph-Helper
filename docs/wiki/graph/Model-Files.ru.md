# Выбор файла модели

У ноды-загрузчика (Load Checkpoint, Load LoRA, Load VAE и других) есть поле с именем файла, например `ckpt_name` или `lora_name`. Список этого поля показывает файлы из нужной папки ComfyUI, и у каждого отметку, подходит ли он к остальному графу. «Подходит» здесь значит: сделан для того же семейства моделей. LoRA для SDXL не работает с чекпойнтом Flux. См. [Семейства моделей](../concepts/Model-Families.ru.md).

## Как выбрать

1. Щёлкните поле загрузчика. Откроется список; пока он читает ваши файлы, он пишет «Смотрю ваши файлы…».
2. Вверху он называет, с чем сравнивает: «Сравниваю с juggernautXL.safetensors (SDXL)», это чекпойнт выше по вашему графу.
3. У каждого файла отметка:

| Отметка | Значение |
|---|---|
| **подходит** | сделан для того же семейства |
| **загрузится, но сделана под SDXL** | родственное семейство: ComfyUI загрузит, но результат может быть плохим |
| **семейство отличается: Flux.1 ≠ SDXL** | другое семейство: работать как задумано не будет |
| **семейство неизвестно** | ни файл, ни его имя не говорят о семействе |

4. Выберите. **Найти в списке** сужает длинный список.

Если сравнивать не с чем: «Подключите чекпойнт выше по графу, и список покажет, какие файлы ему подходят.» (у LoRA) или «Подключите LoRA ниже по графу, и список покажет, какие чекпойнты ей подходят.» (у чекпойнта).

## Другие способы

- На вкладке **Модели** библиотеки откройте карточку файла и нажмите **Добавить на холст** (новый загрузчик с этим файлом) или **Подставить в выбранную ноду** (выделенный загрузчик возьмёт файл). См. [Карточка модели](../interface/Model-Card.ru.md).
- Карточка LoRA перечисляет «Ваши базовые модели, к которым она подходит:»; карточка чекпойнта говорит, сколько ваших LoRA к нему подходят, и даёт **Показать их в списке**.

## Откуда известно семейство

Из заголовка файла, из описания, которое лежит рядом с ним (его пишут, например, помощники для Civitai), из интернета, если вы попросили (**Найти в интернете**), или догадкой по имени файла. Пока синхронизация не прочитала заголовок, это догадка.

## Что может пойти не так

- «В этом списке нет файлов.» В этой папке вашего ComfyUI нет файлов. Приложение ничего не скачивает; положите файл в папку ComfyUI и синхронизируйте.
- «Модели разных семейств» в проверке: две модели в одной цепочке разных семейств. См. [Проверка графа](Checking-A-Graph.ru.md).

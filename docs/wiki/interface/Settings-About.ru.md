# Настройки: О программе

Раздел **О программе** в настройках показывает то же, что **Справка ▸ О программе**: версию, что это за приложение, лицензию, сторонние компоненты, кнопку, чтобы скопировать сведения для сообщения об ошибке, и кнопку, чтобы открыть папку с данными. Подробно это окно описано в [О программе и справка](About-And-Help.ru.md).

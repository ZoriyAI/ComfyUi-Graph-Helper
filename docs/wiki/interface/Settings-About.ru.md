# Настройки: О программе

Раздел **О программе** в настройках показывает то же, что **Справка ▸ О программе**: название со строкой «Учебный помощник по графам ComfyUI», версию, автора, что это за приложение, лицензию, сторонние компоненты, кнопку, чтобы скопировать сведения для сообщения об ошибке, кнопку, чтобы открыть папку с данными, и ссылки проекта. Подробно это окно описано в [О программе и справка](About-And-Help.ru.md).

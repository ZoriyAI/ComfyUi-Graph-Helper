# Значок синхронизации

Значок синхронизации стоит у правого края главного меню: цветная точка и несколько слов о том, прочитало ли приложение ваш ComfyUI. Щелчок открывает всплывающее окно с числами, автоматической синхронизацией и кнопкой **Синхронизировать сейчас**.

<!-- picture: значок «Синхронизировано» с открытым всплывающим окном -->

## Состояния

| Значок пишет | Это значит |
|---|---|
| «ComfyUI ещё не прочитан» | пока ничего не прочитано |
| «Запуск…», «Идёт синхронизация…» | синхронизация идёт |
| «Чтение моделей: 120 / 331» | список нод прочитан, заголовки файлов моделей ещё читаются |
| «Синхронизировано» | последняя синхронизация прошла |
| «Прочитано не всё» | последняя синхронизация прочитала только часть; окно называет, чего не хватает |
| «Синхронизация не удалась» | последняя синхронизация не прошла; окно говорит почему |
| «Нужен токен» | серверу нужен вход |
| «Библиотека с прежнего адреса» | адрес сменили, а библиотека ещё со старого сервера: «Нажмите «Синхронизировать сейчас», чтобы прочитать новый.» |

## Всплывающее окно

- Состояние, а во время синхронизации её этап: «Чтение нод, паков и моделей: 3 из 5».
- **Ноды**, **Классы с известными портами**, **Паки нод**, **Модели**, **Прочитано файлов моделей** («330 / 330»).
- **Последний запуск**, **Длительность**, **Следующий запуск** («Выключено» без автоматической синхронизации) и «Последняя синхронизация: …».
- Предупреждения и последняя ошибка словами, например «ComfyUI не запущен на 127.0.0.1:8188, поэтому входы и выходы нод не обновлены. Запустите ComfyUI и синхронизируйте снова.»
- **Синхронизировать автоматически** и **Интервал, минуты** (не меньше 5). Применяются сразу. «Не чаще раза в 5 минут. Используются только инструменты чтения; в ComfyUI ничего не меняется.»
- **Войти**, если сервер требует входа через браузер, **Приостановить чтение метаданных**, пока читаются файлы моделей, и **Синхронизировать сейчас**.

Когда синхронизация заканчивается, сообщение справа внизу говорит, что прочитано: «Прочитано нод: 75, паков: 5, файлов моделей: 331.» С предупреждениями: «Синхронизировано с предупреждениями».

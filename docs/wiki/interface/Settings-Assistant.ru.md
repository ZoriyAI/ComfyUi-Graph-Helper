# Настройки: Помощник

«С какой моделью говорит помощник и как он ведёт себя в ответе.» Верхняя половина выбирает, кто отвечает; нижняя, **Поведение**, задаёт, как помощник работает. По шагам для каждого вида модели: [Кто отвечает](../assistant/Choosing-Who-Answers.ru.md).

<!-- picture: раздел «Помощник» с выбранным «Свой сервер» и открытым списком моделей -->

## Кто отвечает

Шесть карточек (пять в установленном приложении): **Не выбран** («Помощник выключен.»), **OpenAI**, **Anthropic**, **Google Gemini** («Облако. Нужен ключ.»), **Свой сервер** («Ollama, LM Studio, vLLM на этом или другом компьютере») и, только в сборке для разработчиков, **Проверочный режим TEST**. Метка на карточке говорит о состоянии: **Нет ключа**, **Ключ на этот сеанс**, **Готово**, **Нужен адрес**, **В приложении**.

## Для облачного помощника

- **Ключ OpenAI** (или Anthropic, Google Gemini): вставьте ключ. Приложение сразу его проверит: «Ключ принят: доступно 12 моделей. Действует, пока приложение открыто.» или «Провайдер не принял этот ключ. Проверьте его и вставьте снова.»
- **Запомнить на этом компьютере** сохраняет ключ в системном хранилище паролей. Где его нет: **Запомнить в папке приложения**, без шифрования, читать может только ваш пользователь. **Забыть ключ** удаляет его.
- **Адрес сервера (необязательно)**: оставьте пустым для официального адреса. Только для своего прокси и только https.
- См. [Ключи и где они хранятся](../assistant/Keys.ru.md).

## Для своего сервера

- **Адрес сервера**: адрес с портом, например `http://127.0.0.1:11434/v1` у Ollama. **Найти локальные серверы** ищет на этом компьютере (и спрашивает MCP-сервер); найденные серверы появляются в списке поля.
- Приложение читает список моделей сервера, как только есть адрес.

## Модель

Выберите из списка («Выбрать из 12 моделей на сервере») или впишите название. **Обновить список** читает его снова. Отметки у модели: **инструменты**, **без инструментов**, **зрение**, **рассуждение**. У модели без инструментов предупреждение «Эта модель не умеет вызывать инструменты, а помощнику они нужны, чтобы читать каталог и строить граф.» Если списка нет, **Подсказки (выбираете вы; подойдёт любое название модели):** предлагают несколько названий.

## Проверить связь

Отправляет один короткий запрос с полями выше. «Модель ответила за 840 мс.» Для своего сервера ещё сообщает окно контекста, например «Окно контекста на сервере (в токенах): 4096. Этого мало…». См. [Окно контекста](../assistant/Context-Window.ru.md).

## Поведение

| Поле | По умолчанию | Что делает |
|---|---|---|
| **Когда я прошу изменение** | **Сначала предложить (серые черновики)** | С **Строить сразу** просьба об изменении в режиме «Спросить» выполняется сразу, а не предлагается черновиками. |
| **Шагов на ответ** | 60 (от 4 до 200) | После стольких действий помощник встаёт на паузу и спрашивает, продолжать ли. Сборка «текст в картинку» занимает около 16. |
| **Окно контекста (токены)** | 0 = авто | Размер памяти модели. «Авто» берёт его по названию модели, с сервера или 32 000. |
| **Разрешить поиск в интернете**, **Разрешить читать веб-страницы** | включены | «Только когда ваш каталог не отвечает на вопрос. Ответы из интернета приходят со ссылкой.» |
| **Язык ответов** | **Как в интерфейсе** | или **Английский**, **Русский** |
| **Длина ответов** | **Коротко** | или **Подробнее** |

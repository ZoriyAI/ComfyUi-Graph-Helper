# Настройки: Помощник

«С какой моделью говорит помощник и как он ведёт себя в ответе.» Верхняя часть выбирает, кто отвечает; **Сеть** задаёт прокси; **Поведение** задаёт, как работает помощник. По шагам для каждого вида модели: [Кто отвечает](../assistant/Choosing-Who-Answers.ru.md).

<!-- picture: раздел «Помощник», выбран «Свой сервер», список моделей открыт -->

## Кто отвечает

В установленном приложении шесть карточек: **Не выбран** («Помощник выключен.»), **OpenAI**, **Anthropic**, **Google Gemini** («Облако. Нужен ключ.»), **Совместимый с OpenAI** («Другой облачный сервис по своему адресу. Нужен его ключ.») и **Свой сервер** («Ollama, LM Studio, vLLM на этом или другом компьютере»). При запуске приложения разработчиком видна ещё **Проверочный режим TEST**. Плашка на каждой карточке говорит о её состоянии: **Нет ключа**, **Ключ на этот сеанс**, **Готово**, **Нужен адрес**, **В приложении**.

## Для OpenAI, Anthropic и Google Gemini

- **Ключ OpenAI** (или Anthropic, Google Gemini): вставьте ключ. Он применяется сразу, и приложение проверяет его, читая список моделей: «Ключ принят: доступно 12 модели. Действует, пока приложение открыто.» или «Провайдер не принял этот ключ. Проверьте его и вставьте снова.»
- **Запомнить на этом компьютере** хранит ключ зашифрованным в системном хранилище паролей. Где его нет: **Запомнить в папке приложения**, без шифрования, читать может только ваш пользователь. **Забыть ключ** удаляет его. См. [Ключи и где они хранятся](../assistant/Keys.ru.md).
- **Адрес сервера (необязательно)**: оставьте пустым для официального адреса. Только для своего прокси и только https. Ключ работает только с тем адресом, для которого его вставили.
- У OpenAI ещё **Организация (необязательно)** и **Проект (необязательно)**: только если ваш ключ относится к нескольким организациям или проектам.
- **Какую модель взять**: **Для начала** (модель подешевле) и **Для длинных сборок** (посильнее), у каждой цена за миллион отправленных и полученных токенов и дата цен. «Запросы к облаку платные, счёт выставляет провайдер.» **Где взять ключ** и **Что провайдер делает с вашими данными** показаны адресами с кнопкой **Скопировать адрес**; браузер приложение само не открывает.
- Одна фраза перечисляет, что уходит с каждым вопросом: ваше сообщение, граф со значениями полей (если вы не выключили их в «Приватность»), что выделено и что на экране, ваши недавние действия и сводка ваших нод и файлов моделей. Ключи и сами файлы не отправляются никогда.
- Собственный поиск провайдера в интернете оплачивается отдельно: «около $10 за 1000 поисков» у OpenAI и Anthropic, $14 у Google. См. [Поиск в интернете и страницы](../assistant/Web-Search.ru.md).

## Для сервиса, совместимого с OpenAI

Любой облачный сервис с интерфейсом чата OpenAI: шлюз или региональный провайдер, например там, где три крупных провайдера недоступны.

1. **Адрес сервиса**: его адрес целиком, с https, обычно оканчивается на /v1.
2. Поле ключа ждёт адреса («Сначала впишите адрес сервиса выше: ключ принадлежит этому адресу.»). Потом вставьте собственный ключ сервиса; он уходит только на этот адрес.
3. Выберите модель из списка сервиса или впишите её название.

См. [Сервисы, совместимые с OpenAI](../assistant/OpenAI-Compatible.ru.md).

## Для своего сервера

- **Адрес сервера**: адрес с портом, например `http://127.0.0.1:11434/v1` для Ollama.
- **Найти локальные серверы** ищет на этом компьютере на портах Ollama (11434), LM Studio (1234), vLLM (8000) и сервера llama.cpp (8080) и спрашивает MCP-сервер, если он есть. Найденные серверы появляются в списке поля. Если никто не ответил: «Ни один локальный сервер не ответил. Чтобы модель была на этом компьютере, установите Ollama (ollama.com/download) и выполните «ollama pull qwen3.5:9b» (около 7 ГБ). Или запустите LM Studio, vLLM или сервер llama.cpp либо впишите адрес сами.»
- **Ключ для этого сервера (необязательно)**: только если ваш сервер его просит (vLLM, запущенный с --api-key, LiteLLM, LM Studio с включённой проверкой).
- Приложение читает список моделей сервера, как только есть адрес. Совет показывает, какие модели справляются и сколько им нужно видеопамяти: qwen3.5:9b около 8 ГБ, gpt-oss:20b около 16 ГБ, qwen3.6:27b около 24 ГБ, с окном не меньше 16 384 токенов (это оценки; больше моделей по железу в [Какую модель взять](../assistant/Which-Model.ru.md)). «Модель на вашем компьютере ничего не стоит за вопрос, и ничего не уходит с компьютера.»

## Модель

Выберите из списка («Выбрать из 12 моделей на сервере») или впишите название. **Обновить список** читает его заново. В списке только модели для чата. Отметки у модели: **инструменты**, **без инструментов**, **зрение**, **рассуждение**, **окно до N**. Модель без вызова инструментов получает предупреждение «Эта модель не умеет вызывать инструменты, а помощнику они нужны, чтобы читать каталог и строить граф.» Если списка нет, **Подсказки (выбираете вы; подойдёт любое название модели):** предлагают несколько названий.

## Проверить связь

**Проверить связь** отправляет один короткий запрос с полями выше. «Модель ответила за 840 мс.» Для своего сервера ещё сообщается окно контекста, например «Окно контекста на сервере (в токенах): 4096. Этого мало…».

Если окно маленькое, а сервер это Ollama, **Сделать копию с окном 16 384 токенов** делает копию модели, которая загружается с бо́льшим окном. Копия использует те же файлы: ничего не скачивается. Ей нужно больше памяти, чем исходной. **Как задать окно вручную** описывает Ollama как службу Linux, Ollama в контейнере, Ollama на другом компьютере, LM Studio («Context Length») и сервер llama.cpp (`-c 16384 --jinja`). См. [Окно контекста](../assistant/Context-Window.ru.md).

## Сеть

**Прокси (необязательно)**: пусто значит прокси из настроек системы. Через него идут запросы к облачным моделям и поиск в интернете. Подходят http://, https://, socks4:// и socks5://, имя хоста и порт, без имени пользователя и пароля (иначе «Это не адрес прокси…»). К своему серверу приложение всегда обращается напрямую.

## Поведение

| Поле | По умолчанию | Что делает |
|---|---|---|
| **Когда я прошу изменение** | **Сначала предложить (серые черновики)** | В каком режиме открывается поле помощника. «Спросить» отвечает и предлагает серые черновики, которые попадают в граф, только когда вы их примете. **Строить сразу** открывает «Строить». |
| **Шагов на ответ** | 60 (от 4 до 200) | Сделав столько действий, помощник встаёт на паузу и спрашивает, продолжать ли. Сборка «текст в картинку» занимает около 16. |
| **Окно контекста (токены)** | 0 = авто | Размер памяти модели. «Авто» берёт его по имени модели, с сервера или значение по умолчанию. |
| **Разрешить поиск в интернете**, **Разрешить читать веб-страницы** | включено | «Только когда ваш каталог не отвечает на вопрос. Ответы из интернета приходят со ссылкой.» |
| **Язык ответов** | **Как в интерфейсе** | или **Английский**, **Русский** |
| **Длина ответов** | **Коротко** | или **Подробнее** |

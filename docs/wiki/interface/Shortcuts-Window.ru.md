# Окно «Сочетания клавиш»

**Справка ▸ Сочетания клавиш** (`F1`) открывает окно со всеми командами, у которых есть сочетание, по меню. «Сочетания работают, когда курсор не в текстовом поле. Сохранение, открытие, новый проект, проверка графа и F1 работают всегда.» `F1` открывает его и во время набора в поле, но не поверх другого окна. На Mac вместо `Ctrl` нажимают `Cmd`.

Окно показывает сочетания такими, какие они сейчас, с вашими изменениями из «Настройки ▸ Сочетания клавиш». **Закрыть** или `Escape` закрывают его.

## Сочетания по умолчанию

| Команда | Сочетание |
|---|---|
| Новый проект | `Ctrl+N` |
| Открыть проект | `Ctrl+O` |
| Сохранить проект / Сохранить проект как… | `Ctrl+S` / `Ctrl+Shift+S` |
| Открыть workflow… | `Ctrl+I` |
| Сохранить workflow для ComfyUI… | `Ctrl+E` |
| Настройки… | `Ctrl+,` |
| Выход | `Ctrl+Q` |
| Отменить / Повторить | `Ctrl+Z` / `Ctrl+Shift+Z` (и `Ctrl+Y`) |
| Вырезать / Копировать / Вставить / Дублировать | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| Выделить всё | `Ctrl+A` |
| Удалить выделенное | `Delete` (на холсте) |
| Показать всё | `Shift+1` |
| Приблизить / Отдалить / Масштаб 100 % | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| Крупнее / Мельче / Обычный размер интерфейса | `Ctrl+Alt+=` / `Ctrl+Alt+-` / `Ctrl+Alt+0` |
| Библиотека / Правая панель | `Ctrl+B` / `Ctrl+J` |
| Остановить экскурсию или просмотр истории | `Escape` |
| Добавить ноду… | `Ctrl+K` |
| Собрать субграф из выделенного | `Ctrl+G` |
| Собрать группу из выделенного | `Ctrl+Shift+G` |
| Свернуть | `Alt+C` |
| Обойти / Выключить | `Ctrl+Shift+B` / `Ctrl+M` |
| Разложить граф | `Ctrl+Shift+L` |
| Проверить граф | `Ctrl+Shift+C` |
| Написать помощнику | `Ctrl+/` |
| Сочетания клавиш | `F1` |
| Перейти в главное меню | `Alt`, `F10` |
| Открыть контекстное меню | `Shift+F10` |

Окно перечисляет и клавиши для перемещения: `F6` и `Shift+F6` между частями окна, `F8` к уведомлениям, а на холсте `Enter` или `Пробел`, чтобы выбрать ноду в фокусе, стрелки, чтобы сдвинуть её, `Delete`, чтобы удалить. В библиотеке `Пробел` открывает карточку ноды, а `Enter` добавляет ноду.

# Окно «Сочетания клавиш»

**Справка ▸ Сочетания клавиш** (`F1`) открывает окно со всеми командами, у которых есть сочетание, по меню: Файл, Правка, Вид, Граф, Помощник, Справка. «Сочетания работают, когда курсор не в текстовом поле. Сохранение, открытие, новый проект и проверка графа работают всегда.»

Окно показывает сочетания такими, какие они сейчас, с вашими изменениями из «Настройки ▸ Сочетания клавиш». **Закрыть** или `Escape` закрывают его.

## Сочетания по умолчанию

| Команда | Сочетание |
|---|---|
| Новый проект | `Ctrl+N` |
| Открыть проект | `Ctrl+O` |
| Сохранить проект | `Ctrl+S` |
| Открыть workflow… | `Ctrl+I` |
| Сохранить workflow для ComfyUI… | `Ctrl+E` |
| Настройки… | `Ctrl+,` |
| Выход | `Ctrl+Q` |
| Отменить / Повторить | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Выделить всё | `Ctrl+A` |
| Удалить выделенное | `Delete` (на холсте) |
| Показать всё | `Shift+1` |
| Приблизить / Отдалить / Масштаб 100 % | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| Библиотека / Правая панель | `Ctrl+B` / `Ctrl+J` |
| Остановить экскурсию или просмотр истории | `Escape` |
| Добавить ноду… | `Ctrl+K` |
| Собрать субграф из выделенного | `Ctrl+G` |
| Разложить граф | `Ctrl+Shift+L` |
| Проверить граф | `Ctrl+Shift+C` |
| Написать помощнику | `Ctrl+/` |
| Сочетания клавиш | `F1` |
| Перейти в главное меню | `Alt`, `F10` |
| Открыть контекстное меню | `Shift+F10` |

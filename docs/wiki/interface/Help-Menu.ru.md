# Меню «Справка»

Меню **Справка** открывает страницы помощи внутри приложения, список сочетаний клавиш, журнал общения с помощником и сведения, которые нужны, чтобы сообщить о проблеме.

## Пункты

| Пункт | Сочетание | Что делает |
|---|---|---|
| **Руководство** | нет | Открывает руководство пользователя в окне внутри приложения, на языке интерфейса. |
| **Решение проблем** | нет | Открывает страницу о частых проблемах. |
| **Что нового** | нет | Открывает заметки к этому выпуску. Они написаны по-русски. |
| **Сочетания клавиш** | `F1` | Открывает [окно «Сочетания клавиш»](Shortcuts-Window.ru.md). |
| **Журнал общения с помощником…** | нет | Открывает [журнал общения](Conversation-Log.ru.md): что приложение отправило модели и что она ответила, вопрос за вопросом. |
| **Открыть папку журналов** | нет | Открывает папку с журналами приложения в файловом менеджере. |
| **Скопировать диагностику** | нет | Копирует в буфер обмена короткий отчёт о приложении и системе, для обращения или сообщения. Ключи и токены в него не попадают. |
| **О программе** | нет | Открывает [окно «О программе»](About-And-Help.ru.md): версия, лицензия, компоненты, папка с данными. |

Все пункты доступны всегда.

## Что говорит приложение

- «Диагностика скопирована. Вставьте её в обращение или сообщение. Ключи и токены в неё не попадают.»
- «Не удалось скопировать диагностику» или «Не удалось открыть папку журналов», если буфер обмена или файловый менеджер отказали.
- «Этой страницы нет в этой сборке приложения.», если страницы помощи нет в сборке.

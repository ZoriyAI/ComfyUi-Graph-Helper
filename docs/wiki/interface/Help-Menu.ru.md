# Меню «Справка»

Меню **Справка** открывает это руководство внутри приложения, тур по окну, карточки о запуске в ComfyUI и его ошибках, список сочетаний клавиш, журнал общения с помощником и сведения, которые нужны, чтобы сообщить о проблеме.

## Пункты

| Пункт | Сочетание | Что делает |
|---|---|---|
| **Руководство** | нет | Открывает это руководство в окне справки внутри приложения, на языке интерфейса. |
| **Тур по окну** | нет | Проходит по шести частям окна. См. [Окно приложения](Window.ru.md#тур-по-окну). |
| **Словарь** | нет | Открывает словарь слов ComfyUI. |
| **Решение проблем** | нет | Открывает страницу о частых проблемах. |
| **Что нового** | нет | Открывает заметки к этой версии. |
| **Правила содержимого** | нет | Открывает [правила содержимого](../trust/Content-Rules.ru.md) приложения. |
| **Сайт проекта** | нет | Открывает страницу проекта в браузере. |
| **Сообщить о проблеме…** | нет | Показывает сведения, которые будут вписаны, потом открывает в браузере страницу новой задачи. Задачу видят все. |
| **Новые версии** | нет | Открывает страницу с версиями приложения. |
| **Запустите в ComfyUI** | нет | Открывает карточку о том, как запустить сохранённый workflow. См. [Запуск в ComfyUI](../graph/Running-In-ComfyUI.ru.md). |
| **Разобрать ошибку ComfyUI…** | нет | Открывает карточку, куда вставляют ошибку из ComfyUI. См. [Ошибка в ComfyUI](../graph/ComfyUI-Errors.ru.md). |
| **Сочетания клавиш** | `F1` | Открывает [окно «Сочетания клавиш»](Shortcuts-Window.ru.md). |
| **Журнал общения с помощником…** | нет | Открывает [журнал общения](Conversation-Log.ru.md): что приложение отправило модели и что она ответила, вопрос за вопросом. |
| **Открыть папку журналов** | нет | Открывает папку с журналами приложения в файловом менеджере. |
| **Скопировать диагностику** | нет | Копирует в буфер обмена короткий отчёт о приложении и системе, для обращения или сообщения. Ключи, токены и адреса ваших серверов в него не попадают. |
| **О программе** | нет | Открывает [окно «О программе»](About-And-Help.ru.md): версия, лицензия, компоненты, папка с данными. |

Три ссылки проекта серые в сборке, где адрес проекта не задан: «В этой сборке приложения не задан адрес проекта.» Веб-страница открывается только по выбору пункта.

## Что говорит приложение

- «Диагностика скопирована. Вставьте её в обращение или сообщение. Ключи и токены в неё не попадают.»
- «Не удалось скопировать диагностику» или «Не удалось открыть папку журналов», если буфер обмена или файловый менеджер отказали.
- «Этой страницы нет в этой сборке приложения.», если страницы помощи нет в сборке.

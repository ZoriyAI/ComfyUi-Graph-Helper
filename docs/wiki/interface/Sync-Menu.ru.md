# Меню «Синхронизация»

Меню **Синхронизация** читает ваш ComfyUI: какие в нём есть ноды, паки нод и файлы моделей. Чтение ничего не меняет в ComfyUI. Результат заполняет [библиотеку](Library.ru.md).

## Пункты

| Пункт | Что делает | Серый, когда |
|---|---|---|
| **Синхронизировать сейчас** | Читает ваш ComfyUI прямо сейчас. | синхронизация уже идёт |
| **Синхронизировать автоматически** | Читает его снова по таймеру. Галочка значит «включено». Интервал задаётся в «Настройки ▸ Синхронизация» (не чаще раза в 5 минут). | у приложения ещё нет состояния синхронизации (сразу после первого запуска, пока подключение не задано) |
| **Настройки синхронизации…** | Открывает [Настройки ▸ Синхронизация](Settings-Sync.ru.md). | никогда |

## Что говорит приложение

- Адреса ещё нет: сообщение «Адрес MCP-сервера не указан» с кнопкой **Открыть настройки подключения**.
- Файлы моделей ещё читаются: «Метаданные моделей ещё читаются (12 / 300). „Синхронизировать сейчас“ снова заработает, когда чтение закончится или будет приостановлено.»
- Когда синхронизация заканчивается, сообщение справа внизу говорит, что прочитано, например «Прочитано нод: 812, паков: 41, файлов моделей: 96.»

[Значок синхронизации](Sync-Indicator.ru.md) у правого края главного меню всё время показывает состояние.

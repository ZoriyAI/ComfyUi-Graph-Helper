# Настройки: Сочетания клавиш

«Нажмите «Изменить», затем новые клавиши. Escape отменяет. Сочетания применяются после сохранения.» Раздел перечисляет все команды приложения по меню (Файл, Правка, Вид, Граф, Помощник, Синхронизация, Справка) вместе с их сочетаниями.

## Как изменить сочетание

1. Найдите команду в списке. Строки вроде «Язык: English» или «Кто отвечает: OpenAI» это варианты подменю.
2. Нажмите **Изменить**. Строка напишет «Нажмите клавиши…».
3. Нажмите новое сочетание, например `Ctrl+Shift+K`. `Escape` отменяет.
4. Если сочетание уже занято другой командой: «Ctrl+K уже у команды «Добавить ноду…». Перенести его на «…»? У «Добавить ноду…» сочетания тогда не будет.» **Перенести** или **Оставить как было**.
5. Нажмите **Сохранить настройки**.

## Другие кнопки в строке

- крестик (**Убрать**): у команды не будет сочетания («Нет»);
- круглая стрелка (**Сбросить**): вернуть сочетание по умолчанию; его показывает «По умолчанию: Ctrl+K».

**Сбросить все по умолчанию** вверху сбрасывает все строки. Если две строки делят сочетание, это отмечено: «Занято командой «…»».

## Полезно знать

- В Linux это клавиша `Ctrl`; буквы сравниваются по физической клавише, поэтому русская раскладка тоже работает.
- `Alt` и `F10` (главное меню) и `Shift+F10` (меню холста) поменять нельзя.

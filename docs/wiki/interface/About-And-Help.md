# About and the help reader

**Help ▸ About** opens a small window about the app. **Help ▸ User guide**, **Troubleshooting** and **What is new** open the help reader, a window that shows a help page inside the app.

## The About window

- The name, "Version 0.8.0" and one paragraph: "A learning helper for ComfyUI: it reads which nodes and models you have and helps you build and understand a graph. It changes nothing in ComfyUI itself."
- **Licence** shows the licence of the app (MIT). **Back** returns.
- **Third-party components**: the packages that ship with the app; choose one to read its licence. **Chromium licences** opens the licences of the browser engine inside Electron.
- **Copy details** copies the version, the runtime and the system for a bug report: "Details copied. Paste them into a bug report."
- **Open data folder** opens the folder where the app keeps its data.
- **Details** unfolds the runtime ("Runtime: Electron … · Chromium … · Node …"), the system and the data folder path.
- **Close**.

The same view is in [Settings ▸ About](Settings-About.md).

## The help reader

A window with the page in the language of the interface and **Close**. "Opening…" while it loads. **What is new** is written in Russian only; in English the window says so. A page that is not in this build: "This page is not in this build of the app."

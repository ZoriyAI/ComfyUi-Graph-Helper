# About and the help reader

**Help ▸ About** opens a small window about the app. **Help ▸ User guide**, **Glossary**, **Troubleshooting**, **What's new** and **Content rules** open the help reader: this guide, inside the app.

## The About window

- The name, the line "A desktop tutor for ComfyUI graphs", the version ("Version …"), the author ("Author: Aleksey Ponomarenko", see [The author and the experiment](../trust/Author.md)) and two paragraphs: that the app is an independent, experimental learning tool, not affiliated with or endorsed by Comfy Org, with no ComfyUI code, which only reads a running ComfyUI; and what it does: it reads which nodes and models you have, explains every node and link, and teaches with lessons you do by hand. It never runs or changes anything in ComfyUI.
- **License** shows the license of the app and what it does not allow: selling the app, or a paid product or service built mainly on it, without the written permission of the copyright holder. **Back** returns.
- **Third-party components**: the packages that ship with the app; choose one to read its license. **Chromium licenses** opens the licenses of the browser engine inside Electron.
- **Copy details** copies the version, the runtime and the system for a problem report: "Details copied".
- **Open data folder** opens the folder where the app keeps its data.
- **Project website**, **Report a problem…** and **New versions** open the project's pages in your browser. **Report a problem…** first shows what will be filled in: "A page for a new issue opens in your browser with these details already filled in. Everyone can read an issue: look through the details and everything you add before you post it." **Open the page** opens it.
- **Details** unfolds the runtime ("Runtime: Electron … · Chromium … · Node …"), the system and the data folder path.
- **Close**.

The same view is in [Settings ▸ About](Settings-About.md).

## The help reader

The help reader shows this guide in the language of the interface.

- On the left: the sections of the guide and **Search the help**. A search with no match says "Nothing found. Try another word."
- The page itself on the right. Links between pages open in the reader; **Back** (the arrow) goes to the page before.
- "Opening…" while a page loads. A page that is not in this build: "This page is not in this build of the app."
- **What's new** shows the notes of this version.
- A message or a hint in the app can open the page that explains it.

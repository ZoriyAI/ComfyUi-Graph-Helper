# The shortcuts window

**Help ▸ Keyboard shortcuts** (`F1`) opens a window with every command that has a shortcut, grouped by menu: File, Edit, View, Graph, Assistant, Help. "Shortcuts work when the cursor is not in a text field. Save, Open, New and Check graph work everywhere."

It shows the shortcuts as they are now, with your changes from Settings ▸ Shortcuts. **Close** or `Escape` closes it.

## The default shortcuts

| Command | Shortcut |
|---|---|
| New project | `Ctrl+N` |
| Open project | `Ctrl+O` |
| Save project | `Ctrl+S` |
| Open workflow… | `Ctrl+I` |
| Save workflow for ComfyUI… | `Ctrl+E` |
| Settings… | `Ctrl+,` |
| Exit | `Ctrl+Q` |
| Undo / Redo | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Select all | `Ctrl+A` |
| Delete selection | `Delete` (on the canvas) |
| Fit to view | `Shift+1` |
| Zoom in / Zoom out / Actual size | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| Library / Tools panel | `Ctrl+B` / `Ctrl+J` |
| Stop the tour or replay | `Escape` |
| Add node… | `Ctrl+K` |
| Make a subgraph from selection | `Ctrl+G` |
| Arrange the graph | `Ctrl+Shift+L` |
| Check graph | `Ctrl+Shift+C` |
| Message the assistant | `Ctrl+/` |
| Keyboard shortcuts | `F1` |
| Go to the menu bar | `Alt`, `F10` |
| Open the context menu | `Shift+F10` |

# The shortcuts window

**Help ▸ Keyboard shortcuts** (`F1`) opens a window with every command that has a shortcut, grouped by menu. "Shortcuts work when the cursor is not in a text field. Save, Open, New, Check graph and F1 work everywhere." `F1` opens it even while you type in a field, but not over another dialog. On a Mac, `Ctrl` is `Cmd`.

It shows the shortcuts as they are now, with your changes from Settings ▸ Shortcuts. **Close** or `Escape` closes it.

## The default shortcuts

| Command | Shortcut |
|---|---|
| New project | `Ctrl+N` |
| Open project | `Ctrl+O` |
| Save project / Save project as… | `Ctrl+S` / `Ctrl+Shift+S` |
| Open workflow… | `Ctrl+I` |
| Save workflow for ComfyUI… | `Ctrl+E` |
| Settings… | `Ctrl+,` |
| Quit | `Ctrl+Q` |
| Undo / Redo | `Ctrl+Z` / `Ctrl+Shift+Z` (also `Ctrl+Y`) |
| Cut / Copy / Paste / Duplicate | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| Select all | `Ctrl+A` |
| Delete selection | `Delete` (on the canvas) |
| Fit to view | `Shift+1` |
| Zoom in / Zoom out / Actual size | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| Larger interface / Smaller interface / Normal interface size | `Ctrl+Alt+=` / `Ctrl+Alt+-` / `Ctrl+Alt+0` |
| Library / Tools panel | `Ctrl+B` / `Ctrl+J` |
| Stop the tour or replay | `Escape` |
| Add node… | `Ctrl+K` |
| Make a subgraph from selection | `Ctrl+G` |
| Make a group from selection | `Ctrl+Shift+G` |
| Collapse | `Alt+C` |
| Bypass / Mute | `Ctrl+Shift+B` / `Ctrl+M` |
| Arrange the graph | `Ctrl+Shift+L` |
| Check graph | `Ctrl+Shift+C` |
| Message the assistant | `Ctrl+/` |
| Keyboard shortcuts | `F1` |
| Go to the menu bar | `Alt`, `F10` |
| Open the context menu | `Shift+F10` |

The window also lists the keys that move around: `F6` and `Shift+F6` between the parts of the window, `F8` to the notifications, and on the canvas `Enter` or `Space` to select the node that has focus, the arrows to move it, `Delete` to remove it. In the library, `Space` opens a node's card and `Enter` adds the node.

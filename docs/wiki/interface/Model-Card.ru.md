# Карточка модели

Карточка модели открывается рядом с библиотекой, когда вы щёлкаете файл на вкладке **Модели**. Она говорит, что это за файл, к каким моделям он подходит, как автор задумал его применять, и ставит его на холст за вас.

<!-- picture: карточка LoRA с картинкой, словами-триггерами и разделом «Как применять» -->

## Что показывает карточка

| Часть | Что в ней |
|---|---|
| **Превью** | картинка или ролик-пример, которые лежат рядом с файлом |
| **Семейство** | семейство моделей и откуда это известно: «по метаданным файла», «по описанию рядом с файлом», «по имени файла», «по данным из интернета» |
| **Вид**, **Размер**, **Папка** | что это за файл, какого размера, в какой папке ComfyUI |
| **Название от автора**, **Сделано для**, **Версия**, **Автор**, метки | что автор написал в описании рядом с файлом |
| **Слова-триггеры** | слова, которые включают LoRA. Щелчок по слову копирует его, **Скопировать все** копирует все. Если их нет: «Слов-триггеров в файле нет: LoRA работает и без них.» |
| **Как применять** | «Сила, которую советует автор: 0.9», «Работает от 0.6 до 1.2», «Пропуск слоёв CLIP (clip skip): 2» |
| **Описания, которыми пользовался автор** | промпты картинок-примеров автора, у каждого кнопка **Скопировать** |
| **Подходит к** | у LoRA: «Ваши базовые модели, к которым она подходит:» и ваши чекпойнты её семейства. У чекпойнта: «К этой модели подходят 3 ваших LoRA» и **Показать их в списке** |
| **Из интернета** | что говорят о файле Civitai или Hugging Face, после кнопки **Найти в интернете** |
| **Ваши заметки** | заметки, которые вы написали об этом файле в своём менеджере моделей; они читаются из описания рядом с файлом |

## Кнопки

- **Добавить на холст** ставит подходящую ноду-загрузчик с уже выбранным файлом и выделяет её: «Добавлена нода «Load LoRA» с файлом … Она выделена.»
- **Подставить в выбранную ноду** появляется, когда выделена нода, которая грузит такие файлы: она начнёт грузить этот файл.
- **Спросить помощника** и **Как это подключить?** отправляют вопрос о файле.
- **Найти в интернете** отправляет отпечаток файла на civitai.com, а если Civitai его не знает, имя файла на huggingface.co. «Сервер читает весь файл. Большой файл займёт несколько минут.»

## Содержимое для взрослых

Если автор отметил файл как содержимое для взрослых: «Автор отметил это как содержимое для взрослых. Превью и примеры к нему скрыты.» **Показать для этого файла** показывает их для этого файла; **Скрыть снова** прячет. Показывать всегда: «Настройки ▸ Приватность».

## Что может пойти не так

- «Этого файла больше нет в каталоге. Синхронизируйте ещё раз, чтобы обновить список.»
- «Для файлов из папки «…» нет стандартной ноды-загрузчика. Спросите помощника, какая нода их загружает.»
- «Превью не удалось прочитать. Возможно, компьютер с ComfyUI выключен.»
- «Найти не получилось: сайт не ответил. Проверьте подключение к интернету.»
- «Civitai не знает этот файл; на Hugging Face по имени ничего не найдено.»

# Settings: Canvas

"What the canvas shows, and how fast the assistant builds in front of you." Everything here applies after **Save settings**.

| Field | Default | What it does |
|---|---|---|
| **Show descriptions** | on | "A short card under each node: what it is and why it is there." Off is the same as the mode **Off (dots only)**. |
| **Description cards** | **Own notes only** | **Own notes only**, **All nodes** or **Off (dots only)**. See [Description cards](Description-Cards.md). |
| **Show minimap** | on | "The overview in the corner of the canvas." |
| **Follow the assistant while it builds** | on | "The view moves to each new node. Any pan or zoom of yours turns it off for now." |
| **Play the guided tour automatically** | on | "Off: the tour waits on each stop until you go on." See [The tour of a graph](../graph/Tour.md). |
| **Build pace, ms per step** | 820 (300 to 2000) | How long each step of a live build stays before the next one. With motion off, everything appears at once. |
| **Grid spacing, px** | 18 (8 to 48) | "Distance between the dots on the canvas." |

The canvas toolbar and the View menu change the description mode, the minimap and following for the moment; the View menu choice of following is also saved.

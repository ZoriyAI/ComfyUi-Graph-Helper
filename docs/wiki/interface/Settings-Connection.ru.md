# Настройки: Подключение

Сначала указывается адрес ComfyUI. Все запросы только читают: ничего не ставят в очередь, не загружают и не устанавливают. Шаги: [Подключение](../connect/Connecting.ru.md). Ограничения: [Что даёт каждый способ](../connect/What-Each-Way-Shows.ru.md).

| Поле или действие | Назначение |
|---|---|
| Адрес ComfyUI | Origin, который открывает ComfyUI в браузере, со схемой и портом |
| Найти на этом компьютере | Ищет распространённые локальные адреса; выберите свой сервер |
| Проверить рядом с адресом ComfyUI | Проверяет введённый адрес до сохранения |
| Состояние подключения | Состояние синхронизации и источник библиотеки, включая пробелы |
| Прочитать ComfyUI | Читает по сохранённым настройкам; сначала сохраните изменения |
| Проверить граф | Сверяет граф с текущим каталогом, не выполняет его |
| Адрес необязательного MCP-сервера | Отдельный URL сервера, часто с окончанием `/mcp`, для дополнительных метаданных |
| Проверить рядом с адресом MCP | Определяет доступ к MCP: без входа, токен или браузерный вход |
| Токен MCP / Запомнить на этом компьютере | Токен на время сеанса, по желанию зашифрованный в хранилище паролей ОС |
| Вход MCP через браузер | Сначала сохраните настройки, затем войдите; доступ привязан к адресу MCP |

Для обычного чтения ComfyUI MCP не требуется. Удалённому MCP нужен HTTPS; прямой адрес ComfyUI может использовать HTTP, если он доступен. Прямое чтение использует origin URL; перенаправления на браузерные страницы входа не поддерживаются как адреса ComfyUI. Не помещайте учётные данные в URL.

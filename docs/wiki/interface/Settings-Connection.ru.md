# Настройки: Подключение

«Где ваш ComfyUI. Приложение только читает из него: ничего не ставит в очередь и не устанавливает.» Первым идёт адрес ComfyUI, и его одного достаточно; MCP-сервер не обязателен. Шаги: [Подключение](../connect/Connecting.ru.md). Что даёт каждый способ: [Что даёт каждый способ](../connect/What-Each-Way-Shows.ru.md).

## Сверху вниз

| Поле или кнопка | Что делает |
|---|---|
| **Адрес ComfyUI** | Адрес, по которому вы открываете ComfyUI в браузере. На этом компьютере это обычно `http://127.0.0.1:8188`, у приложения ComfyUI Desktop порт 8000. В списке поля адреса, которые приложение знает. |
| **Проверить ComfyUI** | Спрашивает введённый адрес до сохранения: «ComfyUI 0.45.0 отвечает по этому адресу. Сохраните настройки, и приложение его прочитает.» Адрес без `http://` дополняется. |
| **Найти на этом компьютере** | Проверяет порты 8188 и 8000 этого компьютера и заполняет адрес: «На этом компьютере отвечает ComfyUI: http://127.0.0.1:8188.» Если никто не отвечает: «На этом компьютере ComfyUI не отвечает на портах 8188 и 8000. Запустите ComfyUI или введите его адрес.» |
| подсказки | Для адреса на другом компьютере: «ComfyUI на другом компьютере отвечает, только если запущен с --listen, например --listen 0.0.0.0. Тогда до него может достучаться вся сеть, а своего пароля у ComfyUI нет: пользоваться им сможет любой в сети. Делайте так только в сети, которой доверяете.» Для обычного http между двумя компьютерами: в чужой сети используйте https. |
| состояние | Как прошло последнее чтение. |
| **Прочитать сейчас** | Читает ComfyUI по сохранённым настройкам. Сначала сохраните изменения. |
| **Проверить этот граф** | Сверяет граф на холсте с прочитанным: «Не хватает нод: нет. Не хватает моделей: нет.» Ничего не запускает. |

## MCP-сервер (необязательно)

«ComfyUI не отдаёт файлы описаний рядом с моделями (.civitai.info, .metadata.json), README паков нод и отпечаток файла. Их добавляет MCP-сервер, который умеет читать файлы. Если такого сервера нет, оставьте поле пустым.»

| Поле или кнопка | Что делает |
|---|---|
| **Адрес MCP-сервера** | Вставьте адрес так, как его показывает сервер, например `http://127.0.0.1:9000/mcp`. Серверу на другом компьютере нужен https. |
| **Проверить** | Спрашивает сервер, что он такое и какой доступ ему нужен, и сам выбирает доступ. |
| вид сервера | Строка под полем: «Этот MCP-сервер даёт весь каталог…», «Этот MCP-сервер перечисляет только модели. Ноды приложение берёт по адресу ComfyUI выше.», «Этот MCP-сервер перечисляет только чекпойнты…» или красным «Приложение не знает инструментов этого MCP-сервера и ничего через него не читает. Адреса ComfyUI выше достаточно.» |
| **Доступ к серверу** | **Без входа**, **Токен** (вставьте его в **Токен доступа**; **Запомнить на этом компьютере** хранит его зашифрованным в системном хранилище паролей) или **Вход через браузер** (сначала сохраните настройки, потом **Войти**). |

Официальный comfy-mcp, который работает как локальная команда, подключить пока нельзя.

## Правила

- Не вписывайте в адрес имя пользователя и пароль: «Уберите из адреса имя и пароль.»
- Приложение вызывает только инструменты, которые читают. В ComfyUI ничего не запускается, не загружается и не устанавливается.
- Все фразы об ошибках и их причины: [Проблемы с подключением](../connect/Connection-Problems.ru.md).

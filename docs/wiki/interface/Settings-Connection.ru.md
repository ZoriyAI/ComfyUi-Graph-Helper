# Настройки: Подключение

**Подключение к ComfyUI**: «Как приложение обращается к вашему ComfyUI. Все вызовы только читают; ничего не ставится в очередь и не устанавливается.» Шаги подключения для любой установки описаны в [Подключение](../connect/Connecting.ru.md); здесь перечислены поля.

## Поля сверху вниз

| Поле | Что это |
|---|---|
| **Адрес MCP-сервера** | Адрес MCP-сервера рядом с ComfyUI так, как его показывает сервер, например `http://127.0.0.1:9000/mcp`. Список поля предлагает адреса, которые знает приложение («назван MCP-сервером», «сохранён в настройках», «использовался раньше», «найден на этом компьютере»). |
| **Проверить** (рядом с ним) | Спрашивает сервер, нужен ли вход, и выбирает подходящий вариант ниже: «Сервер отвечает без входа. Выбрано «Без входа».» Если вы не написали `http://`, приложение добавит его и скажет об этом. |
| **Доступ к серверу** | **Без входа**, **Токен** или **Вход через браузер**. «Выбор вступит в силу после «Сохранить настройки».» |
| **Токен доступа** (при «Токен») | Вставьте токен; он сразу проверяется: «Токен принят: сервер отвечает (инструментов: 14). Действует, пока приложение открыто.» **Запомнить на этом компьютере** кладёт его в хранилище паролей; **Забыть токен** удаляет. |
| **Войти** (при «Вход через браузер») | Сначала **Сохранить настройки**, потом **Войти**: откроется браузер. «Вход выполнен до 18:40.» **Войти заново**, **Выйти**. |
| **Адрес ComfyUI** | Необязательно. Адрес, по которому вы открываете ComfyUI в браузере, например `http://127.0.0.1:8188`. Заполните, если ComfyUI работает на другом компьютере или вы читаете его без MCP-сервера. **Поискать на этом компьютере** ищет его. |
| **Состояние MCP** | Метка с состоянием синхронизации, например «Состояние MCP: Синхронизировано». |

## Кнопки внизу

Работают только с сохранёнными настройками (серые, пока в черновике есть изменения):

- **Прочитать через MCP**: синхронизация с тем же итогом, что в её сообщении.
- **Прочитать ComfyUI**: читает адрес ComfyUI напрямую: «ComfyUI 0.3.60 прочитан. Устройств: 1. Нод: 812.»
- **Проверить этот граф**: «Не хватает нод: нет. Не хватает моделей: нет.»

## Что приложение говорит об адресе

- «Добавьте в начало адреса http:// или https://, например http://192.168.1.5:9000/mcp.»
- «Это адрес самого ComfyUI, а нужен адрес MCP-сервера рядом с ним. Сервер показывает его при запуске.»
- «По этому адресу что-то отвечает, но MCP-сервера здесь нет. Обычно адрес MCP-сервера заканчивается на /mcp.»
- «Адрес MCP-сервера должен использовать https, если сервер работает не на этом компьютере.»
- «Уберите из адреса имя и пароль.»

Больше в [Проблемы с подключением](../connect/Connection-Problems.ru.md).

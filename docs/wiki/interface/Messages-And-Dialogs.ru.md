# Сообщения и диалоги

Приложение говорит с вами двумя способами. **Сообщение** появляется справа внизу на несколько секунд и говорит, что только что произошло; у некоторых есть кнопка, а **Закрыть** убирает сообщение. `F8` переводит фокус клавиатуры к сообщениям. **Диалог** останавливает работу и спрашивает перед тем, что нельзя вернуть. Полный список текстов в [Сообщения](../reference/Messages.ru.md).

## Частые сообщения

| Сообщение | После чего |
|---|---|
| «Проект сохранён.» / «Проект открыт.» | Файл ▸ Сохранить проект / Открыть проект |
| «Workflow открыт. Не хватает нод: … Не хватает моделей: …», откуда пришёл workflow (картинка, видео, формат API, пример) и **Открыть проверку** | открытие workflow любым способом. См. [Открыть workflow](../graph/Opening-Workflows.ru.md). |
| «Ноды раздвинуты, чтобы не накрывать друг друга: 12» | открытие workflow, где ноды накрывали друг друга |
| «Workflow сохранён для ComfyUI.» с кнопкой **Как запустить** | Файл ▸ Сохранить workflow для ComfyUI…; открывается и карточка **Запустите в ComfyUI** |
| «Список загружен. Нод: 812. Моделей: 96. Пропущено: 0.» | Файл ▸ Загрузить список нод из файла… |
| «Прочитано нод: 75, паков: 5, файлов моделей: 331.» | синхронизация |
| «Нода KSampler добавлена в граф.» | добавление ноды из библиотеки |
| «Входы и выходы этой ноды пока неизвестны: запустите ComfyUI и синхронизируйте» | добавление ноды, у которой не прочитаны входы и выходы |
| «Изменение не применено» | граф успел измениться |
| «Заменено на …» | Заменить на… |
| «IMAGE нельзя подать на вход, который ждёт LATENT.» | связь отпущена на входе другого типа |
| «Сначала выделите одну или несколько нод.» | «Обойти», «Выключить» или «Цвет», когда ничего не выделено |
| «На диске нет свободного места. Изменение не сохранено; освободите место и повторите.» | диск заполнен |

## Диалоги с вопросом

| Диалог | Кнопки |
|---|---|
| **Начать новый проект?** «Граф на холсте в нынешнем виде не сохранён в файл проекта…» | **Отмена**, **Начать новый проект** |
| **Открыть workflow?** / **Открыть другой проект?** «Граф на холсте в нынешнем виде не сохранён в файл проекта…» | **Отмена**, **Открыть workflow** / **Открыть проект** |
| **Помощник ещё строит. Остановить?** «Сборка остановится, а то, что она уже добавила, останется в этом графе. Потом откроется то, что вы выбрали.» | **Отмена**, **Остановить и продолжить** |
| **В workflow 3 проблемы** «ComfyUI может не запустить его в таком виде. Откройте проверку, чтобы исправить, или сохраните как есть.» | **Отмена**, **Открыть проверку**, **Всё равно сохранить** |
| **1 поле похоже на ключ или токен** «Кто получит файл, сможет прочитать эти значения. Сохраните без них (в файле эти поля останутся пустыми) или как есть.» | **Отмена**, **Сохранить как есть**, **Сохранить без этих значений** |
| **Закрыть без сохранения?** (настройки) | **Продолжить правку**, **Закрыть без сохранения** |
| **Забыть все ключи и токены?** | **Отмена**, **Забыть** |
| **Очистить историю чата?** | **Отмена**, **Очистить** |
| **Включить содержимое для взрослых?** с правилами | **Прочитать правила содержимого**, **Мне есть 18 лет**, **Не включать** |
| **Граф не открылся в прошлый раз** «При прошлом запуске граф не дорисовался. Возможно, он слишком большой или повреждён.» | **Начать с пустого холста**, **Открыть граф снова** |
| «Удалить все 12 записей? Вернуть их будет нельзя.» (журнал общения) | **Оставить**, **Удалить** |

## Когда что-то сломалось

| Заголовок | Что делать |
|---|---|
| **Что-то пошло не так** «В приложении произошла ошибка. Оно продолжает работать; подробности в журнале.» | **ОК**. |
| **Окно перестало работать** | **Перезагрузить**; граф сохранён. |
| **Окно не отвечает** | **Подождать** или **Перезагрузить**. |
| **Файл с данными приложения повреждён** «Можно начать с пустыми данными. Повреждённый файл не удаляется…» | **Начать с пустыми данными**, **Открыть папку** или **Выйти**. |
| «Ваши данные сохранены более новой версией приложения. Установите эту версию снова, чтобы открыть их. Ничего не изменено.» | установите более новую версию |
| **NodeWise Studio не запустился** «Журнал находится в …» | откройте папку журналов и см. [Решение проблем](../reference/Troubleshooting.ru.md) |
| **Ваша работа в NodeWise Studio** (первый запуск после версии 0.9) | прочитайте, где теперь ваша работа; ключи из системного хранилища паролей нужно снова ввести в настройках |
| **Версия 0.9 ещё открыта** | закройте версию 0.9 и запустите приложение снова |

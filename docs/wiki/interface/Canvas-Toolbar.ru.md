# Панель инструментов холста

Панель инструментов холста плавает над холстом сверху. На ней то, что делается на самом холсте: добавить ноду, разложить граф, масштаб, карточки-описания, экскурсия, история и слежение за помощником. Эти действия есть только здесь и в меню, а не на верхней панели.

<!-- picture: панель холста, группы кнопок обведены -->

## Кнопки слева направо

| Кнопка | Что делает |
|---|---|
| **Нода** | Открывает поиск нод (**Добавить ноду**, `Ctrl+K`). См. [Добавление нод](../graph/Adding-Nodes.ru.md). |
| **Разложить** | **Разложить граф** (`Ctrl+Shift+L`): раскладывает граф слева направо; если выделено две ноды или больше, только их. |
| лупа с минусом | **Отдалить** (`Ctrl+-`). |
| число процентов | **Масштаб 100 %** (`Ctrl+0`). |
| лупа с плюсом | **Приблизить** (`Ctrl+=`). |
| четыре уголка | **Показать всё**: весь граф в окне (`Shift+1`). |
| **Описания** | Переключает карточки-описания: только свои заметки, потом все ноды, потом выключены. Подсказка называет режим, например «Описания: только свои заметки. Нажмите, чтобы показать для всех нод». См. [Карточки-описания](Description-Cards.ru.md). |
| **Экскурсия** | Начинает [экскурсию по графу](../graph/Tour.ru.md); повторное нажатие её заканчивает. |
| часы со стрелкой | **Просмотр истории**: ползунок по прежним версиям графа. См. [История и отмена](../graph/History-And-Undo.ru.md). |
| бумажный самолётик | **Следить за помощником**: пока помощник строит, вид переходит к каждой новой ноде. Подсвечен значит включён. |
| **Принять все (3)** | Появляется, когда помощник оставил два серых черновика или больше. Принимает все. См. [Серые черновики](../assistant/Drafts.ru.md). |

## Полоса экскурсии

Пока идёт экскурсия, под панелью появляется вторая полоса: **Предыдущий шаг**, **Воспроизвести** / **Пауза**, **Следующий шаг**, «Шаг 2 из 7» и **Закончить экскурсию**.

## Полоса просмотра истории

Пока идёт просмотр истории, кнопка истории превращается в полосу: **Воспроизвести** / **Пауза**, ползунок (**Версия**) и **Выйти из просмотра истории**. Холст пишет «Версия 12 из 40: добавление ноды KSampler. Только просмотр.» Если истории ещё нет: «Истории пока нет.»

## Полоса живой сборки

Пока помощник строит, под панелью холста видна полоса «Помощник строит: шаг 3 из 8» с кнопками **Приостановить сборку**, **Продолжить сборку**, **Остановить сборку** и **Показать всё сразу**. См. [Строить](../assistant/Build.ru.md).

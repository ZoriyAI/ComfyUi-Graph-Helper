# Help menu

The **Help** menu opens this guide inside the app, the tour of the window, the cards about running in ComfyUI and its errors, the list of keyboard shortcuts, the conversation log and the facts you need when you report a problem.

## Items

| Item | Shortcut | What it does |
|---|---|---|
| **User guide** | none | Opens this guide in the help reader inside the app, in the language of the interface. |
| **Tour of the window** | none | Walks through the six parts of the window. See [The window](Window.md#the-tour-of-the-window). |
| **Glossary** | none | Opens the glossary of ComfyUI words. |
| **Troubleshooting** | none | Opens the page about common problems. |
| **What's new** | none | Opens the notes of this version. |
| **Content rules** | none | Opens the [content rules](../trust/Content-Rules.md) of the app. |
| **Project website** | none | Opens the project page in your browser. |
| **Report a problem…** | none | Shows the details that will be filled in, then opens a page for a new issue in your browser. Everyone can read an issue. |
| **New versions** | none | Opens the page with the versions of the app. |
| **Run it in ComfyUI** | none | Opens the card that says how to run the saved workflow. See [Running the result in ComfyUI](../graph/Running-In-ComfyUI.md). |
| **Explain a ComfyUI error…** | none | Opens the card where you paste an error from ComfyUI. See [An error in ComfyUI](../graph/ComfyUI-Errors.md). |
| **Keyboard shortcuts** | `F1` | Opens the [shortcuts window](Shortcuts-Window.md). |
| **Conversation log…** | none | Opens the [conversation log](Conversation-Log.md): what the app sent to the model and what it answered, question by question. |
| **Open logs folder** | none | Opens the folder with the app's log files in your file manager. |
| **Copy diagnostics** | none | Copies a short report about the app and your system to the clipboard, for an issue or a message. Keys, tokens and the addresses of your own servers are left out. |
| **About** | none | Opens the [About window](About-And-Help.md): version, license, components, data folder. |

The three project links are grey in a build that has no project address: "This build of the app has no project address." A web page opens only when you choose an item.

## What the app says

- "Diagnostics copied. Paste them into an issue or a message. Keys and tokens are left out."
- "Diagnostics could not be copied" or "The logs folder could not be opened" when the clipboard or the file manager refuses.
- "This page is not in this build of the app." when a help page is missing from the build.

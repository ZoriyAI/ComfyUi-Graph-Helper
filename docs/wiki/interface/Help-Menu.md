# Help menu

The **Help** menu opens the help pages inside the app, the list of keyboard shortcuts, the conversation log and the facts you need when you report a problem.

## Items

| Item | Shortcut | What it does |
|---|---|---|
| **User guide** | none | Opens the user guide in a window inside the app, in the language of the interface. |
| **Troubleshooting** | none | Opens the page about common problems. |
| **What is new** | none | Opens the notes of this release. They are written in Russian; in English the window says "Release notes are written in Russian." |
| **Keyboard shortcuts** | `F1` | Opens the [shortcuts window](Shortcuts-Window.md). |
| **Conversation log…** | none | Opens the [conversation log](Conversation-Log.md): what the app sent to the model and what it answered, question by question. |
| **Open logs folder** | none | Opens the folder with the app's log files in your file manager. |
| **Copy diagnostics** | none | Copies a short report about the app and your system to the clipboard, for an issue or a message. Keys and tokens are left out. |
| **About** | none | Opens the [About window](About-And-Help.md): version, licence, components, data folder. |

All items can always be chosen.

## What the app says

- "Diagnostics copied. Paste them into an issue or a message. Keys and tokens are left out."
- "Diagnostics could not be copied" or "The logs folder could not be opened" when the clipboard or the file manager refuses.
- "This page is not in this build of the app." when a help page is missing from the build.

# Settings: About

The **About** section of Settings shows the same view as **Help ▸ About**: the name with its line "A desktop tutor for ComfyUI graphs", the version, the author, what the app is, the license, the third-party components, a button to copy the details for a problem report, a button to open the data folder and the project links. The view is described on [About and the help reader](About-And-Help.md).

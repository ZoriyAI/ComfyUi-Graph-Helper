# The status bar

The status bar is the bottom line of the window. On the left it counts what is on the canvas; in the middle it shows a running build of the assistant; on the right, the language and the motion.

## What it shows

| Item | Example | Meaning |
|---|---|---|
| nodes | "7 nodes" | nodes in the whole graph |
| links | "9 links" | links in the whole graph |
| selection | "No selection", "2 selected" | selected nodes |
| zoom | "Zoom 60%" | the zoom of the canvas |
| version | "Revision 79" | the number of the current version of the graph; every change makes a new one. See [History and undo](../graph/History-And-Undo.md). |
| a build | "The assistant is changing the graph" with **Pause** and **Stop**; "The assistant is paused" with **Resume** and **Stop** | only while the assistant builds |
| language | "Language: English" | change it in View ▸ Language |
| motion | "Motion: System" | change it in View ▸ Motion |

When a build needs the room, the zoom and the version give way first.

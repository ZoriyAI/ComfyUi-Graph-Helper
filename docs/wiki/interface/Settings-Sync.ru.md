# Настройки: Синхронизация

«Библиотека читается из вашего ComfyUI прямо по его адресу или через MCP-сервер, только для чтения. Автосинхронизация и интервал применяются сразу; остальное сохраняет кнопка «Сохранить настройки».» Раздел показывает, как прошла последняя синхронизация, запускает новую, настраивает автоматическую и говорит, как читаются файлы моделей.

## Что он показывает

Состояние и итог: «Синхронизировано · Типов нод: 812, паков: 41, моделей: 331 (с метаданными: 120). Последняя синхронизация: 14:05.» Предупреждения последней синхронизации, приостановленное чтение («Чтение метаданных приостановлено на 120 / 331. Оно продолжится при следующей синхронизации или по кнопке «Синхронизировать сейчас».») и последнюю ошибку.

## Поля и кнопки

| Поле | По умолчанию | Что делает |
|---|---|---|
| **Синхронизировать автоматически** | выключено | Снова читает ComfyUI по таймеру. Работает и с адресом ComfyUI, и с MCP-сервером. Без адреса: «Автоматическую синхронизацию можно включить, когда в разделе «Подключение» указан адрес ComfyUI.» Если прошлая синхронизация не закончилась, автоматическая ждёт, пока вы не нажмёте **Синхронизировать сейчас**. |
| **Интервал, минуты** | 30 | От 5 минут до суток. Число вне диапазона исправляется: «Интервал может быть от 5 минут до суток, поэтому теперь он 5 мин.» |
| **Синхронизировать сейчас** | | Читает ComfyUI прямо сейчас. |
| **Приостановить чтение метаданных** | | Появляется, пока читаются файлы моделей. |
| **Откуда читать метаданные моделей** | **Папки загрузчиков (чекпойнты, LoRA, VAE…)** | или **Все папки моделей** |
| **Моделей в одной порции** | 50 (от 10 до 1000) | Метаданные читаются порциями такого размера, одна за другой, пока не будут прочитаны все файлы. |
| **Пауза между порциями, мс** | 1500 (от 0 до 10 000) | Даёт MCP-серверу и ComfyUI передохнуть. Чтение при этом не прерывается. |

При чтении прямо из ComfyUI приложение получает метаданные из заголовков файлов моделей (название, слово-триггер, базовую модель), но не файлы описаний рядом с ними и не отпечатки; их добавляет MCP-сервер, который читает файлы.

Строка внизу называет постоянный тайм-аут: один вызов MCP может длиться до 60 с. Файл, который не удалось прочитать, не останавливает синхронизацию: он попадает в список **Не удалось прочитать** и читается снова сам через 1 ч, 6 ч, затем 24 ч.

## Не удалось прочитать

Если что-то не прочиталось, под кнопками раздела появляется отчёт. Он начинается одной строкой: «Прочитано файлов моделей: 360 из 372; не прочитано: 2; пропущено: 1.» Дальше по строке на каждую вещь: что это, почему и что делать:

- файл модели с папкой, например «“style.safetensors” в папке “loras”» (в русском интерфейсе в кавычках-ёлочках);
- папка моделей, например «Папка моделей “upscale_models”»;
- часть каталога, например «Каталог: список паков».

| Почему (на экране) | Что делать (на экране) |
|---|---|
| «Сервер оборвал соединение при чтении этого файла, и на новом соединении тоже.» | Возможно, файл повреждён или его заголовок сервер не умеет читать: загрузите его один раз в ComfyUI, чтобы проверить. Остальные файлы прочитаны. |
| «Сервер потерял своё соединение для чтения файлов.» | Перезапустите MCP-сервер. |
| «Сервер ответил ошибкой: …» (короткий текст сервера, без адресов) | Ничего делать не нужно: новая попытка в указанное время. |
| «Ответ оказался слишком большим.», «Сервер не ответил вовремя.», «Чтение не прошло.» | Ничего делать не нужно: новая попытка в указанное время. |
| «ComfyUI не был запущен, когда спрашивали список.» | Запустите ComfyUI и синхронизируйте снова. |
| «Сервер не отдал этот список.» | Синхронизируйте снова. Если не пройдёт, проверьте MCP-сервер. |

У каждой строки файла есть кнопка **Повторить сейчас** (читает только этот файл сразу, не дожидаясь срока) и переключатель **Пропускать этот файл** (файл не читается и не считается неудачей, пока переключатель включён). Под списком: **Повторить все** (снимает все сроки ожидания и запускает синхронизацию) и **Скопировать отчёт** (простой текст, по строке на пункт, без адреса сервера). Длинный список показывает первые пять строк и кнопку **Показать все**.

Синхронизация, запущенная вручную, заканчивается всплывающим сообщением, если что-то не прочиталось: «Синхронизация завершена. Не удалось прочитать: 2. Смотрите список.» Кнопка **Показать список** открывает этот раздел. Синхронизация по таймеру сообщения не показывает; вместо этого предупреждение видно на [значке синхронизации](Sync-Indicator.ru.md). Карточка такой модели в библиотеке говорит «Описания нет: файл не удалось прочитать при синхронизации.» и называет причину.

Автоматическая синхронизация и интервал есть и во всплывающем окне [значка синхронизации](Sync-Indicator.ru.md), там они применяются сразу. Здесь они применяются кнопкой **Сохранить настройки**.

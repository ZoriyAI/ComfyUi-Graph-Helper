# Настройки: Синхронизация

«Библиотека берётся из вашего ComfyUI через инструменты MCP только для чтения.» Раздел показывает, как прошла последняя синхронизация, запускает новую, настраивает автоматическую и говорит, как читаются файлы моделей.

## Что он показывает

Состояние и итог: «Синхронизировано · Классов нод: 812, паков: 41, моделей: 331 (с метаданными: 120). Последняя синхронизация 14:05.» Предупреждения последней синхронизации, приостановленное чтение («Чтение метаданных приостановлено на 120 / 331. Оно продолжится при следующей синхронизации или по кнопке «Синхронизировать сейчас».») и последнюю ошибку.

## Поля и кнопки

| Поле | По умолчанию | Что делает |
|---|---|---|
| **Синхронизировать автоматически** | выключено | Снова читает ComfyUI по таймеру. Включается только при адресе MCP-сервера: «Автоматическую синхронизацию можно включить, когда в разделе «Подключение» указан адрес MCP-сервера.» |
| **Интервал, минуты** | 30 | От 5 минут до суток. Число вне диапазона исправляется: «Интервал может быть от 5 минут до суток, поэтому теперь он 5 мин.» |
| **Синхронизировать сейчас** | | Читает ComfyUI прямо сейчас. |
| **Приостановить чтение метаданных** | | Появляется, пока читаются файлы моделей. |
| **Откуда читать метаданные моделей** | **Папки загрузчиков (чекпойнты, LoRA, VAE…)** | или **Все папки моделей** |
| **Моделей в одной порции** | 50 (от 10 до 1000) | Метаданные читаются порциями такого размера, одна за другой, пока не будут прочитаны все файлы. |
| **Пауза между порциями, мс** | 1500 (от 0 до 10 000) | Даёт MCP-серверу и ComfyUI передохнуть. Чтение при этом не прерывается. |

Строка внизу называет постоянный тайм-аут: один вызов MCP может длиться до 60 с; после 5 неудачных чтений метаданных подряд чтение ждёт следующей синхронизации, а каждый неудачный файл повторяется через 1 ч, 6 ч, затем 24 ч.

Автоматическая синхронизация и интервал есть и во всплывающем окне [значка синхронизации](Sync-Indicator.ru.md), там они применяются сразу. Здесь они применяются кнопкой **Сохранить настройки**.

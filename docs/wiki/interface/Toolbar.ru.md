# Панель инструментов

Панель инструментов это строка кнопок под главным меню. На ней самые нужные команды, выбор помощника, имя проекта и кнопка настроек. Каждая кнопка запускает ту же команду, что и пункт меню.

<!-- picture: панель инструментов при 1400 пикселях, у каждой кнопки подпись -->

## Кнопки слева направо

| Кнопка | То же, что | Что делает |
|---|---|---|
| **Новый** | Файл ▸ Новый проект (`Ctrl+N`) | Пустой граф. |
| **Открыть** | Файл ▸ Открыть проект (`Ctrl+O`) | Открывает файл проекта. |
| **Сохранить** | Файл ▸ Сохранить проект (`Ctrl+S`) | Сохраняет файл проекта. |
| **Импорт** | Файл ▸ Открыть workflow… (`Ctrl+I`) | Открывает workflow из ComfyUI. |
| **Экспорт** | Файл ▸ Сохранить workflow для ComfyUI… (`Ctrl+E`) | Сохраняет workflow для ComfyUI. |
| стрелка назад | Правка ▸ Отменить (`Ctrl+Z`) | Подсказка называет изменение, например «Отменить: добавление ноды KSampler». |
| стрелка вперёд | Правка ▸ Повторить (`Ctrl+Shift+Z`) | |
| **Проверить** | Граф ▸ Проверить граф (`Ctrl+Shift+C`) | Проверяет граф. После проверки маленькое число на кнопке показывает, сколько находок (зелёный 0, янтарный больше). Программа чтения с экрана слышит число фразой («3 находки»). |
| круговые стрелки | Синхронизация ▸ Синхронизировать сейчас | Читает ваш ComfyUI прямо сейчас. |
| **Помощник: …** | Помощник ▸ Кто отвечает | См. ниже. |
| имя проекта | | Название графа. Граф без названия получает имя своего файла проекта или workflow, картинки или видео, из которых пришёл, а иначе «Проект без названия». Точка после имени значит, что граф в нынешнем виде не сохранён в файл проекта (см. [Файлы проекта](../graph/Project-Files.ru.md#отметка-несохранённых-изменений)). Заголовок окна показывает то же имя, а пока точка видна, перед ним стоит «•». |
| шестерёнка | Файл ▸ Настройки… (`Ctrl+,`) | Открывает [Настройки](Settings.ru.md). |

В узком окне кнопки показывают только значки; наведите на кнопку, чтобы увидеть её название и сочетание клавиш.

## Выбор помощника

На кнопке написано «Помощник: не выбран», «Помощник: OpenAI» или «Помощник: Свой сервер · qwen3:8b» (провайдер и короткое имя модели: хаб, автор загрузки, GGUF и квантование опущены; полное имя видно в настройках). Точка на значке показывает, где сейчас ключ.

1. Щёлкните кнопку. Откроется список. Его первая строка говорит, где ключ, например «Ключ OpenAI действует до закрытия приложения. На диск он не записан.»
2. Выберите **Не выбран**, **OpenAI**, **Anthropic**, **Google Gemini**, **Совместимый с OpenAI** или **Свой сервер**. Выбор сохраняется сразу и совпадает с выбором в «Настройки ▸ Помощник».
3. **Настроить…** внизу открывает [Настройки ▸ Помощник](Settings-Assistant.ru.md).

Если выбрать **Свой сервер**, пока у него нет адреса, откроются настройки, чтобы вы указали адрес и модель.

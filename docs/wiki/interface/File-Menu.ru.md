# Меню «Файл»

Меню **Файл** работает с файлами: с файлом проекта этого приложения (`.nodewise.json`, граф вместе с объяснениями) и с файлом workflow для ComfyUI (`.json`, только граф). Ещё оно открывает картинки и видео, сохранённые ComfyUI, недавние файлы и примеры, работает с файлами уроков, открывает настройки и закрывает приложение. Файл, перетащенный в окно, открывается так же, как через **Открыть workflow…**.

## Пункты

| Пункт | Сочетание | Что делает |
|---|---|---|
| **Новый проект** | `Ctrl+N` | Начинает пустой граф. Если граф на холсте в нынешнем виде не сохранён в файл проекта, приложение сначала спросит. См. [Новый проект](../graph/New-Project.ru.md). |
| **Открыть проект** | `Ctrl+O` | Открывает файл проекта этого приложения. Объяснения и заметки возвращаются вместе с графом. См. [Файлы проекта](../graph/Project-Files.ru.md). |
| **Недавние файлы** | нет | Последние 10 файлов, которые вы открывали или сохраняли. Наведите на файл, чтобы увидеть его путь. Пока список пуст, там «Пока ничего не открывали». |
| **Примеры** | нет | Готовый граф каждого урока, который может собрать ваш ComfyUI, под названием урока. Пусто, пока ComfyUI не прочитан. См. [Открыть workflow](../graph/Opening-Workflows.ru.md#примеры). |
| **Сохранить проект** | `Ctrl+S` | Сохраняет граф с объяснениями. В первый раз приложение спросит, куда; потом пишет в тот же файл без вопросов. |
| **Сохранить проект как…** | `Ctrl+Shift+S` | Всегда спрашивает место и имя. |
| **Открыть workflow…** | `Ctrl+I` | Открывает workflow, сохранённый в ComfyUI (файл `.json`), workflow в формате API или картинку или видео, сохранённые ComfyUI. См. [Открыть workflow](../graph/Opening-Workflows.ru.md). |
| **Сохранить workflow для ComfyUI…** | `Ctrl+E` | Проверяет граф, потом сохраняет чистый workflow для ComfyUI и показывает карточку **Запустите в ComfyUI**. Объяснения и заметки остаются в проекте. См. [Сохранить workflow для ComfyUI](../graph/Saving-Workflows.ru.md). |
| **Загрузить список нод из файла…** | нет | Запасной путь, если подключения нет: читает ноды и модели из файла `object_info`, сохранённого из ComfyUI. См. [Список нод из файла](../connect/What-Each-Way-Shows.ru.md). |
| **Импорт уроков…** | нет | Добавляет уроки из файла `.lesson.json` в **Мои уроки**. См. [Вкладка «Уроки»](Lessons-Panel.ru.md). |
| **Сделать урок из этого графа** | нет | Открывает редактор урока с шагом на каждую ноду графа. См. [Вкладка «Уроки»](Lessons-Panel.ru.md). |
| **Настройки…** | `Ctrl+,` | Открывает [Настройки](Settings.ru.md). |
| **Выход** | `Ctrl+Q` | Закрывает приложение. Граф на холсте сохраняется и вернётся при следующем запуске. |

На Mac вместо `Ctrl` нажимают `Cmd`. Новый проект, Открыть проект и Открыть workflow сначала спрашивают, если помощник ещё строит: «Помощник ещё строит. Остановить?»

## Что говорит приложение

- «Проект сохранён.», «Проект открыт.», «Workflow сохранён для ComfyUI.» появляются справа внизу после записи или чтения файла.
- Если поле похоже на ключ или токен, приложение спрашивает до записи файла: «1 поле похоже на ключ или токен». См. [Сообщения и диалоги](Messages-And-Dialogs.ru.md).
- Если файл не открывается, сообщение говорит почему, например «Этот файл не проект NodeWise Studio.» или «В этом файле нет workflow. ComfyUI записывает его в картинки и видео, которые сохраняет сам; в картинке из другого места или пересланной через мессенджер его обычно нет.»

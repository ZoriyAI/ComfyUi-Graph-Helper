# Настройки: Службы

Откройте **Настройки → Службы**, чтобы запускать, останавливать, перезапускать и наблюдать поддерживаемые службы Linux на компьютере с NodeWise. Его имя показано сверху. Подключённый телефон управляет этим же компьютером.

Приложение автоматически находит установленные и загруженные службы systemd с именами ComfyUI, ComfyUI MCP, Ollama, llama-server, llama-cpp и LM Studio. В каждой строке показаны точное имя, принадлежность вашей учётной записи или системе, состояние процесса и RAM по данным systemd. Несколько служб Ollama отображаются отдельно. Если система не сообщает память, показано «система не сообщает»; это не измерение VRAM.

**Запустить** запускает службу. **Остановить** и **Перезапустить** сначала объясняют, что работа других приложений может прерваться. Действия выполняются сразу. Приложение повторно читает состояние и сообщает об успехе только после подтверждения. Пока раздел открыт, список обновляется каждые десять секунд.

Для системной службы Linux может запросить разрешение администратора в своём окне на компьютере. NodeWise не получает пароль и не устанавливает правила доступа. При отмене окна приложение сообщает об отказе авторизации. Телефон не может ответить на системное окно компьютера.

Работающий процесс ещё может загружать HTTP API. Кнопка **Настройки подключения** открывает проверку ComfyUI/MCP, после которой можно синхронизироваться. **Помощник и модели** открывает настройку контекста и загрузку/выгрузку моделей. Из окна проблем синхронизации также можно перейти к службам.

Раздел не управляет другим сервером по адресу чата, не устанавливает службы, не меняет их файлы и не управляет контейнерами или программами, запущенными напрямую. Поддерживаются существующие перечисленные службы Linux systemd. Произвольные команды и имена служб не принимаются. Помощник не может вызывать эти действия.

См. также: [Синхронизация](Settings-Sync.ru.md), [Помощник](Settings-Assistant.ru.md).

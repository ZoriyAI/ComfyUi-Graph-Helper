# Меню «Помощник»

Меню **Помощник** нужно, чтобы написать помощнику, открыть уроки, управлять идущей сборкой и выбрать, кто отвечает.

## Пункты

| Пункт | Сочетание | Что делает | Серый, когда |
|---|---|---|---|
| **Написать помощнику** | `Ctrl+/` | Открывает вкладку **Помощник** и ставит курсор в поле сообщения. | никогда |
| **Спросить о выделенном** | нет | Спрашивает помощника, для чего выделенная нода (для блока-субграфа: что делает субграф). | нода не выделена или идёт просмотр истории |
| **Уроки: собрать самому** | нет | Открывает вкладку **Помощник** в режиме **Учиться** со списком уроков. См. [Учиться](../assistant/Learn.ru.md). | никогда |
| **Приостановить помощника** | нет | Ставит помощника на паузу, пока он отвечает или строит. | помощник не работает |
| **Продолжить работу помощника** | нет | Продолжает сборку после паузы. | ни одна сборка не на паузе |
| **Остановить помощника** | нет | Завершает сборку. Что он успел добавить, остаётся на холсте. | сборка не идёт |
| **Кто отвечает** ▸ **Не выбран** / **OpenAI** / **Anthropic** / **Google Gemini** / **Свой сервер** | нет | Выбирает модель, которая отвечает. Это тот же выбор, что на панели сверху и в «Настройки ▸ Помощник»; он сохраняется сразу. | никогда |
| **Настройки помощника…** | нет | Открывает [Настройки ▸ Помощник](Settings-Assistant.ru.md). | никогда |

В сборке приложения для разработчиков в списке **Кто отвечает** есть ещё **Проверочный режим TEST**: заготовленные ответы для тестов, а не живая модель. Установленное приложение его не предлагает.

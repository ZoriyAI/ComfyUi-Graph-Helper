# Меню «Граф»

Меню **Граф** меняет и объясняет граф: добавление нод, раскладка, субграфы и группы, обход, выключение и цвета, нода на связи, замена ноды, заметки, проверка, ошибка ComfyUI, предложения помощника, экскурсия и история.

## Пункты

| Пункт | Сочетание | Что делает | Серый, когда |
|---|---|---|---|
| **Добавить ноду…** | `Ctrl+K` | Открывает поиск нод посреди холста. См. [Добавление нод](../graph/Adding-Nodes.ru.md). | идёт просмотр истории |
| **Разложить граф** | `Ctrl+Shift+L` | Раскладывает граф слева направо, чтобы ноды не наезжали друг на друга. Если выделено две ноды или больше, только их. Одна отмена возвращает всё как было. См. [Раскладка графа](../graph/Arranging.ru.md). | на уровне нет нод или идёт просмотр истории |
| **Собрать субграф из выделенного** | `Ctrl+G` | Сворачивает выделенные ноды в один блок-субграф. См. [Субграфы](../graph/Subgraphs.ru.md). | ничего не выделено или идёт просмотр истории |
| **Разобрать субграф** | нет | Возвращает ноды выделенного субграфа на холст. | выделен не ровно один блок-субграф |
| **Собрать группу из выделенного** | `Ctrl+Shift+G` | Рисует рамку с названием вокруг выделенных нод. См. [Группы](../graph/Groups.ru.md). | ничего не выделено или идёт просмотр истории |
| **Обойти** | `Ctrl+Shift+B` | ComfyUI пропускает выбранные ноды: то, что приходит на вход ноды, сразу идёт на её выход того же типа. Галочка видна, когда все выбранные ноды в обходе; повторный выбор снова включает их. Заметки пропускаются. См. [Нода на холсте](Node.ru.md#обход-и-выключение). | идёт просмотр истории |
| **Выключить** | `Ctrl+M` | ComfyUI совсем не выполняет выбранные ноды; ноды, которым нужен их результат, ничего не получат. Переключается так же. | идёт просмотр истории |
| **Цвет** ▸ **Красный** / **Коричневый** / **Зелёный** / **Синий** / **Голубой** / **Бирюзовый** / **Фиолетовый** / **Жёлтый** / **Чёрный** / **Без цвета** | нет | Красит выбранные ноды цветом из палитры ComfyUI, поэтому ComfyUI тоже покажет этот цвет. | идёт просмотр истории |
| **Вставить ноду…** | нет | Ставит ноду на одну выделенную связь. См. [Добавление нод](../graph/Adding-Nodes.ru.md#поставить-ноду-на-связь). | идёт просмотр истории |
| **Заменить на…** | нет | Ставит другую ноду на место одной выделенной, сохраняя подходящие связи и значения. | идёт просмотр истории |
| **Добавить заметку** | нет | Ставит на холст заметку для себя и для всех, кто откроет workflow в ComfyUI. | идёт просмотр истории |
| **Проверить граф** | `Ctrl+Shift+C` | Открывает вкладку **Проверка** и сверяет граф с вашим ComfyUI. Работает всегда, даже из текстового поля. См. [Проверка графа](../graph/Checking-A-Graph.ru.md). | никогда |
| **Разобрать ошибку ComfyUI…** | нет | Открывает карточку, куда вставляют ошибку из ComfyUI. См. [Ошибка в ComfyUI](../graph/ComfyUI-Errors.ru.md). Тот же пункт есть в меню «Справка». | никогда |
| **Принять все предложения** | нет | Принимает все серые черновики помощника, одно за другим. См. [Серые черновики](../assistant/Drafts.ru.md). | открытых предложений нет |
| **Отклонить все предложения** | нет | Отклоняет все серые черновики сразу. | открытых предложений нет |
| **Экскурсия по графу** | нет | Начинает или заканчивает [экскурсию по графу](../graph/Tour.ru.md). Галочка значит, что экскурсия идёт. | граф пуст или идёт просмотр истории |
| **Просмотр истории** | нет | Показывает прежние версии графа, только для просмотра. Галочка значит, что просмотр идёт. См. [История и отмена](../graph/History-And-Undo.ru.md). | никогда |

## Полезно знать

- Создание и разбор субграфа, а также группировка нод работают на текущем уровне, включая содержимое субграфа.
- Для «Обойти», «Выключить», «Цвет» и «Заменить на…» нужна хотя бы одна выделенная нода, для «Вставить ноду…» одна выделенная связь. Иначе приложение скажет «Сначала выделите одну или несколько нод.», «Сначала выделите одну связь.» или «Сначала выделите одну ноду.»
- `Ctrl+B` это не «Обойти»: это сочетание открывает и сворачивает библиотеку.
- Во время просмотра истории холст только для чтения, поэтому все пункты, которые меняют граф, серые. Выйти из просмотра: `Escape` или снова **Просмотр истории**.

# О программе и справка

**Справка ▸ О программе** открывает маленькое окно о приложении. **Справка ▸ Руководство**, **Решение проблем** и **Что нового** открывают окно справки, которое показывает страницу помощи внутри приложения.

## Окно «О программе»

- Название, «Версия 0.8.0» и абзац: «Учебный помощник для ComfyUI: читает, какие ноды и модели у вас есть, и помогает собрать и понять граф. В самом ComfyUI он ничего не меняет.»
- **Лицензия** показывает лицензию приложения (MIT). **Назад** возвращает.
- **Сторонние компоненты**: пакеты, которые поставляются с приложением; выберите пакет, чтобы прочитать его лицензию. **Лицензии Chromium** открывает лицензии движка браузера внутри Electron.
- **Скопировать сведения** копирует версию, среду и систему для сообщения об ошибке: «Сведения скопированы. Вставьте их в сообщение об ошибке.»
- **Открыть папку с данными** открывает папку, где приложение хранит свои данные.
- **Подробно** раскрывает среду («Среда: Electron … · Chromium … · Node …»), систему и путь к папке с данными.
- **Закрыть**.

То же самое есть в [Настройки ▸ О программе](Settings-About.ru.md).

## Окно справки

Окно со страницей на языке интерфейса и кнопкой **Закрыть**. Пока страница грузится: «Открываю…». **Что нового** написано только по-русски. Если страницы нет в этой сборке: «Этой страницы нет в этой сборке приложения.»

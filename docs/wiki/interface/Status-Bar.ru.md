# Строка состояния

Строка состояния это нижняя строка окна. Слева она считает, что лежит на холсте; дальше показывает идущую сборку помощника и, если есть, сообщение о новой версии.

## Что она показывает

| Элемент | Пример | Значение |
|---|---|---|
| ноды | «7 нод» | ноды во всём графе |
| связи | «9 связей» | связи во всём графе |
| выделение | «Нет выбора», «2 выбрано» | выделенные ноды |
| масштаб | «Масштаб 60%» | масштаб холста |
| версия | «Версия 79» | номер текущей версии графа; каждое изменение создаёт новую. См. [История и отмена](../graph/History-And-Undo.ru.md). |
| сборка | «Помощник меняет граф» с кнопками **Пауза** и **Остановить**; «Помощник на паузе» с **Продолжить** и **Остановить** | только пока помощник строит |
| новая версия | «Есть версия …» с кнопками **Что нового**, **Скачать** и **Скрыть до следующей версии** | только когда в [Настройки ▸ Приватность](Settings-Privacy.ru.md) включено **Проверять новые версии** и есть версия новее |

Язык и анимацию строка больше не показывает: они в меню «Вид» и в [Настройки ▸ Оформление и анимация](Settings-Appearance.ru.md). С клавиатуры до строки состояния доходит `F6`.

Если сборке не хватает места, первыми уступают масштаб и версия.

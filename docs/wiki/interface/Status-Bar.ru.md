# Строка состояния

Строка состояния это нижняя строка окна. Слева она считает, что лежит на холсте; посередине показывает идущую сборку помощника; справа язык и анимацию.

## Что она показывает

| Элемент | Пример | Значение |
|---|---|---|
| ноды | «7 нод» | ноды во всём графе |
| связи | «9 связей» | связи во всём графе |
| выделение | «Нет выбора», «2 выбрано» | выделенные ноды |
| масштаб | «Масштаб 60%» | масштаб холста |
| версия | «Версия графа 79» | номер текущей версии графа; каждое изменение создаёт новую. См. [История и отмена](../graph/History-And-Undo.ru.md). |
| сборка | «Помощник меняет граф» с кнопками **Пауза** и **Остановить**; «Помощник на паузе» с **Продолжить** и **Остановить** | только пока помощник строит |
| язык | «Язык: Русский» | меняется в «Вид ▸ Язык» |
| анимация | «Анимация: Системная» | меняется в «Вид ▸ Анимация» |

Если сборке не хватает места, первыми уступают масштаб и версия.

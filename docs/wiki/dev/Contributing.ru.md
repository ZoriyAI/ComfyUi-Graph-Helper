# Как участвовать

Полное руководство лежит в корне проекта: `CONTRIBUTING.ru.md`. Коротко:

1. **Сначала договоритесь** о большом изменении: обсуждение или обращение, чтобы идею согласовали до работы.
2. **Подготовьтесь** как в [Сборке из исходников](Building-From-Source.ru.md). Запуск для разработки берёт ту же
   папку с данными, что и установленное приложение; передайте `--user-data-dir`, чтобы держать проверочный профиль
   отдельно.
3. **Держите обещания**: ComfyUI только читается ([Чтение ComfyUI](Reading-ComfyUI.ru.md)); ключи никогда не попадают
   в окно, журнал или файл ([Безопасность](../trust/Security.ru.md)); каждый вызов IPC проверяется
   ([IPC](IPC.ru.md)).
4. **Тексты на двух языках**: каждый новый текст по-английски и по-русски ([Тексты и языки](Texts-And-Languages.ru.md));
   у изменения, которое видит человек, есть страница вики на обоих языках
   ([Как писать страницы справки](Wiki-Style.ru.md)).
5. **Проверьте** перед запросом на слияние:

   ```bash
   npm run type-check
   npm test
   npm run build
   xvfb-run -a npx playwright test tests/e2e/<файл>.test.ts --trace off   # файлы, которые задевает изменение
   node scripts/changelog.js --check
   node scripts/public-tree-check.js
   ```

   [Тесты](Testing.ru.md) говорят, что проверяет каждый вид тестов.
6. **Запрос на слияние** следует шаблону: что и зачем, как проверено.

Отправляя вклад, вы соглашаетесь, что он публикуется под лицензией проекта (MIT с условием Commons Clause). Все
участники следуют правилам поведения (`CODE_OF_CONDUCT.ru.md`).

# Как участвовать

NodeWise Studio принимает идеи, отчёты и проверки от всех, а код пишет один человек: автор. Здесь сказано, как
участвовать и почему pull request (запросы на слияние) с кодом не принимаются. То же подробнее:
[CONTRIBUTING.ru.md](../../../CONTRIBUTING.ru.md) в корне проекта.

## Как принять участие

- **Проверьте скрипты установки.** Скрипты для Windows и macOS ещё не пробовали на настоящих компьютерах
  ([Установка на Windows](../start/Installing-On-Windows.ru.md), [Установка на macOS](../start/Installing-On-macOS.ru.md)).
  Откройте обращение по форме «Test report: Windows or macOS install»: версия системы, какой скрипт, что произошло,
  код завершения и файл журнала, который скрипт называет в конце.
- **Сообщите о проблеме** в обращениях проекта. «Справка ▸ Сообщить о проблеме…» впишет версии.
- **Идеи, пожелания и вопросы** несите в обсуждения проекта.
- **Ошибка в документации:** откройте обращение, назовите страницу, приведите предложение и скажите, как должно быть.
  Исправит автор.
- **Свой урок:** приложите его файл `.lesson.json` к обсуждению. Урок остаётся вашим, другие его импортируют
  ([Формат файла урока](../lessons/Lesson-File-Format.ru.md)).
- **Проблема безопасности:** закрыто, как сказано на странице
  [Безопасность](../trust/Security.ru.md#как-сообщить-об-уязвимости).

## Почему код не принимается

Автор держит авторские права на весь проект в одних руках, чтобы его лицензия и будущее оставались ясными. Для правки,
написанной кем-то другим, понадобилось бы письменное соглашение о правах на неё, а таких соглашений проект не ведёт.

Pull request, который всё же пришёл, закрывают с благодарностью и просят описать идею в обращении. Автор может сделать
эту идею сам. Публикуя идею, пожелание или отчёт в обращениях или обсуждениях, вы соглашаетесь, что автор может
свободно их использовать, и не претендуете на права, оплату или упоминание за результат. Это простое описание того, как
устроен проект, а не юридическая консультация.

## Читать и собирать код для себя

Лицензия (MIT с условием Commons Clause) разрешает читать, собирать и менять свою копию, пока её не продают. Страницы
этого раздела написаны для этого:

- [Сборка из исходников](Building-From-Source.ru.md): подготовка, сборка, запуск; запуск для разработки берёт свой
  профиль с `--user-data-dir`.
- [Тесты](Testing.ru.md): проверки и что проверяет каждый вид тестов.
- [Устройство приложения](Architecture.ru.md) и [Карта кода](Code-Map.ru.md): с чего начать чтение.

Правила, которые соблюдают изменения самого автора, полезно знать, когда меняете свою копию: ComfyUI только читается
([Чтение ComfyUI](Reading-ComfyUI.ru.md)); ключи никогда не попадают в окно, журнал или файл
([Безопасность](../trust/Security.ru.md)); каждый вызов IPC проверяется ([IPC](IPC.ru.md)); каждый текст есть
по-английски и по-русски ([Тексты и языки](Texts-And-Languages.ru.md)).

Все участники следуют правилам поведения (`CODE_OF_CONDUCT.ru.md`).

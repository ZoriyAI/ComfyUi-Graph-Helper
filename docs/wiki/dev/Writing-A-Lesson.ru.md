# Как написать урок

Урок это список шагов, и каждый описан как **то, что должно быть на холсте** после него. Приложение читает холст,
чтобы понять, где человек, поэтому урок не хранит своего состояния: удалите ноду, и урок вернётся к её шагу. Как уроки
выглядят для человека: [Как устроены уроки](../lessons/How-Lessons-Work.ru.md).

## Где что лежит

| Что | Где |
| --- | --- |
| Шаги | `src/shared/lessons/lessons.ts` (и `src/shared/lessons/sets/` для групп уроков, например о семействах моделей для картинок). |
| Слова | `src/shared/lessons/texts.en.ts`, `texts.ru.ts` (и `sets/*.texts.*.ts`) под теми же id урока и шагов. |
| Проверка холста | `src/shared/lessons/engine.ts`, `fit.ts` (есть ли в этом ComfyUI всё нужное уроку), `flow.ts`. |
| Панель | `src/renderer/components/lessons/LessonPanel.tsx`. |
| Страница вики | `docs/wiki/lessons/<Имя>.md` и `.ru.md` с комментарием `<!-- lesson: <id> -->`. |

## Шаг

```ts
{ id: 'model', roles: [node('checkpoint', 'CheckpointLoaderSimple')], fields: [field('checkpoint', 'ckpt_name', chosen)] }
```

- `read: true`: шаг, который только объясняет; человек читает его и идёт дальше. Кладите знания сюда, а шаги с делом
  делайте короткими.
- `roles`: ноды, которые должны быть на холсте, у каждой имя роли и классы, которые подходят.
- `links`: `link(from, output, to, input, via?)`; `via` перечисляет ноды, которые могут стоять между (загрузчик LoRA).
- `fields`: `field(role, name, test)`. Проверки (`FieldTest` в `src/shared/lessons/engine.ts`): `chosen`, `equals`,
  `between` (с `prefer`, значением, которое ставит «Сделать за меня»), `text` (минимальная длина, обязательные
  метки), `weighted` (вес в описании в пределах), `has-trigger` (слова-триггеры выбранной LoRA) и `differs` (не тот же
  файл, что в другом загрузчике).

Берите собственные имена классов и портов ComfyUI. Урок предлагается, только если в ComfyUI человека есть каждый
названный им класс с названными входами, поэтому ComfyUI, где нода устроена иначе, получает «урок не подходит», а не
неверные указания.

## Слова

Для каждого урока: `title`, `result` (одна строка: что получится у человека) и для каждого id шага короткий `title` и
`body` (простой markdown: абзацы, список, `code`). Пишите `{role}`, чтобы назвать ноду урока: приложение подставит
имя ноды так, как его показывает библиотека этого ComfyUI. Простые слова, сначала действие, пункт меню называется
так, как его называет меню.

## Порядок

- `LESSONS` задаёт порядок, в котором человек их встречает.
- `LESSON_AFTER` говорит, на графе какого урока стоит урок (показывается в списке, но не навязывается).

## Тесты

- `tests/unit/lessons.test.ts` проходит каждый урок от пустого холста до конца, делая то, что он говорит, проверяет,
  что каждый объясняющий шаг показан один раз и что место в уроке читается по графу (удалённая нода возвращает
  назад).
- `tests/unit/lessonFit.test.ts` проверяет, когда урок подходит к ComfyUI, а когда нет.
- `tests/unit/wiki.test.ts` проверяет, что у каждого id урока есть страница вики с пометкой `<!-- lesson: <id> -->`
  на обоих языках.
- `tests/e2e/lessons.test.ts` проходит урок в окне.

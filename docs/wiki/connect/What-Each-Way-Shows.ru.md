# Что даёт каждый способ

| Данные | Напрямую из ComfyUI | Необязательный MCP |
|---|---|---|
| Классы нод, входы, выходы, значения по умолчанию | `/object_info` | Если сервер даёт каталог нод; иначе их можно прочитать напрямую |
| Имена файлов моделей | Маршруты моделей ComfyUI | Если сервер перечисляет папки моделей |
| Размеры, заголовки safetensors, превью | Если их отдаёт эта версия ComfyUI | Зависит от инструментов чтения сервера |
| Sidecar-описания моделей и примеры | Недоступны | Сервер с подходящими инструментами чтения файлов |
| README паков и отпечатки файлов | Недоступны | Сервер с подходящими инструментами чтения файлов |

Старый ComfyUI может отдавать только имена, без размеров и превью. Отсутствующие сведения остаются неизвестными; успешное подключение не доказывает, что прочитаны все источники. Индикатор синхронизации показывает пробелы и адрес источника библиотеки.

Проверка графа сверяет его с этим каталогом. Она не запускает workflow, не проверяет качество, не определяет нужную видеопамять и не доказывает совместимость при неизвестных метаданных.

# Проблемы с подключением

Каждое сообщение о подключении, его причина и что делать. Они появляются под адресом в «Настройки ▸ Подключение», во
всплывающем окне индикатора синхронизации и в уведомлениях.

Прямое чтение каталога и переход на него при недоступном MCP проверены на настоящей установке ComfyUI 0.45.3 17 ноября 2026 года. Остальные ошибки проверяются тестовыми серверами; это не подтверждение всех серверов и способов входа.

Если MCP требует вход или недоступен, а адрес ComfyUI сохранён, синхронизация читает его напрямую. В отчёте остаются предупреждение о MCP и причина. Обновлённой библиотекой можно пользоваться, а доступ к MCP восстановить отдельно в **Настройки → Подключение**. Данные входа MCP не передаются ComfyUI. Если оба источника недоступны, отчёт объясняет ошибки и сохраняет прежнюю библиотеку.

## Адрес ComfyUI

| Сообщение начинается так | Причина | Что делать |
| --- | --- | --- |
| «Сначала введите адрес ComfyUI…» | Адреса нет. | Впишите его или нажмите «Найти на этом компьютере». |
| «Адрес не указан…» | Не сохранён ни адрес ComfyUI, ни адрес MCP. | Впишите адрес ComfyUI в «Настройки ▸ Подключение». |
| «Это не адрес…» | Текст не похож на адрес. | Скопируйте его из адресной строки браузера, когда ComfyUI открыт. |
| «Добавьте в начало адреса http:// или https://…» | Адрес другого компьютера без схемы. | Допишите `http://` в начало. |
| «Адрес должен начинаться с http:// или https://…» | Опечатка в схеме. | Исправьте первые буквы. |
| «Уберите из адреса имя и пароль.» | В адресе `user:password@`. | Уберите: пароля у ComfyUI нет. |
| «В адресе опечатка: … не может быть адресом компьютера.» | Например, `127.0.0.l` или `192.168.1`. | Проверьте цифры и буквы. |
| «ComfyUI не отвечает по адресу …» | ComfyUI не запущен, порт неверный или (другой компьютер) он запущен без `--listen`. | Запустите ComfyUI; проверьте порт; см. [ComfyUI на другом компьютере](Another-Computer.ru.md). |
| «Компьютер с именем … не найден.» | Имя не находится в сети. | Напишите адрес цифрами. |
| «ComfyUI отвечает слишком долго…» | Нет ответа вовремя (20 с для проверки, 180 с для списка нод); ComfyUI может быть занят генерацией. | Попробуйте через минуту. |
| «Это адрес MCP-сервера, а не ComfyUI…» | Адрес кончается на `/mcp` или `/sse`. | Перенесите его в поле MCP-сервера; здесь нужен адрес самого ComfyUI. |
| «По этому адресу что-то отвечает, но это не ComfyUI…» | Неверный порт или другая программа. | Обычно ComfyUI работает на 8188, настольное приложение на 8000. |
| «ComfyUI ответил, но список нод прочитать не удалось…» | ComfyUI ещё запускается. | Дождитесь запуска и попробуйте снова. |
| «Адрес отправляет приложение на другую страницу…» | Перенаправление, например прокси со страницей входа. | Укажите адрес самого ComfyUI. |
| «Файл со списком нод слишком большой.» | Список нод больше 512 МБ. | Сообщите в обращениях (Issues). |

## Предупреждения после чтения

Они не останавливают чтение; остальная библиотека обновляется.

| Сообщение начинается так | Причина |
| --- | --- |
| «ComfyUI не перечислил папки моделей…» | Папки моделей не прочитались; список моделей не обновлён. |
| «Это старый ComfyUI: он сообщает только имена моделей…» | Старый ComfyUI: имена без размеров и картинок. Обновите ComfyUI, чтобы их видеть. |
| «Папку моделей … прочитать не удалось…» | Одна папка не прочиталась; в библиотеке остался её прежний список. Синхронизируйте снова. |

## MCP-сервер

| Сообщение начинается так | Причина | Что делать |
| --- | --- | --- |
| «Это адрес самого ComfyUI…» | Адрес ComfyUI в поле MCP. | Перенесите его в поле «Адрес ComfyUI». |
| «По этому адресу что-то отвечает, но MCP-сервера здесь нет…» | Неверный путь. | Адрес MCP обычно кончается на `/mcp`. |
| «По этому адресу что-то отвечает, но это не MCP-сервер…» | Неверный порт или путь. | Скопируйте адрес, который сервер показывает при запуске. |
| «Адрес MCP-сервера должен использовать https…» | Обычный `http` к другому компьютеру. | Используйте `https` или запустите сервер на этом компьютере. |
| «MCP-сервер требует входа…» | Серверу нужен доступ. | Выберите «Токен» или «Вход через браузер». |
| «MCP-сервер не принял токен…» | Токен неверный или истёк. | Вставьте токен заново. |
| «MCP-сервер недоступен: …» | Сервер не запущен или адрес неверный. | Запустите его; проверьте адрес. |
| «MCP-сервер отвечает, но приложение не знает его инструментов…» | Незнакомый сервер и нет адреса ComfyUI. | Впишите адрес ComfyUI: тогда всё прочитается из ComfyUI. |
| «Приложение не знает инструментов этого MCP-сервера, поэтому всё прочитано прямо из ComfyUI.» | Незнакомый сервер, адрес ComfyUI есть. | Ничего; или уберите адрес MCP. |
| «Модели прочитаны через MCP-сервер, а ноды нет: этот сервер их не перечисляет…» | Сервер со списком моделей без адреса ComfyUI. | Впишите адрес ComfyUI. |
| «Модели прочитаны через MCP-сервер, а ноды нет: ComfyUI не ответил…» | Сервер со списком моделей, а ComfyUI не ответил. | См. сообщения об адресе ComfyUI выше. |
| «Инструмент MCP … не входит в список только для чтения, поэтому он не вызван.» | Приложение отказалось от вызова, который не читает. | Ничего делать не нужно. |

## Файлы моделей не прочитались

| Сообщение начинается так | Причина | Что делать |
| --- | --- | --- |
| «Чтение файлов моделей остановлено: MCP-сервер потерял соединение для их чтения…» | Сервер потерял соединение, через которое читает файлы моделей, и новое соединение не помогло. Часто его обрывает один повреждённый файл: он назван в Настройки ▸ Синхронизация ▸ **Не удалось прочитать**. | Перезапустите MCP-сервер. Проверьте названный файл (загрузите его один раз в ComfyUI). Остальные файлы прочитаются при следующей синхронизации. |
| «Не удалось прочитать описания моделей: соединение с MCP-сервером оборвалось…» | Не прочиталось ничего, и в библиотеке нет ни одной модели, прочитанной раньше. | Перезапустите MCP-сервер и синхронизируйте снова. |
| «Не удалось прочитать описания моделей: MCP-сервер ответил ошибкой на каждый файл.» | Инструмент метаданных сервера не работает ни для одного файла. | Причины видны в Настройки ▸ Синхронизация ▸ **Не удалось прочитать**. |

Файл, который не удалось прочитать, никогда не останавливает синхронизацию: она пропускает его, читает остальное и заканчивается успешно, с отчётом в разделе [Настройки: Синхронизация](../interface/Settings-Sync.ru.md). Если сервер отвечает на список «пока недоступно, повторите» (например, пока ComfyUI запускается), приложение ждёт столько, сколько просит сервер, и пробует ещё дважды, прежде чем назвать этот список в отчёте.

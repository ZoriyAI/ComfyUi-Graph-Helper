# MCP-серверы

MCP-сервер это небольшая программа рядом с ComfyUI, которая отвечает на вопросы других программ. CozyGraph он не
нужен: адреса ComfyUI достаточно. Сервер, который умеет читать файлы, добавляет то, чего сам ComfyUI не отдаёт:
описания, которые менеджеры моделей кладут рядом с файлами моделей (`.civitai.info`, `.metadata.json`), README и
`pyproject.toml` паков нод и отпечаток файла (для точного поиска на Civitai).

## Как добавить

1. «Настройки ▸ Подключение ▸ **MCP-сервер (необязательно)** ▸ **Адрес MCP-сервера**»: вставьте адрес так, как его
   показывает сервер, например `http://127.0.0.1:9000/mcp`. Адрес на другом компьютере должен быть `https`.
2. **«Проверить»**. Строка под полем называет вид сервера (ниже).
3. Если серверу нужен доступ, выберите **«Токен доступа»** (вставьте токен) или **«Войти через браузер»**; серверу,
   которому ничего не нужно: **«Без входа»**. Токен или вход относятся только к этому адресу MCP.
4. **«Сохранить настройки»**, затем **«Прочитать сейчас»**.

## Какие виды знает приложение

Приложение узнаёт сервер по списку его инструментов и вызывает только известные ему инструменты чтения с постоянными
аргументами.

| Вид | Строка под полем | Что он добавляет |
| --- | --- | --- |
| Весь каталог | «Этот MCP-сервер даёт весь каталог: ноды, паки, модели, описания и отпечатки.» | Всё: ноды, паки, модели, файлы рядом с моделями, README паков, отпечатки. |
| Список моделей (например, artokun/comfyui-mcp) | «Этот MCP-сервер перечисляет только модели. Ноды приложение берёт по адресу ComfyUI выше.» | Файлы моделей с размерами. Ноды берутся из ComfyUI. |
| Список чекпойнтов (например, joenorton/comfyui-mcp-server) | «Этот MCP-сервер перечисляет только чекпойнты. Всё остальное приложение берёт по адресу ComfyUI выше.» | Папку чекпойнтов. |
| Незнакомый | «Приложение не знает инструментов этого MCP-сервера и ничего через него не читает. Адреса ComfyUI выше достаточно.» | Ничего; показывается красным и никогда как подключённый. |

После чтения всплывающее окно индикатора синхронизации говорит, откуда взята библиотека, например что модели
прочитаны через MCP-сервер, а ноды из ComfyUI.

Официальный `comfy-mcp` от Comfy Org запускается как локальная команда, а не по адресу, и подключить его пока нельзя.

## Безопасность

- Вызываются только инструменты чтения из списка приложения; инструмент не из списка или вызов с лишним аргументом
  отклоняется, не выйдя из приложения. [ComfyUI только читается](../trust/Read-Only.ru.md)
- Адрес ComfyUI, который называет сервер, читается, только если сервер тоже на этом компьютере или это сохранённый
  вами адрес.

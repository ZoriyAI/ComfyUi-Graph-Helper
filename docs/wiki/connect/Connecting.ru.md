# Подключение к ComfyUI

Начните с адреса, который открывает ComfyUI в браузере. MCP-сервер не требуется.

1. Откройте «Настройки ▸ Подключение» и введите адрес ComfyUI со схемой и портом, например `http://127.0.0.1:8188`. ComfyUI Desktop обычно использует порт 8000. Это примеры; укажите свой адрес.
2. «Найти на этом компьютере» ищет распространённые локальные адреса. «Проверить» проверяет введённый адрес, ничего не ставя в очередь.
3. Сохраните настройки, затем выберите «Прочитать ComfyUI» или «Синхронизация ▸ Синхронизировать сейчас». Прочитайте результат и предупреждения индикатора синхронизации.

Для другого компьютера используйте его доступный адрес, а не `127.0.0.1` (он всегда означает компьютер, на котором работает это приложение). Прямое чтение использует HTTP(S) origin; адрес с перенаправлением на страницу входа в браузере не подойдёт как прямой адрес ComfyUI.

## Необязательный MCP

Добавьте MCP-сервер в отдельном разделе, если нужны сведения, которые ComfyUI не отдаёт: sidecar-описания моделей, README паков и отпечатки файлов. Сервер должен предоставлять подходящие инструменты чтения; MCP-сервер, который только запускает генерации, не является источником каталога.

Введите собственный URL MCP-сервера, часто с окончанием `/mcp`, и нажмите «Проверить». Используйте определённый способ доступа: без входа, токен или вход через браузер. Сохраните настройки; для браузерного входа затем войдите. Доступ привязан к этому адресу MCP. Для удалённого MCP нужен HTTPS, на loopback допустим HTTP.

Все обращения к ComfyUI и MCP здесь только читают: без очереди генераций, загрузок, установки или изменения внешнего графа.

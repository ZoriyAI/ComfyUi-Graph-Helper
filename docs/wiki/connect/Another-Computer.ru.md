# ComfyUI на другом компьютере

ComfyUI работает на другом компьютере вашей сети (компьютер с видеокартой, домашний сервер), CozyGraph на этом.

## На компьютере с ComfyUI

ComfyUI отвечает только на своём компьютере, если не запущен с `--listen`, например:

```bash
python main.py --listen 0.0.0.0
```

Тогда до него может достучаться любой компьютер сети, а своего пароля у ComfyUI нет: пользоваться им сможет любой в
сети. Делайте так только в сети, которой доверяете.

## В CozyGraph

1. «Настройки ▸ Подключение ▸ **Адрес ComfyUI**»: `http://<адрес того компьютера>:8188`, например
   `http://192.168.1.50:8188`. Для другого компьютера `http://` (или `https://`) надо написать.
2. **«Проверить ComfyUI»**, затем **«Сохранить настройки»** и **«Прочитать сейчас»**.

Обычный `http` разрешён: приложение не отправляет ComfyUI ни пароля, ни ключа. Подсказка под полем говорит об этом;
в чужой сети ставьте ComfyUI за `https`.

## Если он не отвечает

- «ComfyUI не отвечает по адресу …»: ComfyUI там не запущен, порт другой, он запущен без `--listen` или порт закрыт
  брандмауэром.
- «Компьютер с именем … не найден»: напишите адрес цифрами.
- Адрес, который отправляет приложение на страницу входа (прокси с паролем), отклоняется: приложение скажет, что адрес
  ведёт на другую страницу.

Все сообщения: [Проблемы с подключением](Connection-Problems.ru.md).

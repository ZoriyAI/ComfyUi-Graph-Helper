# Лицензия и сторонние компоненты

**NodeWise Studio: учебный помощник по графам ComfyUI**

NodeWise это независимый экспериментальный учебный инструмент. Он не связан с Comfy Org и не одобрен ею. В нём нет
кода ComfyUI, он только читает запущенный ComfyUI и никогда его не меняет.

Эта страница объясняет лицензию простыми словами. Это объяснение, а не сама лицензия: силу имеет файл `LICENSE` в
корне проекта, он же показан в приложении в «Справка ▸ О программе ▸ Лицензия».

## Лицензия в одном абзаце

NodeWise распространяется по лицензии MIT с условием Commons Clause. MIT разрешает пользоваться программой,
копировать, менять её и делиться ею. Commons Clause забирает одно право: продавать её. Поэтому проект **с открытым
для чтения исходным кодом** (по-английски source-available): каждый может читать, использовать и менять исходники, но
это не «открытый исходный код» в обычном смысле, потому что продавать нельзя.

## Что можно

- Пользоваться приложением, в том числе по работе: учиться ComfyUI, собирать с ним workflow, пользоваться картинками
  и роликами, которые вы потом делаете в ComfyUI, и продавать их.
- Читать исходный код и учиться на нём.
- Менять его для себя.
- Бесплатно делиться копией, изменённой или нет, если вместе с ней идёт текст лицензии.
- Использовать его на курсе или занятии, которое вы ведёте.

## Фронтенд ComfyUI

| Вопрос | Ответ |
| --- | --- |
| Есть ли в NodeWise код ComfyUI? | Нет. |
| Почему NodeWise следует фронтенду ComfyUI? | Чтобы сохранённый workflow открылся в ComfyUI таким, какой он есть: порядок значений виджетов, номера слотов, определения субграфов. |
| Взято ли что-нибудь из фронтенда? | Одна таблица фактов: какая базовая нода-загрузчик читает какую папку моделей (из `modelNodeMappings.ts` проекта `Comfy-Org/ComfyUI_frontend`, GPL-3.0). Это указано в `src/shared/catalog/modelFolders.ts`. |
| Меняет ли приложение ComfyUI? | Нет. Оно только читает запущенный ComfyUI. [ComfyUI только читается](Read-Only.ru.md) |

ComfyUI и фронтенд ComfyUI это проекты их авторов, под их собственными лицензиями.

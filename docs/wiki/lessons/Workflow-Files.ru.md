# JSON, API JSON и workflow внутри PNG

<!-- lesson: workflow-files -->
Урок «workflow-files» в группе **Ежедневный цикл работы** списка уроков. Уровень 1, основа; трек «База». Урок написан
по новому стандарту (стандарт 2).

## Чему вы научитесь
Различать редактируемый workflow, формат API и картинку с workflow, выбирать нужный под задачу и проверять его перед
тем, как отдать.

## Что понадобится
- [Первая картинка из текста](Image.ru.md) и [Как читать чужой workflow](Reading-A-Workflow.ru.md) или те же навыки.
- ComfyUI, в котором вы можете запускать графы, одна модель для картинок в `models/checkpoints` и простой текстовый
  редактор.
- Проверен 2026-11-15.

## Шаги
1. **Один граф, три формы** (чтение).
2. **Перед началом** (список дел).
3. **Граф картинки** с Save Image.
4. **Метка, которую легко узнать**: `filename_prefix`, который начинается с `formats/`.
5. **Все ноды есть в вашем ComfyUI** (проверка приложения).
6. **Сделайте три файла** (список дел): запуск, чтобы появился PNG; сохранение через «Export» и через «Export (API)»
   из меню ComfyUI.
7. **Что хранит каждая форма** (чтение): workflow хранит `"nodes"` и `"links"` с положением, группами и примечаниями;
   формат API хранит пронумерованные записи с `"class_type"` и `"inputs"`, и больше ничего; картинка несёт обе формы,
   `"workflow"` и `"prompt"`, в метаданных. Все три несут каждое значение каждого поля.
8. **Откройте каждую снова** (список дел): оба файла .json в текстовом редакторе, PNG в этом приложении через
   **Файл ▸ Открыть workflow…**.
9. **Прежде чем файл покинет компьютер** (список дел): в файлах нет ключей, токенов и личных путей; картинка несёт
   промпт, а ComfyUI, запущенный с `--disable-metadata`, пишет картинки без workflow.
10. **Откройте файл API здесь** (проверка приложения): последний открытый приложением файл был в формате API.
11. **Как получилось?** (рубрика): формы различены, для каждой задачи своя форма, ничего личного не осталось (здесь
    нужно «Да»).
12. **Проверьте себя** (три вопроса).
13. **Сами: пакет для передачи** (самостоятельная задача).

## Что проверяет урок
- На холсте, приложением: граф картинки и метка `formats/`. Файл API хранит и то и другое, поэтому граф остаётся на
  месте и после его открытия.
- По тому, что приложение уже читает: ComfyUI прочитан, в `models/checkpoints` есть файл, каждая нода установлена, и
  последний открытый приложением workflow был файлом формата API. До конца урока не открывайте другие файлы.
- Не проверяется: запуск, сделанные файлы и их содержимое. Это ваше слово.

## Частые ошибки
- Файл API отправлен тому, кто будет править граф: отправляйте workflow из «Save» или «Export».
- Картинка открывается без workflow: сайт или мессенджер её переписал. Отправьте файл файлом или приложите .json.
- Ключ, личный путь или лишний промпт в отданном файле: каждое поле уходит во всех трёх формах. Это приложение
  спрашивает, прежде чем сохранить поле, похожее на ключ.
- В меню нет «Export (API)»: старый интерфейс; обновите ComfyUI.

## Источники

docs.comfy.org, workflow metadata. «Export» и «Export (API)»: английская локализация frontend ComfyUI. Что открывает
это приложение и как сохраняет: [Открыть workflow](../graph/Opening-Workflows.ru.md) и
[Сохранить workflow для ComfyUI](../graph/Saving-Workflows.ru.md).

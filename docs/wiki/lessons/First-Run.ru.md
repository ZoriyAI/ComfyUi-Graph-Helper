# Установка и первый запуск без ошибок

<!-- lesson: first-run -->
Урок «first-run» в группе **Старт и надёжная среда** списка уроков. Уровень 0, основа; трек «База». Урок написан по
новому стандарту (стандарт 2).

## Чему вы научитесь
Ставить ComfyUI так, чтобы было доказано, что он работает: читать журнал запуска, делать первую картинку и записывать
карточку среды, по которой другой человек повторит установку.

## Что понадобится
- Ваш выбор из урока [Desktop, Portable, ручная установка или Cloud](Choose-Setup.ru.md). Карточка об этом говорит;
  это подсказка, а не замок.
- Около 10 ГБ свободного места под ComfyUI и первую модель.
- Написан для ComfyUI 0.45.0, Comfy Desktop и официального урока о первой генерации, проверен 2026-11-15.

## Шаги
1. **Работает значит картинка, а не окно** (чтение).
2. **Установите и запустите** (список дел, ваше слово): официальная инструкция вашего способа; журнал запуска печатает
   `To see the GUI go to:`; найдите строки `ComfyUI version:`, `Device:` и `Total VRAM`.
3. **Подключите приложение** (проверка приложения): Настройки ▸ Подключение ▸ Найти на этом компьютере, потом
   Прочитать ComfyUI.
4. **Первая модель** (чтение): в свежем ComfyUI моделей нет; `v1-5-pruned-emaonly-fp16.safetensors` из урока в
   `models/checkpoints`; список недостающих моделей с кнопкой **Download**; R заставляет ComfyUI перечитать папки.
5. **Сделайте первую картинку** (список дел): открыт шаблон; файл модели в `models/checkpoints` (приложение видит это
   после синхронизации); Run и строка `Prompt executed in … seconds` в журнале; файл в папке output. Запуск остаётся
   вашим словом.
6. **Откройте картинку здесь** (проверка приложения): Файл ▸ Открыть workflow… и картинка; приложение проверяет, что
   последним открытым файлом была картинка с workflow.
7. **Граф, который её сделал**: Save Image на холсте.
8. **Все ноды есть в вашем ComfyUI** (проверка приложения).
9. **Карточка среды**: нода Text (Multiline) с системой, видеокартой и памятью, версией, способом установки и папками
   (без имени пользователя, если будете делиться workflow).
10. **Сохраните проверенную пару** (список дел): workflow с карточкой и первая картинка.
11. **Установка доказана?** (рубрика): журнал запуска, карточка, повторный запуск без заметок.
12. **Проверьте себя** (три вопроса).
13. **Сами: холодный старт** (список дел, без **Сделать за меня**).

## Что проверяет урок
- Из того, что приложение уже читает: ComfyUI прочитан, в `models/checkpoints` есть файл, последний открытый workflow
  взят из картинки, все ноды графа установлены.
- На холсте: Save Image и карточка с текстом.
- Не проверяется: установка, журнал, запуск. В конце урок пишет **Запуск в ComfyUI: ваше слово**.

## Частые ошибки
- Пустой список чекпоинтов: в свежем ComfyUI моделей нет; скачайте одну и нажмите R.
- Красные строки в журнале запуска: прочитайте последние и сверьтесь с официальной страницей установки.
- Приложение не находит ComfyUI: сначала откройте напечатанный адрес; Desktop на порту 8000, остальные на 8188.
- «Последняя» на карточке вместо номера из строки `ComfyUI version:`.

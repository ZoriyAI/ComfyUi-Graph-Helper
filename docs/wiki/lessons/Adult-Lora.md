# Adult LoRAs: how to load and balance them

<!-- lesson: adult-lora -->
<!-- verify: lesson added with id "adult-lora"; the wiki writer completes this page from the lesson's steps -->
Lesson "adult-lora", in the closed group for adults: load your own LoRA on the first picture graph, check that it fits the model, set its two strengths and balance two LoRAs. For adults only.

## The limits come first
The lesson opens with the rules. The one list of what the app never helps with is on [Content rules](../trust/Content-Rules.md). The lesson names no file and no word: the person brings their own files and reads the trigger words on the file's own page.

## Steps
First, the rules · Where the files go · A picture graph is needed · Put the LoRA between the model and the graph · Does the file fit the model · The LoRA's words in the description · Two strengths · Comparing on one seed · Two LoRAs: a body and a character · When two LoRAs fight · About the assistant in the app.

## What the lesson checks
The picture graph of [A first picture from text](Image.md) is on the canvas; a Load LoRA node with a file chosen stands between the checkpoint and the sampler and both text nodes; the positive prompt holds the trigger words the file names (none needed if it names none).

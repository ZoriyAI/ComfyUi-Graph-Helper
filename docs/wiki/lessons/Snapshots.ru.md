# Снимки, обновления и откат

<!-- lesson: snapshots -->
Урок «snapshots» в группе **Старт и надёжная среда** списка уроков. Уровень 0, основа; трек «База». Урок написан по
новому стандарту (стандарт 2). После него список продолжает урок [Как устроен ComfyUI](How-ComfyUI-Works.ru.md).

## Чему вы научитесь
Обновлять ComfyUI так, чтобы можно было вернуться: снимок вне установки, контрольный workflow до и после и записанный
путь отката.

## Что понадобится
- Контрольный workflow и карточка среды из урока [Установка и первый запуск без ошибок](First-Run.ru.md).
- Хотя бы один пак: [Manager: установка первого пака безопасно](First-Pack.ru.md).
- Написан для ComfyUI 0.45.0, Comfy Desktop и Manager, проверен 2026-11-15.

## Шаги
1. **Обновление, которое можно отменить** (чтение).
2. **Что хранит снимок** (чтение): версии ComfyUI, паков и пакетов Python, а не модели, workflow и картинки. Desktop:
   панель Manage, вкладка Snapshots (Create Snapshot, Export, Import) и снимок перед каждым обновлением. Manager
   (старый интерфейс): Save snapshot, Restore при следующем запуске. Ручная установка: коммит Git.
3. **Контрольный workflow**: Save Image и карточка среды (нода Text (Multiline)) на холсте.
4. **Сейчас все ноды установлены** (проверка приложения).
5. **До обновления** (список дел): контрольный запуск, версия, снимок, его копия вне папки ComfyUI.
6. **Обновите** (список дел): Desktop, вкладка Update (Stable или Latest on GitHub); Portable,
   `update/update_comfyui_stable.bat`; ручная, `git pull` и `pip install -r requirements.txt`; паки по одному.
7. **Прочитайте заново** (проверка приложения): ComfyUI прочитан, и все ноды контрольного workflow по-прежнему
   установлены.
8. **Тот же workflow после** (список дел): контрольный запуск ещё раз и сравнение.
9. **Путь назад** (чтение): восстановление снимка или Stable в Desktop, Copy & Update, чтобы попробовать на копии;
   Restore в Manager и перезапуск; `git checkout` в ручной установке; старая версия одного пака.
10. **Ваш путь отката** (список дел; попробовать его на копии необязательно).
11. **Обновление обратимо?** (рубрика): та же картинка, что изменилось, путь назад (хотя бы записан).
12. **Проверьте себя** (три вопроса).
13. **Сами: один пак** (список дел, без **Сделать за меня**).

## Что проверяет урок
- Из того, что приложение уже читает: все ноды контрольного workflow установлены до и после; ComfyUI прочитан заново.
- На холсте: Save Image и карточка с текстом.
- Не проверяется: снимок, обновление, версии, оба запуска и сравнение.

## Частые ошибки
- `(IMPORT FAILED)` после обновления: обновите пак или восстановите снимок.
- Свежие коммиты что-то сломали: вернитесь на стабильный канал.
- От снимка ждали моделей: файлы копируйте отдельно.
- Восстановление в Manager «ничего не сделало»: оно срабатывает при следующем запуске.

# Библиотека моделей и общие папки

<!-- lesson: model-library -->
Урок «model-library» в группе **Старт и надёжная среда** списка уроков. Уровень 0, основа; трек «База». Урок написан
по новому стандарту (стандарт 2).

## Чему вы научитесь
Хранить файлы моделей там, где их находит ComfyUI, делить одну папку вместо копий и вести список файлов, по которому
библиотеку можно собрать заново.

## Что понадобится
- Рабочий ComfyUI хотя бы с одним чекпоинтом: [Установка и первый запуск без ошибок](First-Run.ru.md).
- Написан для ComfyUI 0.45.0, Comfy Desktop и официальной страницы о моделях, проверен 2026-11-15.

## Шаги
1. **Библиотека, а не куча** (чтение).
2. **Перед началом** (список дел, который приложение проверяет само): ComfyUI прочитан, в `models/checkpoints` есть
   файл.
3. **Одна папка на один вид** (чтение): каждый загрузчик показывает только свою папку; подпапки видны как часть
   имени; после изменений R в ComfyUI и синхронизация здесь.
4. **Разложите файлы** (список дел, ваше слово): сначала убедиться, что каждый файл можно вернуть, потом каждый файл в
   папку его вида.
5. **Практика: библиотека в загрузчике**: Load Checkpoint с моделью для картинок в `ckpt_name`.
6. **Одна папка для нескольких установок** (чтение): `extra_model_paths.yaml`, скопированный из
   `extra_model_paths.yaml.example` (в Desktop дописывайте в его `extra_models_config.yaml` и не заменяйте его);
   `base_path`, виды, `is_default`; перезапуск после каждой правки.
7. **Решите, потом делите** (список дел): нужна ли общая папка; копия, правка и перезапуск необязательны, для тех,
   кому она нужна.
8. **Модели по-прежнему находятся** (проверка приложения).
9. **Список важных файлов** (список дел): имя, вид, размер, источник, лицензия и SHA-256
   (`certutil -hashfile … SHA256`, `shasum -a 256 …`, `sha256sum …`).
10. **Запуск из библиотеки** (список дел): workflow отработал с моделью на новом месте.
11. **Библиотека в порядке?** (рубрика): все модели в списках, копии, список файлов.
12. **Проверьте себя** (три вопроса).
13. **Сами: файл нового вида** (список дел, без **Сделать за меня**).

## Что проверяет урок
- Из того, что приложение уже читает: ComfyUI прочитан, в `models/checkpoints` есть файл, до и после изменений.
- На холсте: в Load Checkpoint выбрана модель для картинок.
- Не проверяется: ваш диск, файл YAML, хеши, запуск.

## Частые ошибки
- Файл на диске, но ни в одном списке: чужая папка, или ComfyUI ещё не перечитал папки.
- Правка YAML ничего не дала или ComfyUI не запускается: файл читается только при запуске; если запуск не проходит,
  верните копию.
- Одна модель в двух установках: одна копия в общей папке.
- Переименованный файл, который никто не узнаёт: сравните хеш.

# Какой загрузчик для какого файла

<!-- lesson: loaders -->
Урок «loaders» в группе **Картинки: модели** списка уроков. Шагов: 8.

## Чему вы научитесь
Найдёте нужный загрузчик для четырёх видов файлов моделей и узнаете, где ComfyUI ищет каждый.

## Что понадобится
- Урок продолжает [Первая картинка из текста](Image.ru.md). Карточка говорит об этом; это подсказка, а не замок.
- Файлы моделей, которые урок проверяет:
  - модель для картинок (SD 1.5, SDXL, Pony, Illustrious, Flux и подобные), а не видео-модель: `models/checkpoints`, например `juggernautXL_v9.safetensors`;
  - полный VAE, а не маленький декодер для просмотра (taesd, vae_approx): `models/vae`, например `sdxl_vae.safetensors`.
- Ноды: Load Checkpoint, Load Diffusion Model, Load CLIP, Load VAE.
- Приложение ничего не скачивает и не устанавливает. Тексты шагов ниже говорят, какие файлы, в какие папки и какой шаблон ComfyUI их называет.

## Шаги
Слова каждого шага, как их показывает урок. Имена нод выделены.

1. **У каждого загрузчика своя папка** (чтение)

   Файл модели бывает одного из нескольких видов, и у каждого вида своя нода-загрузчик и своя папка в ComfyUI. Загрузчик показывает только файлы своей папки. Поэтому если файла нет в списке, он лежит в другой папке или это файл другого вида.

   В этом уроке вы поставите на холст четыре загрузчика и выберете файл в каждом. Соединять их не нужно: цель в том, чтобы знать, какая нода берёт какой файл.

2. **Чекпойнт: Load Checkpoint**

   Добавьте ноду **Load Checkpoint** и выберите файл в поле `ckpt_name`.

   Чекпойнт держит три части в одном файле, поэтому у ноды три выхода: модель, текстовый энкодер и VAE. ComfyUI ищет его в models/checkpoints. Так обычно приходят SD 1.5, SDXL, Pony, Illustrious и SD 3.5.

3. **Одна диффузионная модель: Load Diffusion Model**

   Добавьте ноду **Load Diffusion Model** и выберите файл в поле `unet_name`.

   Это только та часть, которая рисует, без текстового энкодера и VAE. ComfyUI ищет её в models/diffusion_models (и в старой папке models/unet). Так приходят Flux, Flux.2, Z-Image, Qwen-Image, HiDream и видео-модели. Поле `weight_dtype` умеет сжать полный файл до fp8 ради памяти.

4. **Текстовый энкодер: Load CLIP**

   Добавьте ноду **Load CLIP**, выберите файл в поле `clip_name` и семейство в поле `type`.

   Текстовый энкодер превращает промпт в числа для модели. ComfyUI ищет его в models/text_encoders (и в старой models/clip). Тип должен совпадать с семейством: `lumina2` для Z-Image, `qwen_image` для Qwen-Image, `flux2` для Flux.2, `sd3` для одного T5 от SD 3.5. Семействам с двумя энкодерами нужна нода на два файла (Flux.1: `flux`), SD 3.5 нода на три, HiDream на четыре.

5. **VAE: Load VAE**

   Добавьте ноду **Load VAE** и выберите файл в поле `vae_name`.

   VAE превращает латент в пиксели и обратно. ComfyUI ищет его в models/vae. У каждого семейства свой: `ae.safetensors` для Flux.1 и Z-Image, `flux2-vae.safetensors` для Flux.2, `qwen_image_vae.safetensors` для Qwen-Image.

   В списке могут быть и маленькие файлы для превью (taesd, taesdxl, taef1 и другие) из models/vae_approx. Они быстрые и грубые: ComfyUI показывает с их помощью картинку, пока она рисуется. Для готовой картинки берите полный VAE.

6. **Как понять, что за файл** (чтение)

   Способы понять, от самого надёжного:
   - официальный шаблон модели называет каждый файл и его папку;
   - страница модели пишет «checkpoint», «diffusion model», «text encoder» или «VAE»;
   - размер: VAE до нескольких сотен МБ, чекпойнт SD 1.5 от 2 до 4 ГБ, SDXL около 6.5 ГБ, большая диффузионная модель отдельно от 10 до 40 ГБ;
   - карточка файла во вкладке «Модели» этого приложения называет его семейство.

   Чекпойнт в Load Diffusion Model или диффузионная модель в Load Checkpoint кончаются ошибкой. Файлу .gguf нужны загрузчики пака GGUF. Старые форматы .ckpt, .pt, .pth и .bin могут при загрузке запустить код: выбирайте .safetensors.

7. **Другие файлы графов с картинками** (чтение)

   Другие виды, которые встретятся, и их папки:
   - LoRA: models/loras, нода Load LoRA;
   - ControlNet: models/controlnet;
   - модели увеличения: models/upscale_models;
   - CLIP Vision, для картинки-подсказки: models/clip_vision;
   - эмбеддинги: models/embeddings; у них нет ноды, их вызывают в промпте как embedding:имя.

8. **Что дальше** (чтение)

   Теперь вы знаете, какая нода берёт какой файл. Уроки «Flux.1: картинка из отдельных файлов» и «Z-Image Turbo: картинка за восемь шагов» собирают из таких загрузчиков целые графы.

   Эти четыре загрузчика можно оставить на холсте или удалить: загрузчик, выход которого никуда не ведёт, ComfyUI не запускает.

## Что проверяет урок
Шаг для чтения сделан, когда вы нажимаете **Понятно, дальше**. Шаг с делом отмечается сам, когда на холсте есть:

- Шаг 2, **Чекпойнт: Load Checkpoint**:
  - нода **Load Checkpoint**.
  - в поле `ckpt_name` ноды **Load Checkpoint** стоит файл такого вида: модель для картинок (SD 1.5, SDXL, Pony, Illustrious, Flux и подобные), а не видео-модель; такой файл лежит в `models/checkpoints`, например `juggernautXL_v9.safetensors`.
- Шаг 3, **Одна диффузионная модель: Load Diffusion Model**:
  - нода **Load Diffusion Model**.
  - `unet_name` ноды **Load Diffusion Model**: значение выбрано.
- Шаг 4, **Текстовый энкодер: Load CLIP**:
  - нода **Load CLIP**.
  - `clip_name` ноды **Load CLIP**: значение выбрано.
  - `type` ноды **Load CLIP**: значение выбрано.
- Шаг 5, **VAE: Load VAE**:
  - нода **Load VAE**.
  - в поле `vae_name` ноды **Load VAE** стоит файл такого вида: полный VAE, а не маленький декодер для просмотра (taesd, vae_approx); такой файл лежит в `models/vae`, например `sdxl_vae.safetensors`.

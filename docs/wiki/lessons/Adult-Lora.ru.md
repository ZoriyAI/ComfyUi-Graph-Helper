# LoRA для взрослых: как подключать и уравновешивать

<!-- lesson: adult-lora -->

Урок «adult-lora» в закрытой группе для взрослых: подключить свою LoRA к графу первой картинки, проверить, что она подходит к модели, настроить две её силы и уравновесить две LoRA. Только для взрослых.

## Сначала правила
Урок начинается с правил. Единый список того, с чем приложение никогда не помогает, есть на странице [Правила содержания](../trust/Content-Rules.ru.md). Урок не называет ни файлов, ни слов: файлы ваши, слова-триггеры вы читаете на странице самого файла.

## Что проверяет урок
На холсте граф из урока [Первая картинка из текста](Image.ru.md); нода Load LoRA с выбранным файлом стоит между моделью и сэмплером и обеими нодами текста; в описании есть слова-триггеры, которые записаны в файле (если слов нет, проверять нечего).

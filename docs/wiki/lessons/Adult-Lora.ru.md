# LoRA для взрослых: как подключать и уравновешивать

<!-- lesson: adult-lora -->
Урок «adult-lora» в группе **Для взрослых (18+)**, последней в списке. Шагов: 11. Эта страница описывает технику общими словами.

## Закрытая группа, пока вы её не откроете
Группа открыта, только пока включён переключатель **Содержимое для взрослых (18+)** в **Настройки ▸ Приватность**. В новом профиле он выключен. Пока он выключен, список показывает группу одной строкой с замком, текстом «Уроки о содержимом для взрослых: картинки, LoRA и видео. Их открывает переключатель «Содержимое для взрослых (18+)» в разделе «Настройки ▸ Приватность».» и кнопкой **Открыть настройку**. Включение сначала спрашивает **Включить содержимое для взрослых?** и показывает правила; **Мне есть 18 лет** включает, **Не включать** оставляет как было.

Урок этой группы никогда не предлагается следующим после обычного урока, а обычный после него.

## Сначала правила
Первый шаг, **Сначала правила**, показывает правила приложения о содержимом, те же слова, что в «Справка ▸ Правила содержимого»:

> Взрослые (18+) могут делать любое законное содержимое для взрослых с согласия всех участников, и приложение объясняет технику. В вашей работе этого быть не должно:
> - несовершеннолетние и все, кто выглядит несовершеннолетним, включая рисованных персонажей;
> - реальные люди в откровенном содержимом; лицо и голос человека используйте только с его согласия;
> - сексуальное насилие и принуждение;
> - животные в откровенном содержимом;
> - всё, что запрещено законом там, где вы живёте.
>
> За то, что вы делаете и куда выкладываете, отвечаете вы: законы вашей страны и правила площадок.

См. [Правила содержимого](../trust/Content-Rules.ru.md).

## Чему вы научитесь
Подключите свою LoRA, проверите, к какой модели она подходит, и научитесь уравновешивать две LoRA.

## Что понадобится
- Граф урока [Первая картинка из текста](Image.ru.md).
- Свой файл LoRA в `models/loras`, сделанный для семейства вашей модели.
- Приложение ничего не скачивает.

## Шаги
1. **Сначала правила** (чтение): правила приложения о содержимом, целиком (они приведены выше).
2. **Где лежат файлы** (чтение): файл LoRA кладут в `models/loras`; потом **Синхронизация ▸ Синхронизировать сейчас**, и он появится на вкладке **Модели**. Файлы и слова ваши: урок их не называет.
3. **Нужен граф для картинки**: на холсте должен быть граф картинки.
4. **Поставьте LoRA между моделью и графом**: нода Load LoRA между чекпойнтом и графом, как в официальном примере ComfyUI: `MODEL` и `CLIP` идут через неё к сэмплеру и к обеим текстовым нодам.
5. **Подходит ли файл к модели** (чтение): LoRA работает только с семейством, для которого сделана; сравните семейство в карточке файла с карточкой модели.
6. **Слова LoRA в промпте**: прочитайте слова-триггеры файла в его карточке и впишите их в промпт сами.
7. **Две силы** (чтение): `strength_model` меняет то, что рисует модель, `strength_clip` то, как она читает промпт; начинайте с силы от автора, обычно от 0.6 до 1.
8. **Сравнение на одном seed** (чтение): чтобы увидеть, что делает файл, оставьте `seed` и все остальные поля и меняйте только его силу: 0, значение автора, потом выше.
9. **Две LoRA: тело и персонаж** (чтение): две LoRA ставят цепочкой; LoRA тела и LoRA персонажа часто тянут лицо в разные стороны: настраивайте по одной, уменьшите LoRA тела, поставьте LoRA персонажа последней или поправьте лицо отдельным проходом.
10. **Когда две LoRA спорят** (чтение): две LoRA, которые учат разному, складываются и могут смазать картинку: уменьшите обе или разнесите их по двум проходам.
11. **О помощнике в приложении** (чтение): урокам помощник не нужен; вопрос в режиме «Спросить» уходит выбранной модели, и она отвечает по своим правилам; правила первого шага принадлежат приложению. Отправку значений полей можно выключить в **Настройки ▸ Приватность**.

## Что проверяет урок
Шаг для чтения сделан, когда вы нажимаете **Понятно, дальше**. Шаг с делом отмечается сам, когда на холсте есть:

- Шаг 3, **Нужен граф для картинки**:
  - нода **Load Checkpoint**.
  - нода **CLIP Text Encode (Prompt)**.
  - нода **CLIP Text Encode (Prompt)**.
  - нода **KSampler**.
  - нода **VAE Decode**.
  - нода **Save Image** или **Preview Image**.
  - `CLIP` ноды **Load Checkpoint** во вход `clip` ноды **CLIP Text Encode (Prompt)** (промпт) (можно через Load LoRA или CLIP Set Last Layer).
  - `CLIP` ноды **Load Checkpoint** во вход `clip` ноды **CLIP Text Encode (Prompt)** (негатив) (можно через Load LoRA или CLIP Set Last Layer).
  - `MODEL` ноды **Load Checkpoint** во вход `model` ноды **KSampler** (можно через Load LoRA или LoraLoaderModelOnly).
  - `CONDITIONING` ноды **CLIP Text Encode (Prompt)** (промпт) во вход `positive` ноды **KSampler**.
  - `CONDITIONING` ноды **CLIP Text Encode (Prompt)** (негатив) во вход `negative` ноды **KSampler**.
  - `LATENT` ноды **KSampler** во вход `samples` ноды **VAE Decode**.
  - `IMAGE` ноды **VAE Decode** во вход `images` ноды **Save Image** или **Preview Image**.
- Шаг 4, **Поставьте LoRA между моделью и графом**:
  - нода **Load LoRA**.
  - `MODEL` ноды **Load Checkpoint** во вход `model` ноды **Load LoRA**.
  - `CLIP` ноды **Load Checkpoint** во вход `clip` ноды **Load LoRA**.
  - `MODEL` ноды **Load LoRA** во вход `model` ноды **KSampler** (можно через Load LoRA или LoraLoaderModelOnly).
  - `CLIP` ноды **Load LoRA** во вход `clip` ноды **CLIP Text Encode (Prompt)** (промпт) (можно через Load LoRA или CLIP Set Last Layer).
  - `CLIP` ноды **Load LoRA** во вход `clip` ноды **CLIP Text Encode (Prompt)** (негатив) (можно через Load LoRA или CLIP Set Last Layer).
  - `lora_name` ноды **Load LoRA**: значение выбрано.
  - файл в поле `lora_name` ноды **Load LoRA** сделан для семейства файла из поля `ckpt_name` ноды **Load Checkpoint**. Почему: loRA и ControlNet работают только с тем семейством моделей, для которого сделаны; с другим они ничего не дают или портят картинку.
- Шаг 6, **Слова LoRA в промпте**:
  - `text` ноды **CLIP Text Encode (Prompt)** (промпт): есть слово-триггер файла из поля `lora_name` ноды **Load LoRA**, если описание файла их называет.

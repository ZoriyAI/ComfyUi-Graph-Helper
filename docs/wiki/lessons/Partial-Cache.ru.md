# Частичное выполнение и кэш

<!-- lesson: partial-cache -->
Урок «partial-cache» в группе **Ежедневный цикл работы** списка уроков. Уровень 1, основа; трек «База». Урок написан
по новому стандарту (стандарт 2).

## Чему вы научитесь
Запускать только ту ветку, над которой работаете, и по времени и файлам говорить, какие ноды выполнились снова и почему.

## Что понадобится
- [Run, очередь, история и отмена](Queue-History.ru.md) или те же навыки.
- ComfyUI, в котором вы можете запускать графы, одна модель для картинок в `models/checkpoints` и интерфейс (frontend)
  версии 1.24 или новее для частичного выполнения.
- Ноды: граф картинки, Upscale Image By и Preview Image. Все они собственные ноды ComfyUI.
- Проверен 2026-11-15.

## Шаги
1. **Выполняйте только то, над чем работаете** (чтение): ComfyUI помнит результаты и считает только изменённое.
2. **Перед началом** (список дел).
3. **Граф картинки** с Save Image.
4. **Вторая ветка: маленький предпросмотр**: Upscale Image By от VAE Decode, `scale_by` от 0.25 до 0.75
   (**Сделать за меня** ставит 0.5), и после неё Preview Image.
5. **Все ноды есть в вашем ComfyUI** (проверка приложения).
6. **Полный запуск и запуск без изменений** (список дел): `control_after_generate` в `fixed`, время запуска по строке
   «Prompt executed in … seconds» и второй запуск, который сразу заканчивается.
7. **Что выполняется снова** (чтение): изменённая нода и всё после неё выполняются снова; ноды до неё берутся из памяти.
8. **Правка в конце графа** (список дел): поменяли только `scale_by`: сэмплер не выполнялся, запуск короткий.
9. **Запустите одну ветку** (список дел): предпросмотр выделен и запущен один кнопкой на панели выделения (или «Queue
   Selected Output Nodes»): нового файла нет; новый seed на одной ветке предпросмотра: сэмплер выполняется, файла всё
   равно нет; весь граф: Save Image пишет новую картинку.
10. **Что вы доказали?** (рубрика): какая ветка выполнилась, почему быстрее, что выполняет снова правка выше.
11. **Проверьте себя** (три вопроса).
12. **Сами: сохранить маленькую копию** (самостоятельная задача на холсте, без **Сделать за меня**): вторая Save Image
    от маленькой копии с другим `filename_prefix`.

## Что проверяет урок
- На холсте, приложением: граф картинки, ветка предпросмотра и её масштаб, а в последнем шаге второе сохранение с
  другим именем.
- По тому, что приложение уже читает: ComfyUI прочитан, в `models/checkpoints` есть файл, каждая нода установлена.
- Не проверяется: какие ноды выполнились, время и файлы. Это ваше слово.

## Частые ошибки
- Нет кнопки запуска у выделения: частичное выполнение начинается с ноды вывода.
- Частичный запуск выполняет всё: старый интерфейс; обновите ComfyUI.
- После правки ничего не выполнилось: правка не лежит на пути к выходу, который вы запускаете, или значение не поменялось.
- Каждый раз выполняется всё: seed меняется после каждого запуска; поставьте `control_after_generate` в `fixed`.

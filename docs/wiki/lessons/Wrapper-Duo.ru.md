# Разговор двоих: InfiniteTalk

<!-- lesson: wrapper-duo -->
Урок «wrapper-duo»: два человека на одной картинке говорят, каждый своим голосом.

## Сначала о согласии
Озвучивать можно только тех, кто согласен, их собственными голосами или голосами, на которые у вас есть разрешение. См. [Правила содержания](../trust/Content-Rules.ru.md).

## Чему вы научитесь
Добавлять к графу InfiniteTalk второй голос, выбирать, как звучат две записи (вместе или по очереди), и понимать, какой голос достанется какому человеку.

## Что понадобится
- Граф урока [Говорящее видео: InfiniteTalk](Wrapper-Talk.ru.md).
- Модуль InfiniteTalk для нескольких говорящих (в имени есть «multi»; у MultiTalk один модуль на все случаи).
- Картинка, где два человека стоят рядом и оба видны крупно, и две записи голоса.

## Шаги
1. **Два голоса в одном кадре** (чтение), с правилом согласия.
2. **Нужен граф говорящего видео.**
3. **Проверьте модуль** (чтение): модуль для нескольких говорящих в MultiTalk Model Loader.
4. **Выберите картинку** (чтение): один человек в левой половине, другой в правой.
5. **Добавьте второй голос**: вторая Load Audio с другим файлом, во вход `audio_2`.
6. **Вместе или по очереди** (чтение): `multi_audio_type` `para` (обе с начала, в каждой записи паузы) или `add` (сначала первая, потом вторая).
7. **Кто каким голосом говорит** (чтение): `audio_1` достаётся человеку слева, `audio_2` справа; иначе нужны маски во входе `ref_target_masks`, нарисованные в редакторе масок ComfyUI; `audio_3` и `audio_4` требуют масок.
8. **Граф готов** (чтение).

## Что проверяет урок
Граф InfiniteTalk на месте; вторая Load Audio с другим файлом питает `audio_2`.

## Частые ошибки
- Модуль single: двигается только одно лицо.
- Голоса перепутаны: поменяйте записи местами или возьмите маски.
- Длинные записи, пока идёт подбор: берите реплики по несколько секунд.

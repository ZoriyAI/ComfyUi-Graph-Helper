# LoRA: добавить стиль или тему

<!-- lesson: lora -->
Урок «lora»: LoRA в пути обеих моделей Wan 2.2 и её слова-триггеры в промпте.

## Чему вы научитесь
Ставить загрузчик LoRA в путь модели, выбирать правильный файл для каждой из двух моделей Wan 2.2, задавать силу и находить и вписывать слова-триггеры.

## Что понадобится
- Граф урока [Видео из текста](Video-Text.ru.md) или [Видео из картинки](Video-Image.ru.md): две Load Diffusion Model и две ModelSamplingSD3.
- LoRA, сделанная для вашей модели Wan, часто парой файлов (`high` и `low`), в `models/loras`.
- Встроенная нода LoraLoaderModelOnly (в зависимости от версии ComfyUI называется «LoraLoaderModelOnly» или «Load LoRA (Model only)»).

## Шаги
1. **Что такое LoRA** (чтение): небольшая добавка, которая учит одному; делается под свою модель; LoRA для Wan 2.2 часто идут парой.
2. **Нужен граф для видео.**
3. **Добавьте две ноды LoRA**: по одной на модель.
4. **Поставьте их в путь модели**: `MODEL` загрузчика в ноду LoRA, `MODEL` ноды LoRA в ModelSamplingSD3. Для обеих моделей.
5. **Выберите файлы и силу** (чтение): файл `high` в путь `high_noise`, `low` в путь `low_noise`; единственный файл ставится в обе; `strength_model` 1, если LoRA всё перебивает, 0.6 до 0.8; несколько LoRA ставятся цепочкой.
6. **Слова, которые включают LoRA** (чтение): слова-триггеры; карточка файла во вкладке **Модели** показывает их, если автор записал их в файл.
7. **Впишите слова LoRA в описание.**
8. **LoRA подключена** (чтение): сравните с роликом без неё; если ничего не поменялось, проверьте семейство файла, слова-триггеры и силу.

## Что проверяет урок
LoraLoaderModelOnly стоит между каждым загрузчиком и его ModelSamplingSD3 (другие загрузчики LoRA между ними можно); положительный промпт содержит одно из слов-триггеров, записанных в два файла LoRA. Если слов в файлах нет, шаг со словами засчитывается сам.

## Частые ошибки
- LoRA для другого семейства или размера (SDXL или Wan 1.3B к модели 14B): ничего не происходит, ComfyUI только пишет предупреждения в журнал.
- Файл `low` в пути `high_noise`.
- Сила 1.5 и больше: картинка ломается.
- Забыть слова-триггеры.

# Run, очередь, история и отмена

<!-- lesson: queue-history -->
Урок «queue-history» в группе **Ежедневный цикл работы** списка уроков. Уровень 1, основа; трек «База». Урок написан
по новому стандарту (стандарт 2).

## Чему вы научитесь
Ставить в очередь несколько запусков намеренно, отменять ненужный и находить готовый запуск с его настройками в истории.

## Что понадобится
- [Первая картинка из текста](Image.ru.md) или тот же граф, собранный вручную.
- ComfyUI, в котором вы можете запускать графы, и одна модель для картинок в `models/checkpoints`.
- Написан для собственных нод ComfyUI и его интерфейса по документации ноября 2026 года, проверен 2026-11-15.

## Шаги
1. **Run ставит задачу в очередь** (чтение): состояния задачи и почему повторный Run добавляет задачу, которая сразу
   заканчивается.
2. **Перед началом** (список дел): ComfyUI прочитан и модель есть (это приложение видит само), версии записаны (ваше слово).
3. **Граф для очереди**: граф картинки с Save Image.
4. **Папка для запусков**: `filename_prefix`, который начинается с `queue/`.
5. **Все ноды есть в вашем ComfyUI** (проверка приложения).
6. **Где смотреть очередь** (чтение): панель запуска с **Run** и **Cancel**, Shift для начала очереди, режимы «Run»,
   «Run (On Change)» и «Run (Instant)», счётчик активных задач и **Job History** с меню задач. В некоторых версиях
   Job History включается настройкой «Docked job history/queue panel».
7. **Поставьте три задачи** (список дел): три задачи с тремя промптами; счётчик уменьшается.
8. **Одну отменить, одну остановить** (список дел): «Cancel job» у ждущей, «Cancel» или Ctrl+Alt+Enter у идущей и
   состояние каждой из шести задач.
9. **Найдите запуск снова** (список дел): готовая задача найдена по картинке, открыта через «Open as workflow in a new
   tab», промпт и seed прочитаны, файл найден.
10. **Как получилось?** (рубрика): состояние каждой задачи, восстановленный запуск, как часто Run нажимался вслепую.
11. **Проверьте себя** (три вопроса): Run без изменений, что убирает очистка очереди, как поставить задачу первой.
12. **Сами: серия** (самостоятельная задача): четыре seed, ненужные задачи отменены, seed лучшей записан.

## Что проверяет урок
- На холсте, приложением: граф картинки и папка `queue/`.
- По тому, что приложение уже читает: ComfyUI прочитан, в `models/checkpoints` есть файл, каждая нода установлена.
- Не проверяется: очередь, история, отмена и запуски. Это ваше слово.

## Частые ошибки
- Три нажатия Run, одна картинка: между ними ничего не менялось, и ComfyUI взял готовый результат.
- ComfyUI сам продолжает запускать: кнопка Run в режиме «Run (Instant)» или «Run (On Change)».
- Очередь очищена, а идущая задача продолжилась: очистка убирает только ждущие; идущую останавливает «Cancel».
- Нет Job History: включите «Docked job history/queue panel» (Settings, Comfy, Queue) или пользуйтесь панелью очереди
  старой версии (клавиша Q).

Запуск с партнёрскими нодами, платными нодами внешнего сервиса, тратит кредиты при каждой постановке в очередь:
отменяйте ненужное сразу.

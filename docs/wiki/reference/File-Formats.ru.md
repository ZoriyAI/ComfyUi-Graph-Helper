# Форматы файлов

Файлы, которые приложение читает и пишет вне своей [папки с данными](Data-Folder.ru.md). Все они текстовые, в формате
JSON, кроме картинок и видео, из которых читается workflow. Файл больше 64 МБ не открывается.

## Файл проекта

- **Имя:** при сохранении предлагается `*.nodewise.json`. Файлы проекта, сохранённые версией 0.9 с окончанием
  старого названия приложения, тоже открываются: приложение смотрит на содержимое, а не на имя. «Сохранить проект»
  записывает такой файл обратно под его же именем; «Сохранить проект как» предлагает окончание `.nodewise.json`.
- **Пишет:** «Файл ▸ Сохранить проект». **Читает:** «Файл ▸ Открыть проект».
- **Внутри:** поле `format` с названием формата проекта (`nodewise-studio-project`; название, которое писала версия
  0.9, тоже читается, а файл записывается обратно уже с новым), `version` (сейчас 2; версии 0 и 1 тоже открываются), граф в
  собственной форме ComfyUI, записи о компонентах (назначение, как пользоваться), субграфы, группы, название и заметки
  графа, объяснения и заметки, которые вы написали.
- **Не внутри:** разговор, настройки и ключи. Поле, похожее на ключ или токен, показывается вам перед сохранением, и
  вы выбираете, сохранить без него или как есть.
- **Совместимость вперёд:** поля, которых эта версия не знает, сохраняются и записываются обратно.
- Новый проект хранит граф в формате workflow 1, поэтому в нём можно делать субграфы.
- Файл проекта из более новой версии не открывается, а сообщение называет его версию.

Подробнее: [Файлы проекта](../graph/Project-Files.ru.md).

## Файл workflow

- **Пишет:** «Файл ▸ Сохранить workflow для ComfyUI…». **Читает:** «Файл ▸ Открыть workflow…» (и сам ComfyUI).
- **Внутри:** обычный workflow ComfyUI в том формате, в каком его сохраняет фронтенд ComfyUI (версии 0.4 и 1), с
  субграфами. То, что вы не меняли, возвращается точно таким же, включая значения, которые приложение не показывает.
- **Старый формат 0.4** открывается, но не может содержать субграф: приложение предложит скопировать ноды в новый
  проект.
- **Из картинки или видео:** «Файл ▸ Открыть workflow…» предлагает и картинки и видео, которые сохраняет ComfyUI
  (PNG, WebP, JPEG, GIF, MP4, WebM, MKV, MOV), и его звуковые файлы (FLAC, MP3, Opus, OGG). ComfyUI записывает
  workflow в сохраняемые файлы; приложение читает его оттуда и пишет «Прочитан из картинки…» или «Прочитан из
  видео…». Файл без workflow: «В этом файле нет workflow…».
- **Формат API** ComfyUI (файл с заданиями по номерам нод, без положения нод) тоже открывается: приложение
  раскладывает ноды слева направо и пишет «Файл был в формате API, где нет положения нод…». Он открывается как формат
  0.4.
- Файл, брошенный на окно или названный в [командной строке](Command-Line.ru.md), открывается так же.
- С ключами так же, как в файле проекта.

Подробнее: [Как открыть workflow](../graph/Opening-Workflows.ru.md),
[Как сохранить workflow для ComfyUI](../graph/Saving-Workflows.ru.md).

## Файл урока

- **Имя:** `*.lesson.json`. **Пишет:** кнопка экспорта на карточке урока или рядом с названием группы.
  **Читает:** «Файл ▸ Импорт уроков…», кнопка «Импорт…» в «Моих уроках» или файл, брошенный на список уроков.
- **Внутри:** поле `format` (`nodewise-studio/lessons`), `version` (сегодня 1; более новая отклоняется с
  сообщением) и один урок или больше (не больше 200): id, тексты по-английски, по-русски или на обоих языках, шаги и
  то, что каждый шаг проверяет на холсте. Файл не больше 2 МБ.
- **Только данные:** ничего из него не запускается и не открывается; файл принимается целиком или не принимается.

Весь формат: [Формат файла урока](../lessons/Lesson-File-Format.ru.md).

## Файл со списком нод

- **Читает:** «Файл ▸ Загрузить список нод из файла…», если подключения нет.
- **Внутри:** ответ `/object_info` ComfyUI, сохранённый из ComfyUI или из браузера как файл `.json`.

## Журнал общения с моделью

- **Пишет:** «Справка ▸ Журнал общения с помощником…» ▸ сохранение в файл, для отмеченных ответов.
- **Внутри:** по одному объекту JSON на строку (`.jsonl`): каждый запрос к модели, что пришло в ответ, вызовы
  инструментов и их результаты. Ключи и токены скрыты; домашняя папка записана как `~`.

Подробнее: [Журнал общения с моделью](../assistant/Conversation-Log.ru.md).

# Сообщения и что делать

Сообщения, которые приложение показывает, когда что-то идёт не по плану, по местам, где они появляются, и что делать
с каждым. Как выглядят сообщения и диалоги: [Сообщения и диалоги](../interface/Messages-And-Dialogs.ru.md). Когда
помощник не может ответить: [Неудачные ответы](../assistant/Failed-Answers.ru.md).

## При запуске

| Сообщение | Что делать |
| --- | --- |
| «Ваши данные сохранены более новой версией приложения. Установите эту версию снова, чтобы открыть их. Ничего не изменено.» | Снова установите более новую версию или запустите приложение с другой папкой данных (`--user-data-dir`). |
| **«Файл с данными приложения повреждён»** | «Начать с пустыми данными» откладывает повреждённый файл под новым именем; «Открыть папку» показывает его. Файлы проектов и workflow не затронуты. |
| «Файл с данными приложения в папке … повреждён, и его не удалось убрать в сторону. Перенесите файл comfyui-desktop.db из этой папки…» | Перенесите файл вручную и запустите снова. |
| «Приложение не может писать в папку с данными …» | Проверьте, что папка ваша и диск не защищён от записи. |
| «На диске нет места для данных приложения.» | Освободите место; ваши данные сохранены. |
| «Файл с данными приложения занят другой программой.» | Закройте другую программу (вторую копию приложения, программу резервного копирования, просмотрщик баз). |
| **«… не запустился»** «Приложение не смогло запуститься. Журнал находится в …» | Откройте журнал; см. [Решение проблем](Troubleshooting.ru.md). |

## Открытие и сохранение файлов

| Сообщение | Что делать |
| --- | --- |
| «Файл был в формате API, где нет положения нод: приложение разложило их слева направо.» | Ничего: файл API открылся. При желании разложите его (`Ctrl+Shift+L`). |
| «Это не workflow: текст файла не удалось прочитать.» | Файл не в формате JSON или обрезан. Сохраните его из ComfyUI заново. |
| «В этом файле нет workflow…» | Картинку или видео сохранил не ComfyUI, или мессенджер убрал из них workflow. Откройте исходный файл или `.json`. |
| «Такой файл здесь не открыть…» | Откройте workflow (`.json`), проект или картинку либо видео, сохранённые в ComfyUI. |
| «Этого файла больше нет: его перенесли или удалили.» | Файл из «Файл ▸ Недавние файлы» переехал; откройте его с нового места. |
| «Этот файл слишком большой, чтобы его открыть.» | Файл больше 64 МБ. |
| «Этот граф слишком большой (нод: …, связей: …)…» | Приложение открывает графы не больше 1500 нод и 3000 связей. Ничего не изменилось. [Известные ограничения](Known-Limits.ru.md) |
| «Этот файл защищён от записи…» | Выберите другое имя или разрешите запись в свойствах файла. |
| «Этот файл не проект …» | Если это workflow, откройте его через «Файл ▸ Открыть workflow…». |
| «Эта версия файла проекта не поддерживается (N). Обновите приложение, чтобы открыть его.» | Файл сохранён более новой версией. |
| «Файл проекта повреждён. Откройте другую копию проекта.» | Возьмите другую копию. |
| «В эту папку нельзя записывать. Выберите другую папку.» | Сохраните в свою папку. |
| «На диске нет свободного места. Освободите место или выберите другой диск.» | Освободите место. |
| «Это не список нод, сохранённый из ComfyUI.» | «Файл ▸ Загрузить список нод из файла…» ждёт ответ `/object_info` ComfyUI. |
| **«N полей похожи на ключ или токен»** | «Сохранить без этих значений» не пускает ключ в файл. |

## Пока вы правите граф

| Сообщение | Что делать |
| --- | --- |
| «Изменение не удалось сохранить. Граф остался таким, каким был до него.» | Обычно диск полон; освободите место и повторите. |
| «Изменение не применено» | Граф успел измениться (например, помощник построил шаг). Повторите правку. |
| «Входы и выходы этой ноды пока неизвестны: запустите ComfyUI и синхронизируйте» | Прочитайте ComfyUI снова: «Синхронизация ▸ Синхронизировать сейчас». |
| «Субграф нельзя положить внутрь самого себя, ни сразу, ни через другой субграф.» | Выберите для субграфа другие ноды. |

## Помощник

| Сообщение | Что делать |
| --- | --- |
| «У облачного помощника нет ключа. Добавьте ключ в «Настройки ▸ Помощник».» | Вставьте ключ: [Ключи](../assistant/Keys.ru.md). |
| «Не выбрана модель у облачного помощника.» / «Не выбрана модель на своём сервере.» | Выберите модель в «Настройки ▸ Помощник». |
| «Облачный ключ не отправляется на адрес http. Укажите адрес, который начинается с https.» | Исправьте адрес. |
| «Не указан адрес своего сервера с моделью.» | Впишите его в «Настройки ▸ Помощник», например `http://127.0.0.1:11434/v1`. |
| «Провайдер не принял ключ.» | Ключ неверный, отозван или от другого поставщика. |
| «Сервер не ответил.» / «Сервер не прислал список моделей вовремя.» | Запустите сервер; проверьте адрес. |
| «Эта модель не умеет вызывать инструменты, а без них помощник не может читать граф…» | Выберите в списке модель с пометкой «инструменты». |

Больше, в том числе сообщения внутри ответа: [Неудачные ответы](../assistant/Failed-Answers.ru.md).

## Ключи и настройки

| Сообщение | Что делать |
| --- | --- |
| «В настройки нельзя записать ключ или пароль. Уберите его из поля.» | Ключ вставляется в своё поле для ключа, а не в адрес или название. |
| «В объяснение нельзя записать ключ или пароль. Уберите его из текста.» | Уберите ключ из заметки. |
| «Хранится только в этом сеансе: система не подтвердила шифрование.» | Хранилище паролей не открылось; см. [Решение проблем](Troubleshooting.ru.md). |
| «Сохранённые настройки не прочитались; показаны настройки по умолчанию.» | Проверьте и сохраните настройки заново. |

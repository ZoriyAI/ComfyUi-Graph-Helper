# Keyboard shortcuts

The full table. Help ▸ Keyboard shortcuts (`F1`) shows the same list in the app. The shortcuts work in the Russian
keyboard layout too: the app reads the key, not the letter it types.

On macOS (a build from source) `Cmd` takes the place of `Ctrl`.

## Menus

| Keys | What it does |
| --- | --- |
| `Alt` or `F10` | Opens the menu bar; the arrow keys move through it. |
| `Shift+F10` or the Menu key | Opens the context menu of the canvas or of the selected node. |

## File

| Keys | Command |
| --- | --- |
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+Shift+S` | Save project as… |
| `Ctrl+I` | Open workflow… |
| `Ctrl+E` | Save workflow for ComfyUI… |
| `Ctrl+,` | Settings… |
| `Ctrl+Q` | Exit |

## Edit

| Keys | Command |
| --- | --- |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` or `Ctrl+Y` | Redo |
| `Ctrl+C` | Copy |
| `Ctrl+X` | Cut |
| `Ctrl+V` | Paste |
| `Ctrl+D` | Duplicate |
| `Ctrl+A` | Select all |
| `Delete` or `Backspace` | Delete selection |

## Graph

| Keys | Command |
| --- | --- |
| `Ctrl+K` | Add node… |
| `Ctrl+G` | Make a subgraph from selection |
| `Alt+C` | Collapse or expand the selected nodes |
| `Ctrl+Shift+L` | Arrange the graph |
| `Ctrl+Shift+C` | Check graph |

## View

| Keys | Command |
| --- | --- |
| `Shift+1` | Fit to view |
| `Ctrl+=` | Zoom in |
| `Ctrl+-` | Zoom out |
| `Ctrl+0` | Actual size |
| `Ctrl+B` | Library |
| `Ctrl+J` | Tools panel |
| `Esc` | Stop the tour or replay |

## Assistant and Help

| Keys | Command |
| --- | --- |
| `Ctrl+/` | Message the assistant |
| `Enter` | Sends the message; `Shift+Enter` starts a new line. |
| `F1` | Keyboard shortcuts |

## On the canvas

| Keys | What it does |
| --- | --- |
| `Enter` or `Space` | Selects the focused node or link. |
| Arrow keys | Move the selected node. |
| `Ctrl` + click | Adds a node to the selection. |
| `Esc` | Cancels a link being drawn or an edit. |

## In the guided tour

| Keys | What it does |
| --- | --- |
| `→` and `←` | Next and previous step. |
| `Space` | Plays or pauses the tour. |
| `Esc` | Ends the tour. |

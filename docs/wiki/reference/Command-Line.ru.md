# Командная строка

Программа называется `nodewise-studio`. Без параметров она открывает окно. Она понимает
такие параметры и один файл:

| Параметр | Что делает |
| --- | --- |
| `--version`, `-v` | Печатает версию и выходит, не открывая окна. |
| `--help`, `-h` | Печатает список параметров и выходит, не открывая окна. Текст на языке системы: по-русски в русской системе, иначе по-английски. |
| `--user-data-dir=<папка>` | Хранит настройки, ключи и историю в этой папке вместо обычной [папки с данными](Data-Folder.ru.md). Удобно для второго, отдельного профиля или для проверки. |
| `--password-store=<хранилище>` | Какое хранилище паролей системы хранит сохранённые ключи: `gnome-libsecret`, `kwallet5` или `kwallet6`. То же самое изнутри приложения делает «Настройки ▸ Приватность ▸ Какое хранилище использует приложение». |
| `--ozone-platform-hint=auto` | Работает прямо в Wayland, если рабочий стол его использует, а не через XWayland. |
| `[файл]` | Workflow (`.json`), проект или картинка либо видео, сохранённые ComfyUI: файл открывается в окне. Если граф на экране не сохранён ни в каком файле, приложение сначала спрашивает. |

Остальные параметры принадлежат Chromium и передаются ему без изменений.

## Примеры

```bash
nodewise-studio --version
nodewise-studio ~/Pictures/ComfyUI_00001_.png
nodewise-studio --user-data-dir="$HOME/nodewise-test"
nodewise-studio --password-store=kwallet6
```

Для одной папки с данными одновременно работает только одно окно приложения: повторный запуск выводит открытое окно
на передний план, а файл, названный при повторном запуске, открывается в нём.

В Windows программа оконная, своей консоли у неё нет. `--version` и `--help` пишутся одной прямой записью в её вывод:
через канал, как читает скрипт установки, они доходят; появятся ли они, если набрать команду в окне консоли, не
проверено. Справка называет папку с данными каждой системы, а `--password-store` и `--ozone-platform-hint` показывает
только в Linux.

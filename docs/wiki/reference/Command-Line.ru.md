# Командная строка

Программа называется `cozygraph`. <!-- verify: technical rename --> Без параметров она открывает окно. Она понимает
такие параметры:

| Параметр | Что делает |
| --- | --- |
| `--version`, `-v` | Печатает версию и выходит, не открывая окна. |
| `--help`, `-h` | Печатает список параметров и выходит, не открывая окна. |
| `--user-data-dir=<папка>` | Хранит настройки, ключи и историю в этой папке вместо обычной [папки с данными](Data-Folder.ru.md). Удобно для второго, отдельного профиля или для проверки. |
| `--password-store=<хранилище>` | Какое хранилище паролей системы хранит сохранённые ключи: `gnome-libsecret`, `kwallet5` или `kwallet6`. То же самое изнутри приложения делает «Настройки ▸ Приватность ▸ Хранилище паролей». |
| `--ozone-platform-hint=auto` | Работает прямо в Wayland, если рабочий стол его использует, а не через XWayland. |

Остальные параметры принадлежат Chromium и передаются ему без изменений.

## Примеры

```bash
cozygraph --version
cozygraph --user-data-dir="$HOME/cozygraph-test"
cozygraph --password-store=kwallet6
```
<!-- verify: technical rename -->

Для одной папки с данными одновременно работает только одно окно приложения: повторный запуск выводит открытое окно
на передний план.

В Windows у программы нет консоли, поэтому `--version` и `--help` там ничего не печатают.

# Известные ограничения

Чего приложение не делает и где оно сегодня слабо. NodeWise Studio экспериментальный проект; этот список прямо говорит,
чего ждать. Пожелания пишите в обсуждения проекта, о проблемах в обращения (Issues).

## Так задумано

- **Оно никогда не запускает workflow.** Оно собирает и объясняет; запускает ComfyUI.
  [Как запустить результат в ComfyUI](../graph/Running-In-ComfyUI.ru.md)
- **Оно не ставит ноды и модели и не добавляет задания в очередь.** Доступны явная загрузка изображений и управление поддерживаемыми локальными службами.
  [Чтение каталога и загрузка выбранных файлов](../trust/Read-Only.ru.md)
- **Два языка:** русский и английский.

## Системы и пакеты

- **Пакеты только для Linux**, 64-битный x86: `.deb`, `.rpm`, AppImage и `.tar.gz`. Пакетов для Linux на ARM и
  Flatpak нет.
- **Windows и macOS ставятся из исходного кода скриптом**: `install-windows.ps1` (Windows 10 22H2 и 11, x64) и
  `install-macos.sh` (macOS 13 или новее, Apple silicon или Intel) собирают приложение на вашем компьютере и ставят
  его для вашего пользователя. Ни на одной из этих систем приложение не подписано издателем. Пакеты для Linux для каждого выпуска собираются, устанавливаются и запускаются на сервере сборки; скрипты для
  Windows и macOS проверяются на машинах GitHub с Windows и macOS при каждом изменении, а на разных настоящих
  компьютерах их **ещё не пробовали**. Сообщения в обращениях (Issues) проекта, с журналом
  скрипта и версией системы, очень нужны.
  [Установка на Windows](../start/Installing-On-Windows.ru.md), [Установка на macOS](../start/Installing-On-macOS.ru.md)
- На Windows и macOS часть текстов всё ещё говорит о Linux: настройка хранилища паролей и подсказки к ней называют
  GNOME Keyring и KWallet, а Windows пользуется DPAPI, macOS связкой ключей. На macOS собственные меню приложения
  остаются внутри окна; в строке меню наверху экрана только стандартные меню приложения, «Правка» и «Окно».
- Автоматических обновлений нет: новую версию ставите вы сами со страницы выпусков проекта. «Настройки ▸ Приватность ▸
  Проверять новые версии» может сказать, что она вышла. [Обновление](../start/Updating.ru.md)
- Пока не проверено на настоящем компьютере: установка `.deb` через apt, `.rpm` через dnf в Fedora, готовый файл
  AppImage. Это проверяется только в CI.

## Подключение и чтение

- Пока не проверено на настоящей установке: подключение сверено с тестовыми серверами, которые отвечают так же, как
  ComfyUI, а не с настоящим ComfyUI, ComfyUI в Windows, настольным приложением ComfyUI или настоящим MCP-сервером.
- Прямо из ComfyUI нет описаний рядом с файлами моделей, README паков и отпечатков, поэтому «Найти в интернете» ищет
  только по имени файла. MCP-сервер, который умеет читать файлы, их добавляет.
  [Что даёт каждый способ](../connect/What-Each-Way-Shows.ru.md)
- Старый ComfyUI сообщает только имена моделей, без размеров и картинок.
- Официальный `comfy-mcp` от Comfy Org запускается как локальная команда, и подключить его пока нельзя; MCP-сервер, чьих
  инструментов приложение не знает, не используется.
- Окно контекста читается из доступного API Ollama, LM Studio, llama.cpp или vLLM. Автоматическая настройка и загрузка/выгрузка моделей требуют native API Ollama. Запуск/остановка/перезапуск поддерживаемых локальных служб Linux systemd доступны в [Службах](../interface/Settings-Services.ru.md). Другие ОС, контейнеры и произвольное удалённое администрирование не поддерживаются.
- Поиск моделей: Civitai находит файл точно по отпечатку; Hugging Face ищется по имени файла, и карточка говорит, что
  это догадка. Отпечаток большого файла сервер считает минутами, поэтому синхронизация его не считает.
- Пак нод описывается по его `pyproject.toml` и началу README; у пака без них видны только имя и версия.
- Когда у облачной модели нет своего поиска, помощник ищет через HTML-страницу DuckDuckGo, и это может перестать
  работать, когда страница изменится.

## Размер графа

- **Около тысячи нод работает медленно.** На графе примерно из 1000 нод перетаскивание и масштаб идут примерно с
  5 кадрами в секунду, а первая отрисовка занимает много секунд.
- **Предел 1500 нод и 3000 связей**, считая субграфы. Workflow или проект больше этого отклоняется, пока ничего не
  изменилось: «Этот граф слишком большой…». Самый большой из 1335 настоящих workflow, на которых проверялось
  приложение, состоит из 603 нод.
- Если в прошлый запуск холст не дорисовал граф, приложение один раз спрашивает: начать с пустого холста (граф
  останется в истории) или открыть граф снова.

## Граф

- Внутри субграфа можно создавать и редактировать другие субграфы и группы. Разбор вложенной ноды сохраняет граничные связи, внутренние рамки и известные соответствия внешних полей. Неоднозначное или неизвестное соответствие отклоняется без изменения графа.
- Workflow в старом формате (0.4) не может хранить субграф; приложение об этом говорит. Откройте его в свежем ComfyUI и
  сохраните заново или скопируйте его ноды в новый проект (он в формате 1). [Субграфы](../graph/Subgraphs.ru.md)
- Устаревшие ноды-группы из старых workflow показываются одной неизвестной нодой; сохраняются они как были.
- Входы, которые прибавляются по мере подключения, и отметки списков на входах пока не показываются.
- Точки связей ComfyUI можно двигать перетаскиванием и стрелками, удалять из меню по касанию и восстанавливать отменой. Это работает и внутри субграфов. Удаление точки сохраняет соединения нод. **Добавить точку связи** создаёт современную точку, а **Добавить старую ноду Reroute** — отдельную ноду редактора.
- Рамки групп изменяются мышью, касанием и клавиатурой; **Подогнать рамку к нодам** возвращает автоматический размер. Действие отменяется и работает внутри субграфов; native-прямоугольник и неизвестные поля сохраняются. ComfyUI вычисляет состав по экспортированной рамке; подробнее в [Группах](../graph/Groups.ru.md).
- Картинка или видео открываются, только если ComfyUI записал в них workflow. В картинке из другого места или
  присланной через мессенджер его обычно нет.

## Помощник и уроки

- Помощник строит и редактирует внутренние графы, включая определения из прошлых ходов. Уроки проверяют открытый холст или копию субграфа; ответы вложенных экземпляров сохраняются отдельно. Вынесенные параметры принадлежат выбранной копии, структура и остальные поля определения общие.
- Задача на паузе по пределу шагов или повторным неудачам сохраняется вместе с историей чата. После перезапуска **Проверить и продолжить** читает текущий граф и начинает новый ответ для оставшейся работы. Прежние команды не воспроизводятся. Для другого графа или неполной сохранённой задачи сначала доступно **Разобрать текущий граф**. При выключенной истории задача остаётся только в открытом окне.
- Качество ответов зависит от модели. Маленькие локальные модели с маленьким окном контекста теряют нить длинной
  сборки. [Окно контекста](../assistant/Context-Window.ru.md)
- Видеоуроки по WanVideoWrapper охватывают часть этого пака; у остальных его возможностей уроков нет.
- Черновики уроков и расширений сохраняются после перезапуска при включённой истории чата. Для проекта хранятся 20 последних черновиков уроков и 12 расширений. Примите урок или скачайте ZIP расширения для отдельной копии; очистка чата удаляет и его черновики.

## Доступность

- Стрелки не переводят фокус между нодами: они двигают выделенную ноду, а по нодам ходит `Tab`.
- Пока не проверено с настоящим экранным диктором.
- При размере интерфейса 200 процентов на экране 1080p окно не помещается.

# Сочетания клавиш

Полная таблица клавиш по умолчанию. «Справка ▸ Сочетания клавиш» (`F1`) показывает тот же список в приложении, с
вашими изменениями. «Настройки ▸ Сочетания клавиш» меняют или убирают любое из них: «Изменить», нажмите новые клавиши,
затем «Сохранить настройки».

Большинство сочетаний работает, когда курсор не в текстовом поле. «Сохранить проект», «Сохранить проект как…»,
«Открыть проект», «Новый проект», «Проверить граф» и `F1` работают везде.

## Клавиатуры и раскладки

- В латинской раскладке (QWERTY, AZERTY, QWERTZ, Dvorak) нажимайте клавишу, на которой нарисована буква или знак.
- В русской и другой нелатинской раскладке нажимайте клавишу на том же месте, что на американской клавиатуре:
  `Ctrl+Z` это клавиша, которая печатает «я». «Настройки ▸ Сочетания клавиш» там, где это важно, пишут «На этой
  раскладке: клавиша Я» или «На этой раскладке: вместе с Shift или AltGr».
- В macOS (сборка из исходников, не проверялась) вместо `Ctrl` нажимается `Cmd`.

## Переход по окну

| Клавиши | Что делает |
| --- | --- |
| `Alt` или `F10` | Переход в главное меню (у «Файл» видна рамка); по нему ходят стрелками. |
| `F6` и `Shift+F6` | Переход между главным меню, панелью инструментов, библиотекой, холстом, правой панелью и строкой состояния. |
| `F8` | Переход к уведомлениям. |
| `Shift+F10` или клавиша меню | Открывает контекстное меню холста или выделенной ноды. |
| `F1` | Сочетания клавиш (и во время набора текста, но не поверх другого окна). |

## Правка

| Клавиши | Команда |
| --- | --- |
| `Ctrl+Z` | Отменить |
| `Ctrl+Shift+Z` или `Ctrl+Y` | Повторить |
| `Ctrl+C` | Копировать |
| `Ctrl+X` | Вырезать |
| `Ctrl+V` | Вставить |
| `Ctrl+D` | Дублировать |
| `Ctrl+A` | Выделить всё |
| `Delete` или `Backspace` | Удалить выделенное |

## Граф

| Клавиши | Команда |
| --- | --- |
| `Ctrl+K` | Добавить ноду… |
| `Ctrl+G` | Собрать субграф из выделенного |
| `Ctrl+Shift+G` | Собрать группу из выделенного |
| `Ctrl+Shift+B` | Обойти: ComfyUI пропускает выделенные ноды. Повторное нажатие снова включает их. |
| `Ctrl+M` | Выключить: ComfyUI не запускает выделенные ноды. Повторное нажатие отменяет. |
| `Alt+C` | Свернуть (или развернуть) выделенные ноды |
| `Ctrl+Shift+L` | Разложить граф |
| `Ctrl+Shift+C` | Проверить граф |

`Ctrl+B` здесь не обход: он показывает или прячет библиотеку.

| Клавиши | Команда |
| --- | --- |

| `Ctrl+0` | Масштаб 100 % |

| `Ctrl+Alt+-` | Мельче (весь интерфейс) |

## Помощник и справка

| Клавиши | Что делает |
| --- | --- |
| `Ctrl+/` | Написать помощнику |
| `Enter` | Отправляет сообщение; `Shift+Enter` начинает новую строку. |
| `↑` и `↓` в пустом поле сообщения | Возвращают прежние вопросы. |
| `F1` | Сочетания клавиш |

## На холсте

| Клавиши | Что делает |
| --- | --- |
| `Tab` | Переходит по нодам. Связь достижима через `Tab`, когда выделена одна из её нод. |
| `Enter` или `Пробел` | Выбирает ноду, на которой фокус. |
| Стрелки | Двигают выделенную ноду. Фокус на другую ноду они не переводят. |
| `Delete` или `Backspace` | Удаляет выделенную ноду или связь; фокус переходит на ближайшую ноду. |
| `Shift+F10` на входе или выходе | Открывает его меню: выберите «Предложить связь», затем `Enter` соединяет. |
| `Ctrl`, `Shift` или `Cmd` + щелчок | Добавляет ноду к выделению. |
| `Esc` | Отменяет рисуемую связь или правку. |

Заметка на холсте: двойной щелчок или `Enter` открывает её для записи, `Ctrl+Enter` или щелчок в другом месте
сохраняет, `Esc` оставляет прежний текст.

## В библиотеке

| Клавиши | Что делает |
| --- | --- |
| `↓` в поиске | Переходит в список. |
| `Пробел` | Открывает карточку ноды; `Esc` возвращает в список. |
| `Enter` | Добавляет ноду на холст. На вкладке «Модели» открывает карточку модели. |

## В экскурсиях

| Клавиши | Что делает |
| --- | --- |
| `→` и `←` | Следующий и предыдущий шаг («Граф ▸ Экскурсия по графу»; в «Справка ▸ Тур по окну», когда фокус на карточке). |
| `Пробел` | Запускает или приостанавливает экскурсию по графу. |
| `Esc` | Заканчивает экскурсию. |

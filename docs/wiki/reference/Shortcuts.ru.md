# Сочетания клавиш

Полная таблица. «Справка ▸ Сочетания клавиш» (`F1`) показывает тот же список в приложении. Сочетания работают и в
русской раскладке: приложение смотрит на клавишу, а не на букву, которую она печатает.

В macOS (сборка из исходников) вместо `Ctrl` нажимается `Cmd`.

## Меню

| Клавиши | Что делает |
| --- | --- |
| `Alt` или `F10` | Открывает строку меню; по ней ходят стрелками. |
| `Shift+F10` или клавиша меню | Открывает контекстное меню холста или выделенной ноды. |

## Файл

| Клавиши | Команда |
| --- | --- |
| `Ctrl+N` | Новый проект |
| `Ctrl+O` | Открыть проект |
| `Ctrl+S` | Сохранить проект |
| `Ctrl+Shift+S` | Сохранить проект как… |
| `Ctrl+I` | Открыть workflow… |
| `Ctrl+E` | Сохранить workflow для ComfyUI… |
| `Ctrl+,` | Настройки… |
| `Ctrl+Q` | Выход |

## Правка

| Клавиши | Команда |
| --- | --- |
| `Ctrl+Z` | Отменить |
| `Ctrl+Shift+Z` или `Ctrl+Y` | Повторить |
| `Ctrl+C` | Копировать |
| `Ctrl+X` | Вырезать |
| `Ctrl+V` | Вставить |
| `Ctrl+D` | Дублировать |
| `Ctrl+A` | Выделить всё |
| `Delete` или `Backspace` | Удалить выделенное |

## Граф

| Клавиши | Команда |
| --- | --- |
| `Ctrl+K` | Добавить ноду… |
| `Ctrl+G` | Собрать субграф из выделенного |
| `Alt+C` | Свернуть или развернуть выделенные ноды |
| `Ctrl+Shift+L` | Разложить граф |
| `Ctrl+Shift+C` | Проверить граф |

## Вид

| Клавиши | Команда |
| --- | --- |
| `Shift+1` | Показать всё |
| `Ctrl+=` | Приблизить |
| `Ctrl+-` | Отдалить |
| `Ctrl+0` | Масштаб 100 % |
| `Ctrl+B` | Библиотека |
| `Ctrl+J` | Правая панель |
| `Esc` | Остановить экскурсию или просмотр истории |

## Помощник и справка

| Клавиши | Команда |
| --- | --- |
| `Ctrl+/` | Написать помощнику |
| `Enter` | Отправляет сообщение; `Shift+Enter` начинает новую строку. |
| `F1` | Сочетания клавиш |

## На холсте

| Клавиши | Что делает |
| --- | --- |
| `Enter` или `Пробел` | Выделяет ноду или связь, на которой фокус. |
| Стрелки | Двигают выделенную ноду. |
| `Ctrl` + щелчок | Добавляет ноду к выделению. |
| `Esc` | Отменяет рисуемую связь или правку. |

## В экскурсии по графу

| Клавиши | Что делает |
| --- | --- |
| `→` и `←` | Следующий и предыдущий шаг. |
| `Пробел` | Запускает или приостанавливает экскурсию. |
| `Esc` | Заканчивает экскурсию. |

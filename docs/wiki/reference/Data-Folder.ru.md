# Папка с данными

Каждый файл, который хранит приложение, где он лежит и зачем. Файлов проектов и workflow здесь нет: они там, куда вы
их сохранили.

## Где она

- Linux: `~/.config/nodewise-studio`. Версия 0.9 хранила данные в папке со старым названием приложения; первый
  запуск 1.0 переносит её сюда ([Обновление](../start/Updating.ru.md)).
- Другая папка, если запустить приложение с `--user-data-dir=<папка>` ([Командная строка](Command-Line.ru.md)).
- Windows и macOS (сборка из исходников): см. [Windows](../dev/Building-On-Windows.ru.md) и
  [macOS](../dev/Building-On-macOS.ru.md).

Её открывает «Справка ▸ О программе ▸ Открыть папку с данными». В Linux папка доступна для чтения только вашему
пользователю (права 0700), а база, её журнальные файлы и файлы, которые приложение пишет для вас, читает только ваш
пользователь (права 0600).

## Что внутри

| Файл или папка | Что в нём | Размер |
| --- | --- | --- |
| `comfyui-desktop.db` (рядом `-wal` и `-shm`) | База: настройки, каталог, прочитанный из ComfyUI, граф и его история, разговоры, сохранённые ключи, зашифрованные хранилищем паролей системы. | Растёт с историей; самые старые версии удаляются. |
| `comfyui-desktop.db.before-v<N>.bak` | Копия базы перед обновлением её схемы до версии N. Хранится только самая новая. | Как сама база. |
| `comfyui-desktop.db.damaged-<дата>` | Повреждённая база, которую приложение отложило, когда вы выбрали «Начать с пустыми данными». Приложение её не удаляет. | |
| `logs/main.log`, `main.log.1`, `main.log.2` | Журнал: что делало приложение и какие ошибки встретило. Ключи и токены скрыты, домашняя папка записана как `~`. | 5 МБ на файл, три файла. |
| `logs/model/` | Журнал общения с моделью, по файлу на ответ, пока включено «Настройки ▸ Приватность ▸ Вести журнал общения с моделью». | Не больше 300 файлов и 150 МБ; первыми уходят самые старые. |
| `model-previews/` | Картинки моделей, загруженные для карточек моделей. «Настройки ▸ Приватность ▸ Очистить кэш картинок» опустошает папку; она очищается и при смене адреса сервера. | Не больше 3000 файлов и 512 МБ; первыми уходят самые старые. |
| `lessons/` | «Мои уроки»: по файлу `.lesson.json` на каждый урок, который вы сделали, импортировали или оставили из черновика помощника. Имя файла строится из проверенного id самого урока. | Не больше 500 уроков. |
| `recent-files.json` | «Файл ▸ Недавние файлы»: последние 10 открытых или сохранённых файлов и имя файла, из которого пришёл каждый граф. Только пути и время, никогда не содержимое. | Крошечный. |
| `graph-start.json` | Безопасный запуск: отметка «рисую» перед тем, как холст рисует граф, и «нарисовано» после. Если запуск находит оставшуюся отметку «рисую», приложение спрашивает, прежде чем рисовать этот граф снова. | Крошечный. |
| `window-state.json` | Размер и положение окна. | Крошечный. |
| `profile-adopted.json` | Оставляет первый запуск 1.0, когда перенёс сюда папку версии 0.9; удаляется, как только приложение вам об этом сказало. | Крошечный. |
| `update-check.json` | Последний ответ о новых версиях, только если включено «Проверять новые версии». | Крошечный. |
| `password-store.json` | Какое хранилище паролей использовать, если вы выбрали его в «Настройки ▸ Приватность». Не секрет. | Крошечный. |
| `model-key.json` | Ключ модели без шифрования, только если вы выбрали для него это место. Читать может только ваш пользователь. | Крошечный. |
| `mcp-token.json` | Токен доступа к серверу без шифрования, только если вы выбрали для него это место. Читать может только ваш пользователь. | Крошечный. |

Chromium, который рисует окно, тоже держит здесь несколько своих папок (кэши, локальное хранилище). В них нет ничего
нужного приложению; их можно удалить, пока приложение закрыто.

## Как очистить

- Забыть только ключи: «Настройки ▸ Приватность ▸ Забыть все ключи и токены».
- Начать с нуля: закройте приложение и удалите всю папку. Ключи в хранилище паролей системы останутся, пока вы их не
  забудете: см. [Удаление](../start/Removing.ru.md).
- Перенести: закройте приложение и скопируйте папку; запустите приложение с `--user-data-dir`, указывающим на копию.

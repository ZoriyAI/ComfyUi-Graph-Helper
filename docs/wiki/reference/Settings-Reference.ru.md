# Все настройки

Каждая настройка в «Файл ▸ Настройки…» (`Ctrl+,`), её значение по умолчанию и где она хранится. Все настройки
хранятся в базе в [папке с данными](Data-Folder.ru.md); ключи и токены хранятся отдельно (см.
[Безопасность](../trust/Security.ru.md)). Большинство настроек применяется по кнопке **«Сохранить настройки»**;
немногие, что применяются сразу, говорят об этом в окне.

Что делает каждая настройка, подробно: страницы о настройках в разделе [Интерфейс](../interface/README.ru.md),
начиная с [Настройки](../interface/Settings.ru.md).

## Помощник

| Настройка | По умолчанию | Значения |
| --- | --- | --- |
| Кто отвечает | не выбрано | Проверочный режим, OpenAI, Anthropic, Google, своя модель |
| Модель | пусто | любое название модели; предлагаются подсказки |
| Адрес сервера | пусто; обязателен для своей модели | адрес `http` или `https` |
| Ключ модели | не хранится | отдельно для каждого поставщика и адреса |
| Когда я прошу изменение | Сначала предложить (серые черновики) | Сначала предложить, Строить сразу |
| Шагов на ответ | 60 | от 4 до 200 |
| Окно контекста (токены) | 0 (авто) | 0 или до 10 000 000 |
| Разрешить поиск в интернете | включено | включено, выключено |
| Разрешить читать веб-страницы | включено | включено, выключено |
| Язык ответов | Как в интерфейсе | Как в интерфейсе, Английский, Русский |
| Длина ответов | Коротко | Коротко, Подробнее |

## Сочетания клавиш

Сочетание каждой команды можно изменить, убрать или сбросить; хранятся только ваши изменения. Сочетания по
умолчанию: [Сочетания клавиш](Shortcuts.ru.md).

| Настройка | По умолчанию | Значения |

Здесь же: **«Где хранятся ключи»**, **«Забыть все ключи и токены»** и **«Очистить историю чата»**.

## Что запоминается без настройки

Приложение само, не спрашивая, запоминает размер и положение окна (`window-state.json`), какой урок открыт, какие
шаги уроков вы прочитали и какие уроки прошли.

# 1.2.6 — groups and unpacking inside subgraphs

Create, rename, colour, move and remove **groups inside subgraphs**, and use **Dissolve subgraph** on a nested node. These operations now follow the displayed graph level and its undo history.

- Imported inner groups are visible and editable. Whole group frames travel with nodes when a selection is wrapped into another subgraph, and return when it is unpacked. Native project save and ComfyUI export preserve their names, colours and extension fields.
- Nested unpacking preserves boundary connections, inner frames and native link data. Promoted controls are retargeted through parent nodes while each instance retains its own values. Shared definitions remain while still used. Ambiguous widget layouts are refused without changing the graph.
- Group titles have a **⋯** menu for touch use, including rename, colour and removal. Dragging a title moves its nodes in one undo step. Equal node/group numbers on different levels stay separate. On narrow screens, subgraph navigation stays clear of the touch toolbar.
- Help now explains the same operations on the main canvas and inside subgraphs. All improvements from 1.2.5, including local service controls and understandable synchronization profiles, are included.

Checked through focused command/codec/project tests and the actual Electron editor at desktop and 390px widths, including drag, touch-accessible menus, unpacking, undo and export. Real physical-phone operation and execution of arbitrary custom ComfyUI widgets remain outside this proof.

Linux x64: `.deb`, AppImage, portable `.tar.gz`, source-build scripts for Windows/macOS, SBOM and checksums. Close the old application before installing the update.

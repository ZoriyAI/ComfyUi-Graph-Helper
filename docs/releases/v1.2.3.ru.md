# NodeWise Studio 1.2.3 — исправление чтения метаданных

Исправлена синхронизация, которая после ответа MCP `Not connected` снова останавливалась на одном файле. Резервный маршрут ComfyUI возвращает HTTP 404 и для заголовков больше своего ограничения 1 МиБ, и для файлов без встроенных метаданных. Прежде такая ошибка первого файла прерывала весь проход.

Теперь приложение проверяет не более пяти других заголовков из каталога. Переход на разрешённый адрес ComfyUI выполняется только после настоящего ответа с метаданными. Недоступные файлы попадают в отдельный отчёт, остальные продолжают читаться. Результаты проверки повторно используются между пакетами; поддержаны пакет из одного файла и следующие попытки чтения последнего недоступного файла. Отчёт находится в «Настройки → Синхронизация».

Отсутствующий маршрут, выключенный сервер и отмена не считаются успешным чтением. Большие или отсутствующие метаданные не выдумываются и не помечаются прочитанными. Исправлено восстановление в приложении; внутренний читатель MCP-сервера не перезапускается и не изменяется.

Проверены целевые сценарии: отключённый MCP, первый резервный ответ 404 и здоровые следующие файлы, отсутствие маршрута, потеря сети, отмена и повторная синхронизация. Файлы моделей приложение не изменяет. Linux x64: deb, AppImage и переносной архив; скрипты сборки Windows/macOS.

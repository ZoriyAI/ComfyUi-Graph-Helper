# 1.2.5 — service controls and understandable synchronization settings

**Settings → Services** discovers supported Linux systemd services on the NodeWise computer and offers start, stop, restart and live status. The same controls are available from a paired phone. **Sync** now offers explained Gentle, Balanced and Faster reading profiles instead of leading with batch sizes and millisecond pauses.

- Service rows show exact names, user/system scope, state and reported RAM. Mutations revalidate the displayed service identity and confirm the resulting state. Stop/restart explain effects on other applications; system services use the host's OS authorization dialog. No shell commands or service-file editing are exposed.
- The sync repair center links directly to Services. A running process is distinguished from a ready ComfyUI/MCP connection.
- Common synchronization intervals have readable names. Existing custom values remain intact; detailed batch/pause controls stay in Advanced settings. Changes apply with Save settings.
- Current help explains supported service families, phone/host behavior, authorization and limits. The audit also corrected the outdated claim that inner subgraph creation was unavailable; nested group/dissolve work remains a separate delivery.

Service discovery was read on a Linux host without changing its services. Action/state/error/authorization boundaries were checked with an isolated transport and the actual Electron IPC/settings flow at desktop and 390px widths. A real privileged authorization dialog and physical-phone operation are not claimed. Model configuration still requires the provider's native capability; this release does not install services or remotely administer arbitrary operating systems.

Linux x64: `.deb`, AppImage, portable `.tar.gz`, source-build scripts for Windows/macOS, SBOM and checksums. Close the old application before installing the update.

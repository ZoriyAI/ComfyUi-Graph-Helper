# 1.3.0

Обновлены все уроки, восстановление работы помощника после остановки, совместимость с современными графами ComfyUI и редактирование больших графов. При недоступном MCP синхронизация может продолжить чтение напрямую через ComfyUI; описания моделей и их переводы имеют отдельный понятный прогресс.

- **Учитесь на том графе, который редактируете.** Все 95 уроков содержат цель, подготовку, конкретные ошибки, самопроверку, самостоятельную практику и отдельную оценку построения, запуска и результата. У вложенных экземпляров субграфа сохраняются собственные ответы и вынесенные значения.
- **Продолжайте прерванную работу.** При включённой истории после перезапуска сохраняются приостановленные задачи агента, черновики уроков и расширений. Продолжение сначала читает текущий граф. Уже выполненные изменения учитываются после сокращения контекста, чтобы не создавать ноды повторно. Очистка истории удаляет и её черновики.
- **Сохраняйте настройки ComfyUI.** Поддерживаются объявленные в каталоге динамические варианты, растущие входы, группы полей, согласование типов, списки, именованные значения и современные внешние поля субграфов. Точки связей и рамки групп редактируются с отменой, в том числе внутри субграфов. Неизвестные данные сторонних виджетов сохраняются.
- **Читайте модели без остановки всего каталога.** При недоступном MCP приложение может читать настроенный ComfyUI напрямую, не передавая ему учётные данные MCP. У перевода есть очередь, пауза, повтор и кэш; оригинальные описания и слова активации сохраняются.
- **Удобнее работайте с большими графами.** Отрисовка видимых карточек, страницы результатов проверки и устранение лишних обновлений уменьшают задержки. В измерении на 1000 нодах готовность ускорилась с 25,00 до 4,69 секунды; расход памяти остаётся значительным. Клавиатурный фокус показывает ноду ниже панели, а сообщения диктора не повторяются на каждом шаге.
- **Восстанавливайте и обслуживайте работу.** История показывает измеренный объём данных и предлагает очистку с предварительным просмотром, сохраняя текущую работу и активные задачи. Из больших MP4, MOV, MKV и WebM извлекаются встроенные workflow без чтения всех кадров, в том числе в подключённом браузере.
- **Получайте конкретные подсказки.** Проверены все 50 экранов помощи, включая возврат к выбранной внутренней ноде. Подсказки по памяти показывают распознанные размеры и измеренный пример цепочки vision → изображение. В разделе «О программе» появился экспорт версионного публичного каталога уроков, маршрутов и шаблонов для портала, без пользовательских проектов.
- **Настройки объясняются с учётом ОС.** Выбор хранилищ Linux показывается только в Linux; Windows и macOS объясняют автоматическую системную защиту. Обновлены зависимости и действующая справка.
- **Элементы управления остаются доступны.** Вписывание холста учитывает рамки групп и оставляет место для навигации внутри субграфа. Расчёт высоты текстовых полей соответствует увеличенным элементам управления. В узких импортированных карточках числовые поля и кнопки seed получают достаточно места; сенсорный режим учитывает увеличенные кнопки. Журнал объясняет остановку запроса до отправки, если окно контекста слишком мало.

Реальные локальные проверки включили каталог ComfyUI с 3375 типами нод и 797 файлами моделей, 678 официальных workflow, построение и продолжение работы настоящего агента, освобождение памяти native Ollama, ноды vision и embeddings и цепочку vision → diffusion → изображение. Границы результатов изложены в [отчётах проверки](https://github.com/ZoriyAI/nodewise-studio/blob/v1.3.0/docs/research/2026-11-17-native-compatibility.md); это не гарантия для всех расширений и моделей.

Для Linux x64 доступны `.deb`, `.rpm`, AppImage и переносимый архив. Windows/macOS устанавливаются скриптами из исходников. Физические Android/iOS, независимая проверка новичками, подпись издателя и публикация портала остаются отдельной приёмкой; этот выпуск не объявляет их завершёнными.

Установите новый пакет поверх прежнего: настройки и проекты остаются в папке данных. Для работы с телефона держите NodeWise запущенным. Генерация выполняется в ComfyUI после экспорта графа; поддерживаемые модели Ollama, которыми пользовался NodeWise, могут освобождаться при выходе из настольного приложения.

# 1.2.2 — исправление синхронизации

Синхронизация переиспользует уже прочитанный каталог ComfyUI и дочитывает метаданные через проверенный адрес ComfyUI,
если внутренний обработчик MCP отвечает «Not connected» даже после переподключения.

- Полный `/object_info` читается до постраничного discovery. Его список классов заменяет повторные запросы страниц:
  для каталога из 3375 классов устранены 34 дополнительных запроса, каждый из которых мог запускать сканирование файлов
  на сервере. Список паков и моделей продолжает обновляться. Если полный каталог недоступен, остаётся постраничное чтение.
- Классы с непонятными определениями параметров остаются в каталоге; читаемые параметры и порядок виджетов сохраняются.
- При потере MCP-соединения чтение заголовков моделей после ограниченного переподключения может продолжиться через
  `/view_metadata` того адреса ComfyUI, чей каталог успешно прочитан в этой синхронизации. Проверки адреса и отмены
  сохраняются; токен MCP не передаётся ComfyUI. Последующие свежие синхронизации не перечитывают уже прочитанные заголовки.
- Ошибка или отсутствующий маршрут резервного чтения не помечают модель прочитанной. Если оба способа недоступны,
  приложение сохраняет предупреждение или ошибку; повреждение модели по одному обрыву соединения не предполагается.

Linux x64: `.deb`, AppImage и переносной `.tar.gz`; также скрипты сборки для Windows/macOS, перечень компонентов
и `SHA256SUMS`. Перед установкой закройте прежнее приложение. Проекты и настройки сохраняются.

Исправление проверено на локальных тестовых серверах и воспроизведении каталога из 3375 классов, включая обрыв
соединения, повторный запуск, неподдерживаемый маршрут, смену/отмену адреса и сохранение каталога. Работа на реальном
сервере владельца пока не проверена. Изменений в установленный ComfyUI или его MCP-сервис обновление не вносит.

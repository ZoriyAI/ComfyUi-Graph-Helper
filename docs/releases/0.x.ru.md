# Версии с 0.2.0 по 0.8.0

Версии с 0.2.0 по 0.8.0 выходили закрыто, до того как проект стал публичным. Их полные заметки не опубликованы.
Коротко:

- **0.8.0**: ещё пять уроков на WanVideoWrapper (UniAnimate, два голоса в InfiniteTalk, FantasyTalking, Ovi,
  ReCamMaster); «Новый проект» спрашивает, прежде чем очистить граф, который ни разу не сохраняли.
- **0.7.0**: картинки-примеры с Hugging Face в карточках моделей; уроки о VACE, анимации по позе и говорящем
  портрете.
- **0.6.0**: описания паков нод, описания моделей из интернета по вашей кнопке, первые уроки на WanVideoWrapper.
- **0.5.0**: карточки моделей и нод; советы по описаниям (промптам) в проверке.
- **0.4.1**: уроки подходят к большему числу графов и точнее говорят, чего не хватает шагу.
- **0.4.0**: «Учиться», третий способ работать с помощником: уроки, которые вы собираете руками, с проверкой
  каждого шага.
- **0.3.2**: каждый элемент сохраняет размер и место при любом масштабе холста, размере окна и масштабе экрана.
- **0.3.1**: ни на одном экране нет служебных слов и обрезанных текстов; каждый экран проверяется
  автоматически на обоих языках.
- **0.3.0**: поля нод стали настоящими элементами управления, граф раскладывается сам, сборка рассказана одной
  карточкой, у разговора с моделью появился журнал, который можно сохранить.
- **0.2.7**: чат и правая панель говорят простыми словами.
- **0.2.6**: настройки помощника для людей, а не для программистов.
- **0.2.5**: токен доступа применяется сразу, как только вставлен.
- **0.2.4**: настройки предлагают списком то, что можно прочитать из системы.
- **0.2.3**: исправления после первой установки.
- **0.2.2**: ни один порт не зашит: каждый адрес задаётся целиком, с портом.
- **0.2.1**: токен доступа к MCP-серверу можно хранить в хранилище паролей системы.
- **0.2.0**: первая устанавливаемая версия: помощник, который объясняет графы ComfyUI и учит их строить на живом
  холсте.

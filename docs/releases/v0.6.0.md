# ComfyUI Graph Helper v0.6.0

Три вещи, которых не хватало в 0.5.0: описания паков нод, описания моделей из интернета и уроки на
WanVideoWrapper.

## Что пак говорит о себе

- **Карточка ноды показывает описание её пака.** Программа читает у пака его `pyproject.toml` и начало
  README: короткое описание, первые абзацы и ссылку на репозиторий. Длинный текст свёрнут, его можно
  развернуть. Ссылку можно скопировать.
- Читается при синхронизации, один раз на версию пака. Обновили пак: прочитается заново.
- Помощник тоже видит это описание, когда объясняет ноду.

## Описание модели из интернета

- **Кнопка «Найти в интернете» в карточке модели.** Она нужна, когда рядом с файлом ничего не лежит или там нет
  данных с Civitai.
  - Civitai находит файл по отпечатку, это точно тот файл. Отпечаток обычно уже записан менеджером моделей. Если
    нет, его посчитает ваш сервер. Большой файл считается минутами, карточка об этом говорит.
  - Если Civitai файла не знает, программа ищет на Hugging Face по имени файла. Это догадка, и карточка так и
    пишет: «Найдено по имени файла, может быть не та модель».
  - Карточка показывает название, автора, для какой модели сделано, слова LoRA, описание, примеры описаний,
    картинку-пример с Civitai и ссылку на страницу.
- **Что уходит в интернет.** Только отпечаток файла или его имя, и только на civitai.com и huggingface.co. Без
  вашей кнопки программа туда не ходит.
- **Для всех файлов сразу.** В «Настройки ▸ Приватность» можно включить поиск при синхронизации. По умолчанию
  выключено. Включённый поиск спрашивает по одному файлу в секунду, не больше 200 за раз, и только для файлов,
  у которых отпечаток уже известен.
- **Отмеченное сайтом как взрослое закрыто** так же, как отмеченное в файлах рядом с моделью: картинка не
  скачивается, примеры описаний не показываются, пока вы их не откроете.
- Найденное хранится у программы и при следующем запуске не запрашивается снова.

## Уроки на WanVideoWrapper

- **Урок «Видео на WanVideoWrapper».** Граф Wan 2.2 на нодах пака: две модели, его чтение текста, одна нода
  с обоими описаниями, два прохода с разделением шагов, сдвиг шума и строгость прямо в сэмплере. Сказано, что
  делать при нехватке памяти видеокарты, как подключать LoRA к загрузчику и как ускорить до четырёх шагов.
- **Урок «Видео из картинки на WanVideoWrapper».** Тот же граф, начатый с вашей картинки, и два поля, которые
  добавляют движения.
- Входы и выходы нод в уроках взяты из самого пака, установленного у вас.
- **«Проверить» читает и описания этого пака:** записи из других программ, второй текст при `cfg` 1, слова LoRA,
  выбранной для загрузчика.

## Мелочи

- Длинное имя типа у порта ноды (у пака WanVideoWrapper есть `WANVIDIMAGE_CLIPEMBEDS`) вылезало за край ноды.
  Теперь оно сокращается многоточием, полное имя во всплывающей подсказке.
- Совет «второй текст не действует при `cfg` 1» говорится один раз на текст, а не по разу на каждый сэмплер.

Границы прежние. В ComfyUI программа ничего не меняет и ничего не скачивает. Сервер она только читает:
описания рядом с моделями, файлы описания паков и отпечаток файла модели по вашей кнопке.

Установка: `sudo apt install ./comfyui-graph-builder_*.deb`. Настройки, ключи и проекты сохраняются.

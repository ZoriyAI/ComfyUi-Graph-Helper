# ComfyUI Graph Helper v0.2.7

Чат и правая панель — без слов программиста.

- **Чат.** Пустой чат предлагает человеческое: «Напишите, что хотите получить, например «хочу картинку по тексту»,
  или откройте workflow из ComfyUI». Упоминание тестовой заглушки видно только тогда, когда она действительно
  включена. На карточках действий помощника больше нет внутреннего имени инструмента, а «Аргументы» стали
  «Подробностями».
- **Правая панель.** «Инспектор» стал «Свойствами»; блок «Процесс / Название процесса / Заметки процесса»
  — «Этот граф / Название / Заметки / Сохранить название и заметки».
- **История.** «Ревизия 1» в строке состояния стала «Шаг истории 1»; повтор сборки и объяснения говорят «шаг».
- **Файлы.** Везде одно слово — workflow: «Открыть workflow», «Сохранить workflow для ComfyUI», понятные
  сообщения, когда файл не тот («Это файл для API, а не workflow холста…»). «Снимок каталога» стал
  «Списком нод из файла», ошибки каталога говорят про файл, а не про JSON и схему.
- **Помощник.** «Провайдер чата» на панели стал «Кто отвечает».

Установка: `sudo apt install ./comfyui-graph-builder_*.deb`.

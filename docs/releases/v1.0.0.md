# NodeWise Studio 1.0.0

The app is now NodeWise Studio. A plain ComfyUI address is enough to connect, 79 lessons in twelve groups and lessons
of your own, a first hour that leads a newcomer, an assistant that asks before it changes your work, editing as in
ComfyUI, motion that explains, accessibility from the keyboard to the screen reader, and caps that keep a broken
file from hanging the window. Linux only.

## The new name, and the upgrade from 0.9

The app is now NodeWise Studio. The `.deb` and `.rpm` replace the 0.9 package. On its first start the app moves the
0.9 data folder to `~/.config/nodewise-studio`. Keys saved in GNOME Keyring or KWallet must be entered again (keys in
the key file are kept). Project files from 0.9 still open; new ones end in `.nodewise.json`.

A window "NodeWise Studio has your work" says once where your work is now. If 0.9 is still open, "Version 0.9 is
still open" asks you to quit it first. The old keyring entry stays and can be deleted in your keyring manager. How to
go back to 0.9: [Updating](../wiki/start/Updating.md#from-version-09-to-10).

## Connect

- The address you open ComfyUI at in the browser is all the app needs. Settings ▸ Connection starts with the ComfyUI
  address, **Check ComfyUI** and **Find on this computer** (ports 8188 and 8000).
- An MCP server is optional. **Test server** names the kind it is: a full catalog, a model list, a checkpoint list,
  or unknown (then nothing is read through it).
- Every message about the connection says its cause in plain words: a missing `http://`, a typo in the address,
  ComfyUI started without `--listen`, an MCP address in the ComfyUI field, a sign-in page in between.
- Every request to ComfyUI goes through one read-only gate: `GET` only, on a short list of routes.

## Canvas and files

- File ▸ Open workflow… also opens the pictures and videos ComfyUI saves, and files in the API format, laid out from
  left to right. A file dropped on the window, or named on the command line, opens the same way.
- File ▸ Open recent (the last 10 files) and File ▸ Examples (the finished graph of a lesson, made of your nodes).
- After Save workflow for ComfyUI…, the card "Run it in ComfyUI" shows the three steps; Help ▸ Explain a ComfyUI
  error… reads an error ComfyUI showed and points at the node it names.
- Editing as in ComfyUI: Bypass (`Ctrl+Shift+B`), Mute (`Ctrl+M`), node and group colours ComfyUI shows, Insert node…
  on a link, Replace with…, notes written in place, Add reroute, Add to group and Take out of group, Make a group from
  selection (`Ctrl+Shift+G`).
- The node search finds nodes by what they do, in Russian too, marks paid, outdated and experimental nodes, and puts
  recent nodes first.
- A seed shows what happens after a run (fixed, increment, decrement, randomize).
- Every save dialog asks before it replaces an existing file.

## Lessons

- 79 lessons in twelve groups: ComfyUI basics, Pictures: first steps, Video, WanVideoWrapper, Pictures: models,
  Video: the anchor picture, Packs and tools, Pictures: techniques, Sound and speech, 3D, Faces and characters, and
  For adults (18+).
- A step that takes a model file names the kind it wants and says in words why a file is the wrong one; a value that
  is wrong comes with the reason the step asks for it.
- **My lessons:** File ▸ Make a lesson from this graph, an editor, a try from an empty canvas, export to a
  `.lesson.json` file and import. A lesson file is data only. The assistant can draft a lesson that you keep or
  discard. A refused lesson file says which rule it breaks, in your language. A lesson open from My lessons comes
  back after a restart.
- "Still to do" names each of two alike nodes by what it is in that lesson.
- The lessons for adults teach the technique for lawful, consensual 18+ work. They stay closed until you turn on
  Settings ▸ Privacy ▸ Adult content (18+) and confirm you are 18 or older; the app's content rules apply to them.
- Words of the glossary are underlined where they first appear and explain themselves on hover or `Tab`.

## The first hour

- The app speaks your system's language; a button on the welcome card switches between Русский and English.
- The tour of the window runs once on the first start (Help ▸ Tour of the window brings it back).
- The welcome card offers three ways to start: take a lesson, open an example, ask the assistant. "I have no ComfyUI
  yet" explains ComfyUI and opens its download page on a click.

## The assistant

- Who answers: OpenAI, Anthropic, Google Gemini, any OpenAI-compatible cloud service at its own `https` address, or
  your own server (Ollama, LM Studio, vLLM, the llama.cpp server). Each card says which model to take, what it costs,
  and what goes out with a question.
- Find local servers looks at ports 11434, 1234, 8000 and 8080. With a small context window, Ollama can make a copy of
  the model with a 16 384-token window, without a download.
- A proxy for cloud requests, if your network needs one; your own server is always reached directly.
- In Build, the assistant changes only what it placed itself. A change to your own nodes, values, notes or links is a
  grey draft that waits for you: Accept all or Reject all.
- The chat keeps its history and loads older messages as you scroll; `↑` and `↓` bring back earlier questions. A
  stopped answer says so; a model that cannot call tools says it answered without them.

## Checks

- Check graph marks every node with a finding: raspberry where the graph will not run, amber for the rest. Bypassed
  and muted nodes are no longer reported.
- A field with a built-in note shows an "i" beside its name.

## Look and motion

- One motion setting for everything that moves: System, On, Reduced, Off. The camera takes longer the farther it
  goes; a lesson step lights its place and dims the rest; the check runs a wave over the nodes it marked; the
  history shows what each version changed.
- A new app icon, a calmer status bar and welcome card, and group names readable at any zoom in the overview.

## Accessibility

- `F6` moves between the areas of the window, `F8` goes to the notifications, `F1` opens the shortcuts while you type.
- Nodes, links and inputs have spoken names in the interface language; a finished answer is read once; lesson steps
  and sync are announced.
- Interface size from 80 to 200 percent (`Ctrl+Alt+=`, `Ctrl+Alt+-`, `Ctrl+Alt+0`).
- Shortcuts follow your keyboard: the key with the letter on a Latin layout, the key in the US place on a Russian one.

## Safety

- A graph larger than 1500 nodes or 3000 links is refused before anything changes. If the canvas did not finish
  drawing a graph at the last start, the app asks before drawing it again.
- Keys of the services paid ComfyUI nodes use (Replicate, fal, ElevenLabs, Runway, Tavily, Perplexity), and long
  random strings in any field, are caught before a file is written.
- A model card marks the formats that can run code (`.ckpt`, `.pt`, `.pth`, `.bin`); the check and the lessons say
  to install node packs only through ComfyUI Manager or from an author you trust.
- Copy diagnostics and a saved conversation log hold no address of your own servers. The spell checker downloads no
  dictionaries. The database, its journal files and the start mark are readable by your user only.
- The update check is off by default; when on, it asks the releases page once a day and downloads nothing.

## Packages

Linux x64: `nodewise-studio_1.0.0_amd64.deb`, `nodewise-studio-1.0.0-1.x86_64.rpm`,
`nodewise-studio-1.0.0-x86_64.AppImage` and `nodewise-studio-1.0.0-linux-x64.tar.gz` with `run.sh`, `install.sh` and
`uninstall.sh`, with `SHA256SUMS`, an SBOM and a build provenance attestation. There are no ARM builds. Windows and
macOS are not supported; running from source there is not tried.

## What the checks do not prove

A clean graph check means that the static checks of the catalog read, the graph's structure, inputs and outputs,
values, model files and known families found no problem. It is not a run in ComfyUI and no promise of quality or of
enough graphics memory. An incomplete or outdated catalog, and metadata the app does not know, remain limits. A
passed lesson step means the canvas holds what the step asks for, not that the picture will be good.

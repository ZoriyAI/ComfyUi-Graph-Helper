# Versions 0.2.0 to 0.8.0

Versions 0.2.0 to 0.8.0 were private releases, made before the project was published. Their full notes are not
public. In short:

- **0.8.0**: five more lessons on WanVideoWrapper (UniAnimate, two voices with InfiniteTalk, FantasyTalking, Ovi,
  ReCamMaster); New project asks before it clears a graph that was never saved.
- **0.7.0**: example pictures from Hugging Face in model cards; lessons on VACE, animation by pose and a talking
  portrait.
- **0.6.0**: descriptions of node packs, descriptions of models looked up on the internet on request, the first
  lessons on WanVideoWrapper.
- **0.5.0**: model cards and node cards; advice on descriptions (prompts) in the check.
- **0.4.1**: lessons fit more graphs and say more precisely what a step lacks.
- **0.4.0**: Learn, the third way to work with the assistant: lessons you build by hand, checked step by step.
- **0.3.2**: every element keeps its size and place at any zoom, window size and screen scale.
- **0.3.1**: no service words or cut texts on any screen; every screen is checked automatically in both languages.
- **0.3.0**: node fields became real controls, the graph arranges itself, a build is told in one card, and the
  conversation with the model has a log you can save.
- **0.2.7**: the chat and the right panel speak plain words.
- **0.2.6**: assistant settings for people, not for programmers.
- **0.2.5**: an access token is applied as soon as it is pasted.
- **0.2.4**: settings offer what can be read from the system as lists.
- **0.2.3**: fixes after the first installation.
- **0.2.2**: no port is built in: every address is set whole, with its port.
- **0.2.1**: an MCP access token can be kept in the system password store.
- **0.2.0**: the first installable version: an assistant that explains and teaches ComfyUI graphs on a live canvas.

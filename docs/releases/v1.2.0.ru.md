# NodeWise Studio 1.2.0

Открывайте запущенное приложение с телефона или планшета через Wi-Fi. В браузере доступны общий с компьютером проект
и помощник, а раскладка подстраивается под телефон, планшет и большой экран. Также исправлены сохранение и импорт
уроков, учёт изменений пояснений в проекте и сообщения о неполном удалении секретов.

## Подключение телефона

1. Запустите NodeWise Studio на компьютере. Откройте **Настройки → Доступ по сети**.
2. Включите **Разрешить доступ из браузера**, выберите Wi-Fi или LAN адрес компьютера и порт, затем сохраните.
3. Снова откройте этот раздел и нажмите **Подключить устройство**. На телефоне откройте показанный адрес или
   отсканируйте QR-код, затем введите код подключения. Приложение на компьютере должно оставаться запущенным,
   а устройства — находиться в сети, где могут связаться друг с другом.

По умолчанию доступ выключен. Код действует пять минут и подходит для одного подключения. Устройство можно отключить
с компьютера. Выключение доступа или закрытие приложения завершает подключения. Выбирайте сетевой адрес компьютера:
`127.0.0.1` доступен только на самом устройстве, где открыт браузер. Соединение использует HTTP и предназначено
для доверенной локальной сети. Приложение не меняет настройки роутера и межсетевого экрана.

## Общий проект на двух экранах

- Изменения графа видны на компьютере и в браузере. Конфликтующие команды отклоняются, чтобы устаревшая команда
  браузера не затёрла более новые изменения.
- Помощник использует настройки компьютера. Ключи провайдеров остаются на компьютере.
- На небольшом экране холст, библиотека, помощник и свойства открываются отдельными панелями. Поддерживаются
  касания, портретная и альбомная ориентация.
- Проект или workflow можно загрузить из браузера, а текущий проект или workflow — скачать на телефон.
  Размер загрузки из браузера ограничен 11 МиБ.
- Сетевой доступ, папки компьютера и хранение ключей настраиваются на компьютере.

[Руководство по доступу из браузера](../wiki/start/Browser-Access.ru.md)

## Исправления после 1.1.0

- Редактирование урока сохраняет другой перевод. Позднее завершение сохранения не стирает новые правки;
  ошибки записи показываются пользователю.
- Импорт набора уроков выполняется целиком: при ошибке прежние файлы восстанавливаются, а черновик остаётся для повтора.
- Изменение пояснений отмечает проект как изменённый; совместимость с чистыми файлами версии 1.1.0 сохранена.
- Распаковка сжатых метаданных workflow в PNG ограничена; слишком большой объём вызывает понятное сообщение.
- Удаление сохранённых секретов сообщает о файлах, которые не удалось удалить или проверить.
- Фоновая синхронизация отбрасывает повторы от старого источника после смены подключения.

## Файлы выпуска

Для Linux x64 собраны `.deb`, переносной `.tar.gz` с `run.sh`, `install.sh` и `uninstall.sh`, а также AppImage.
К выпуску приложены `install-windows.ps1`, `install-macos.sh`, перечень компонентов и `SHA256SUMS`.
Скрипты собирают приложение из исходников этого тега на Windows или macOS; готовых приложений для этих систем нет.
RPM и сборок для ARM в этом выпуске нет. Пакеты собраны локально; аттестация происхождения сборки GitHub не заявляется.

Перед обновлением закройте прежнее приложение. Существующие проекты и настройки сохраняются.

## Границы проверки

Доступ по сети проверен на упакованном приложении Linux через Chromium с размером экрана телефона: подключение,
общие изменения графа и выключение доступа. Физический телефон в домашней Wi-Fi сети ещё не проверен.
Реальный ComfyUI и физические устройства с Windows/macOS в эту проверку не входили.

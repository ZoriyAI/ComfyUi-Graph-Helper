# ComfyUI Graph Helper v0.7.0

Картинки-примеры с Hugging Face и три новых урока на WanVideoWrapper: VACE, анимация по позе и говорящий портрет.

## Картинка-пример с Hugging Face

- Если модель нашлась на Hugging Face, карточка теперь показывает и её картинку или ролик-пример. Программа
  берёт первую картинку из описания модели, а если там нет, то пример из файлов репозитория.
- Значки, логотипы и крошечные иконки пропускаются. Файл больше 16 МБ или не картинка тоже пропускается, тогда
  берётся следующий, не больше трёх попыток.
- Репозиторий с пометкой «не для всех» (not-for-all-audiences) закрыт так же, как отмеченное взрослым на
  Civitai: картинка не скачивается, пока вы сами её не откроете.
- У результата с Hugging Face появилась кнопка «Искать снова».
- Картинки скачиваются только с huggingface.co и его файловых серверов.

## Новые уроки на WanVideoWrapper

- **«VACE: движение из другого видео».** Продолжает урок «Видео на WanVideoWrapper». Модуль VACE к обеим
  моделям, видео-подсказка, разобранная на кадры, карта глубины, поза или контуры из неё, картинка-образец и
  то, насколько сильно подсказка держит ролик.
- **«Анимация по позе: Wan Animate».** Герой с вашей картинки повторяет движения и мимику человека из видео.
  Поза и лицо вынимаются из видео нодами пака ComfyUI-WanAnimatePreprocess.
- **«Говорящее видео: InfiniteTalk».** Портрет произносит текст из звукового файла, губы в такт словам, звук
  идёт в ролик дорожкой.
- Последние два урока первым делом говорят: оживлять и озвучивать чужое лицо и голос можно только с согласия
  этого человека.
- Все ноды, входы и выходы в уроках взяты из исходников пака, установленного у вас.

## Мелочи

- На обзорном масштабе холста имя ноды занимает не больше трёх строк. Длинное имя раньше растягивало блок на
  соседний.

Границы прежние. В ComfyUI программа ничего не меняет и ничего не скачивает. В интернет она ходит только по
вашей кнопке или по настройке в «Приватности».

Установка: `sudo apt install ./comfyui-graph-builder_*.deb`. Настройки, ключи и проекты сохраняются.

# 1.3.1

Синхронизация моделей теперь читает большие заголовки safetensors небольшими порциями до обращения к старому инструменту метаданных. Исправлен воспроизводимый разрыв MCP на заголовке размером 14 МБ и отдельное ограничение ответа сервера, которое отклоняло слишком большие порции.

- Заголовки читаются порциями по 256 КиБ с проверкой границ и целостности. Веса моделей не передаются в NodeWise.
- Резервное чтение через ComfyUI остаётся доступным, даже если описания нод успешно получены через MCP.
- Оборванный ответ заголовка отмечается для конкретного файла без запроса всего большого заголовка; следующие файлы продолжают читаться.
- Авторские описания читаются независимо от заголовка. Отсутствие встроенного описания не мешает успешно прочитать файл.
- Выбранные исключения сохраняются. В **Синхронизация → Проблемы и исправление** выключите **Пропускать этот файл** для нужных файлов и нажмите **Повторить**.

Если старая версия уже оборвала внутреннее соединение сервера, один раз перезапустите настроенную службу MCP через **Настройки → Службы**, затем повторите синхронизацию. Исправление предотвращает запрос, вызывавший этот сбой; установленный сервер не изменяется, ComfyUI автоматически не перезапускается.

# 1.4.0

Редактируемые материалы к школьному занятию с помощником или вручную, проверка компьютера до установки ComfyUI и восстановление синхронизации моделей без повторных запросов слишком больших заголовков.

- **Материалы к уроку** открываются с первого экрана и из меню «Справка». Выберите карточки, рабочий лист, проверку понимания, объяснение, историю по кадрам или разные уровни поддержки. Укажите тему, возраст и цель; заполните заготовку вручную или попросите настроенного помощника подготовить черновик.
- Каждый блок можно изменить. Ответы и заметки учителя отделены от заданий; новый черновик помощника заменяет текущую копию только после принятия. Подготовка материала не меняет граф.
- Скачайте HTML ученика, HTML учителя или JSON для редактирования. Поля учителя не входят в ученический файл. HTML открывается в браузере для печати или сохранения PDF. Текущий черновик хранится на устройстве; JSON переносит редактируемую копию коллеге или на другое устройство.
- **Настройки → Компьютер** читают процессор, RAM, доступные данные видеокарт и место на диске без ComfyUI. На подключённом телефоне показан компьютер с NodeWise. Объяснённые советы и официальные инструкции ведут к подключению; отчёт не обещает запуск любой модели.
- Для подготовки материала через локальную Ollama мастер запрашивает короткий ответ без рассуждений, если модель поддерживает этот режим. Настройки остальных разговоров сохраняются.
- Заголовки safetensors читаются порциями до 256 КиБ, включая воспроизведённый 14-МБ заголовок, который обрывал старый MCP-reader. После успешного восстановления через native ComfyUI следующие файлы сначала используют рабочий путь чтения. Повторная синхронизация не перечитывает готовые заголовки без необходимости.

Исправления чтения моделей, подготовленные для 1.3.1, вошли сюда; отдельный выпуск 1.3.1 не публиковался. Выбранные исключения сохранены: чтобы прочитать файл снова, выключите **Пропускать этот файл** и нажмите **Повторить** в **Синхронизация → Проблемы и исправление**. Если старая программа уже оборвала внутренний reader сервера, один раз перезапустите настроенную службу MCP через **Настройки → Службы**.

Учительская основа — это текстовый редактор и подготовка черновиков. Генерация иллюстраций к занятиям, общая школьная библиотека и подтверждённое соответствие учебной программе пока не входят в неё. В [исследовании и поэтапном плане](../research/2026-11-17-teacher-direction.ru.md) сохранены 60 сценариев с критериями готовности. Перед занятием проверьте факты, ответы и пригодность материала для класса.

Полные шаги: [Материалы к уроку](../wiki/start/Classroom-Materials.ru.md) и [Что сможет мой компьютер?](../wiki/start/Computer.ru.md).

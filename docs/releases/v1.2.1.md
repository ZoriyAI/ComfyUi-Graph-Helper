# NodeWise Studio 1.2.1

Media loaders now let you choose a file from this device, including a phone browser. The node library has **Collapse
all** and **Expand all** controls. Input and output ports share the same rows, following ComfyUI's node layout.
Browser access over Wi-Fi from 1.2.0 is included.

- Imported ComfyUI settings stay visible and editable even before reading the catalog. Exact, reliable widget layouts use the original field names; unknown or changed layouts retain values by their saved position. Reading the catalog restores named controls without resetting values or links.
- **Choose file…** is available on media loader nodes and in Properties. The selected image, video or audio file is
  uploaded to the configured ComfyUI input folder, then the server's filename is selected in the node. Existing
  files are not overwritten. Cancelling, a failed upload, or changing project/connection keeps the previous value.
  Files are limited to 64 MiB, or the lower limit configured by ComfyUI. This is an explicit user action; the
  assistant cannot select files or upload them. Catalog reads remain read-only and workflows are never queued.
- The Nodes library can fold or unfold every category at once. Both actions work in search results too; searching
  keeps the folding choices of the unfiltered list.
- Node input ports are on the left and output ports on the right in shared rows, with widgets underneath.
  The catalog still supplies the node classes, port types, parameter names, ranges and choices.
- For a phone, open **Settings → Browser access**, enable access, choose a network interface and port, then pair
  the phone using the displayed address/QR code and one-time code. Keep the desktop app running.

Linux x64: `.deb`, AppImage and portable `.tar.gz`. The release also carries the Windows/macOS source-install scripts,
a component list and `SHA256SUMS`. Built locally; no RPM, ARM build or GitHub build provenance attestation.

Close the old app before installing and starting this update. Existing projects and settings are preserved.
The changed paths are checked with a loopback ComfyUI fixture and a mobile-sized Chromium browser; a physical phone
and a real ComfyUI installation remain unverified. Full visual parity with every custom ComfyUI widget is not claimed.

# 1.4.0

Prepare editable classroom materials with or without an assistant, check the computer before installing ComfyUI, and recover model synchronization without repeating oversized header requests.

- **Help → Explain a ComfyUI error → Check ComfyUI** now distinguishes native waiting, running and exact-prompt history. It shows Reference Studio guard reasons, measured memory and a copyable report without changing the job. Invalid Ollama residency responses no longer confirm a false empty state. Settings tabs stay readable with enlarged text.
- **Materials for a lesson** opens from the welcome screen and Help. Choose topic cards, a worksheet, a quick quiz, an explanation, a storyboard or support variants. Enter the topic, age and goal; use an empty scaffold or ask your configured assistant for a draft.
- Edit every block, keep teacher answers and notes separate, and review a new assistant draft before replacing the current copy. The assistant does not change your graph while preparing a classroom material.
- Download a pupil HTML sheet, a teacher HTML copy or editable JSON. Pupil files do not contain the teacher-only fields. Open the HTML in a browser to print or save a PDF. Current drafts are saved on the device; JSON transfers an editable copy to a colleague or another device.
- **Settings → Computer** reads processor, RAM, reported GPUs and data-drive space without ComfyUI. A paired phone sees the NodeWise host. Explained starting points and official installation guides lead to connection settings; a resource report is not a guarantee that every model fits.
- Local Ollama drafting from the classroom wizard requests a short non-thinking response where supported. Other conversations keep their existing settings.
- Safetensors headers are read in bounded 256 KiB portions, including the reproducible 14 MB header that broke the legacy MCP reader. After successful native recovery, later files use that working reader first. A repeated synchronization does not reread completed headers unnecessarily.

The model-reading fixes originally prepared for 1.3.1 are included here; 1.3.1 was not published as a separate release. Existing skip choices remain yours: uncheck **Skip this file** and choose **Retry** in **Sync → Problems and repair** when you want to read it again. If the old app already broke a server's internal reader, restart that configured MCP service once through **Settings → Services**.

The teacher foundation is a text editor and drafting flow. It does not yet generate classroom illustrations, maintain a shared school library or certify alignment to a curriculum. The bilingual [teacher research and staged plan](../research/2026-11-17-teacher-direction.md) records 60 scenarios with acceptance criteria. Review facts, answers and suitability before using a material with pupils.

Read [Materials for a lesson](../wiki/start/Classroom-Materials.md) and [What can my computer do?](../wiki/start/Computer.md) for the full steps.

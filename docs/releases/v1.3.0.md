# 1.3.0

This release completes the lesson upgrade, preserves work across assistant interruptions, improves current ComfyUI workflow compatibility and makes large graphs easier to edit. Synchronization can continue directly through ComfyUI when MCP is unavailable, with separate progress for model descriptions and translations.

- **Learn on the graph you are editing.** All 95 lessons now include a goal, preparation, specific mistakes, a quiz, independent practice and separate checks for construction, execution and result assessment. Nested subgraph copies keep their own lesson answers and exposed values.
- **Continue interrupted work.** Paused assistant tasks, pending lesson drafts and extension drafts survive restart when history is enabled. Continue first reads the current graph. Completed edits are retained across context compaction, avoiding repeated nodes. Clearing history removes its drafts too.
- **Keep native workflow settings.** Dynamic choices, growing inputs, dynamic groups, type matching, list marks, named values and modern subgraph controls are supported when declared by the node catalog. Routing points and group frames can be edited with undo, including inside subgraphs. Unknown custom widget data is preserved.
- **Read models reliably.** An unavailable MCP connection can fall back to the configured ComfyUI address without forwarding MCP credentials. Translation has a visible queue, pause, retry and cache; original descriptions and trigger words remain available.
- **Edit large graphs more comfortably.** Visible-card rendering, paged findings and fewer redundant refreshes reduce stalls. The measured 1000-node readiness time fell from 25.00 to 4.69 seconds; memory use remains substantial. Keyboard focus brings the selected node below the toolbar, and live announcements are coalesced.
- **Recover and maintain your work.** History shows measured stored data and offers reviewed cleanup while protecting current work and active tasks. Large MP4, MOV, MKV and WebM files can yield embedded workflows through bounded metadata reads, including in the paired browser.
- **Use concrete guidance.** All 50 guide screens were checked, including return to a selected inner node. Resource guidance shows recognized dimensions and a measured vision-to-image example. The About screen exports a versioned public catalog of lessons, guides and blueprints for portal integration, without user projects.
- **Correct platform explanations.** Linux keychain choices appear only on Linux. Windows and macOS explain their automatic system storage. Dependencies and current documentation were updated.

Actual local checks covered a ComfyUI catalog with 3375 node types and 797 model files, 678 official workflows, real assistant construction and restart, native Ollama memory release, vision and embedding nodes, and a combined vision → diffusion → image run. These are bounded results, described in the [qualification reports](https://github.com/ZoriyAI/nodewise-studio/blob/v1.3.0/docs/research/2026-11-17-native-compatibility.md), not a guarantee for every custom extension or model.

Linux x64 has `.deb`, `.rpm`, AppImage and portable archives. Windows/macOS use the source installation scripts. Physical Android/iOS, independent beginner testing, publisher signing and portal deployment remain separate acceptance; this release does not claim they were completed.

Install the new package over the old version; saved settings and projects remain in the data folder. Keep NodeWise running to use its paired phone browser. Export the workflow to run generation in ComfyUI; supported Ollama models used by NodeWise can be released when the desktop app exits.

# 1.2.5 — управление службами и понятная синхронизация

**Настройки → Службы** находят поддерживаемые службы Linux systemd на компьютере с NodeWise и позволяют запускать, останавливать, перезапускать их и наблюдать состояние. Те же действия доступны с подключённого телефона. В **Синхронизации** появились режимы «Бережно», «Сбалансированно» и «Быстрее» с объяснениями нагрузки.

- Видны точные имена служб, пользовательская/системная принадлежность, состояние и RAM по данным системы. Перед действием проверяется актуальность выбранной службы, после — фактическое состояние. Остановка/перезапуск объясняют влияние на другие приложения; системные службы запрашивают разрешение через окно ОС на компьютере. Произвольные команды и редактирование файлов служб не открываются.
- Из центра проблем синхронизации можно перейти к службам. Работающий процесс не выдаётся за готовое подключение ComfyUI/MCP.
- У частых интервалов синхронизации понятные названия. Прежние пользовательские значения сохраняются; размеры пакетов и паузы доступны в дополнительных настройках. Изменения применяет «Сохранить настройки».
- Справка объясняет поддерживаемые службы, работу с телефона, авторизацию и ограничения. Исправлено устаревшее описание запрета создания субграфа внутри другого; вложенные группы и распускание остаются отдельной доработкой.

Автопоиск проверен на Linux без изменения работающих служб. Действия, ошибки, авторизация и проверка состояния проверены изолированным транспортом и настоящим Electron IPC/интерфейсом при обычной ширине и 390px. Реальное окно привилегированной авторизации и физический телефон в эту проверку не входили. Настройка модели по-прежнему зависит от native API провайдера; релиз не устанавливает службы и не администрирует произвольные удалённые ОС.

Linux x64: `.deb`, AppImage, переносной `.tar.gz`, скрипты сборки Windows/macOS, состав компонентов и контрольные суммы. Закройте старое приложение перед обновлением.

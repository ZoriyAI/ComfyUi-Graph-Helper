# ComfyUI Graph Helper v0.2.3

Исправления по результатам первой установки на машине владельца.

- **Файлы моделей снова читаются.** Текущий MCP-сервер на запрос списка моделей без категории отвечает только
  перечнем категорий, а файлы отдаёт по каждой категории отдельно. Приложение теперь читает категории, затем все
  страницы каждой категории (скрытые папки вроде `.cache` пропускаются; одна нечитаемая папка не теряет остальные).
  Старые серверы, отдающие файлы сразу, читаются как раньше.
- **Сервер без авторизации.** Локальный MCP-сервер, который принимает подключение без токена, синхронизируется
  без входа и без токена: нужен ли вход — решает сервер, а не приложение. Подсказка «вход не выполнен, токена нет»
  показывается только после того, как сервер ответил 401. Ответ 401 без учётных данных называется «MCP-сервер
  требует входа», с неверным токеном — «MCP-сервер отклонил токен». Первая синхронизация после запуска идёт и без
  учётных данных, пока сервер не попросил вход.
- **«Войти через браузер»** на сервере без OAuth сообщает «сервер принимает подключение без входа» вместо
  «вход не завершён»; недоступный сервер называется по адресу. Причина неудавшегося входа пишется в лог
  (без секретов) для «Скопировать диагностику».

Установка: `sudo apt install ./comfyui-graph-builder_*.deb`.

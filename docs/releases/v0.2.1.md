# ComfyUI Graph Helper v0.2.1

- Ручной токен MCP можно сохранить в системном хранилище паролей (раздел «Модели и ключи»), и он
  используется после перезапуска; в памяти на один сеанс он тоже остаётся доступен.
- Локальная схема: MCP-сервер на этой же машине по `http://127.0.0.1:<порт>`, чтение `object_info`
  напрямую по «Адресу Comfy», локальная модель через Ollama без ключа.

Установка: `sudo apt install ./comfyui-graph-builder_*.deb`.

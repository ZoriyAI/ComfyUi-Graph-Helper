# ComfyUI Graph Helper v0.3.0

Большое обновление: поля нод стали настоящими элементами управления, граф раскладывается сам, сборка рассказана
одной карточкой, а у разговора с моделью появился журнал, который можно сохранить и отправить.

- **Журнал общения с моделью.** Каждый вопрос записывается: что ушло модели, что она ответила на каждом шаге,
  вызовы инструментов, ошибки со словами сервера, токены и время. Для облачных и локальных моделей одинаково.
  «Справка ▸ Журнал общения с помощником…»: отметьте вопрос, «Сохранить в файл…» и отправьте файл целиком.
  «Скопировать отчёт» даёт короткий текст для сообщения. У ответа в чате есть значок, который открывает его
  запись. Ключи и токены в журнал не попадают, журнал хранится только на этом компьютере, выключается в
  «Приватности».
- **Своя модель и окно контекста.** Сервер Ollama сам решает, сколько текста модель читает за раз (от 4 тысяч
  токенов, смотря по видеопамяти и настройке сервера), и молча отбрасывает то, что не поместилось. Приложение
  теперь читает это окно у сервера, показывает его в «Проверить связь», при маленьком окне предлагает модели
  меньше инструментов и говорит в чате, когда запрос не поместился и что изменить на сервере.
- **Поля нод.** seed, steps, sampler, файл модели меняются прямо на ноде и в «Свойствах»: списки из вашего
  ComfyUI, числа в своих границах, кнопка случайного seed. Поле с моделью показывает ваши файлы с семейством и
  отметкой, какие подходят к чекпойнту выше по графу.
- **Раскладка.** Новая нода не ложится на другую. «Граф ▸ Разложить граф» (`Ctrl+Shift+L`) наводит порядок одной
  командой. После сборки помощник раскладывает построенное сам. На мелком масштабе граф читается как карта
  подписанных блоков. «Следить за помощником» включено по умолчанию.
- **Сборка и чат.** Одна карточка «Сборка · 16 шагов» с шагами по-русски и «зачем» у каждого, в конце итог и
  «что дальше»: экскурсия, проверка, сохранение. Чтения и поиск свёрнуты в одну тихую строку.
- **Модели.** Щелчок по файлу открывает карточку: семейство и откуда оно известно, слова-триггеры, к чему
  подходит, «Добавить на холст». Совместимость LoRA проверяется и для загрузчиков сторонних паков.
- **Оболочка.** Один элемент «Помощник» в верхней панели, панели без повторов, иконки в контекстном меню,
  находки проверки называют ноды по именам, субграфы показаны по имени и размеру.
- **Ключи.** У каждого облачного провайдера свой ключ: ключ одного не показывается и не уходит другому. Ключ,
  который провайдер отверг, приложение не удерживает.
- **Движок.** Группу можно переименовать двойным щелчком. Правки внутри субграфа (перемещения, поля, связи)
  сохраняются.

После обновления запустите синхронизацию один раз («Синхронизация ▸ Синхронизировать сейчас»): приложение
перечитает ноды и запомнит границы, шаги и подсказки полей, которых в прежних версиях не хранило.

Установка: `sudo apt install ./comfyui-graph-builder_*.deb`.

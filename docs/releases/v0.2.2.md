# ComfyUI Graph Helper v0.2.2

- Порты нигде не зашиты. Приложение больше не держит встроенный номер порта ComfyUI: адрес ComfyUI с портом
  берётся из ответа MCP-сервера или из поля «Адрес Comfy», адрес MCP-сервера и локальной модели — целиком из
  настроек. Защита чтения страниц помощником теперь закрывает именно настроенные адреса (сохранённый адрес
  Comfy, адрес MCP-сервера и адрес ComfyUI, который назвал сервер), на любом порту, и обновляется после каждой
  синхронизации.
- Подсказки в настройках и README говорят, что порт — ваш: `http://127.0.0.1:<порт>` для ComfyUI, свой хост и
  порт для MCP и Ollama.

Установка: `sudo apt install ./comfyui-graph-builder_*.deb`.

# 1.2.2 — touch editing, task wizards and synchronization

Phone and tablet panels now close with a second tap or the back-to-canvas action, including their floating cards. Photo selection uses the current device's native picker. The **Image** button, paste and file drop add an ordinary ComfyUI `LoadImage` source with preview and an `IMAGE` output.

- Touch node menus, deletion, undo/redo, select-all and tap-based multiple selection; connect an output and an input with two taps. Zooming out retains node controls and ports. Manual collapse is separate.
- A mobile subgraph constructor with close, step navigation, scrollable content and accessible bottom actions.
- **Task wizards** bundle all 115 official native blueprints from Comfy-Org/workflow_templates at `ff15d86b5a14` (MIT), covering images, video, audio, 3D and text. Review typed I/O, dependencies and inner graphs, then create an independent editable copy. Native settings, links and promoted controls survive ComfyUI export; unknown positional values are never assigned invented names.
- The configured assistant can search and inspect blueprints, read inner graphs and build stepwise variations in its own new subgraphs. Teachers can request a lesson draft, review it, keep it in **My lessons** and export a lesson file to students.
- **Ollama and local AI** and **Custom extension** wizards support typed interface design and source-only extension drafts with source review and ZIP download. An optional starter package supplies Ollama image-to-prompt, chat, embeddings and cosine similarity nodes. Embedding vectors have a distinct type and cannot replace CLIP `CONDITIONING`. The person reviews and installs the package, chooses models, restarts ComfyUI and synchronizes; NodeWise never executes generated Python.
- The graph check includes resource planning: measured RAM/VRAM, unique model files, inner stages and missing dependencies. File sizes are a planning reference, not measured peak VRAM or a guarantee of execution. Ollama/API memory and model overlap remain explicit unknowns.
- With Russian UI, the configured assistant translates readable model descriptions, notes and metadata in the background across all model folders, including LoRAs. Translations are cached with an original-text toggle. Filenames, trigger words and technical parameters stay intact. An unconfigured assistant leaves the original visible; synchronization does not wait for translation.

Synchronization reuses full `/object_info` before paged discovery. For 3375 classes this removes 34 redundant requests that could each trigger a server filesystem scan. Paged discovery remains when full definitions are unavailable. After bounded MCP reconnection, unread model headers may continue through `/view_metadata` only at the ComfyUI origin whose catalog was successfully read. Failed or unsupported fallback requests never count as completed headers; origin-change and cancellation guards remain.

Linux x64: `.deb`, AppImage and portable `.tar.gz`, plus Windows/macOS source installers, component inventory and `SHA256SUMS`. Close the previous app before installing. Projects and settings are retained.

Targeted sync reproductions, all115 native blueprint roundtrips, paired Chromium390×844 touch authoring/picker/menu/ZIP/wizard operations, translated prose and resource display were checked. The owned starter Python compiles and its schemas/chat/embed/cosine contracts pass offline. Physical phones, Safari, actual LLM/Ollama inference and graph execution on the owner's server were not exercised.

See [Task wizards, agent and extensions](../wiki/graph/Task-Wizards.md).

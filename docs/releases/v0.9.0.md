# Graph Helper for ComfyUI v0.9.0

Редактор графов и субграфов, 45 уроков по темам и более точные подсказки: технический помощник сохраняет выбор темы за человеком, а отмена последовательных шагов помощника сохраняет ручные правки между ними.

## Редактор и обучение

- Редактирование нативных графов и субграфов, работа с выделением и буфером обмена, проверки связей и защита при замене несохранённого графа. Неизвестные нативные данные сохраняются средствами существующего кодека; совместимость с любым внешним workflow этим не доказана.
- 45 уроков собраны в шесть групп: первые картинки (3), видео (15), WanVideoWrapper (10), модели картинок (10), опорная картинка для видео (4), паки и инструменты (3). Видны все связанные уроки из метаданных пути и зависимостей графа; проходить линейный курс необязательно.
- Копирование, вырезание, вставка и дублирование выделения; удаление, сдвиг и перенос нескольких нод отменяются одним шагом. «Сохранить» пишет в выбранный файл, «Сохранить как» запрашивает новый; несохранённые изменения отмечаются, ручные правки во время повтора ограничены.
- Системный промпт помощника объясняет графы, субграфы, ноды, модели, LoRA, вспомогательные инструменты и промпты без запретов по теме от приложения. Выбранный провайдер или локальная модель отвечает по собственным правилам и возможностям.
- Взрослые материалы дают фактические технические пояснения для законного использования 18+ с согласием участников. Тему, показ превью и примеров выбирает пользователь.

## Исправления

- Каталог учитывает источник и изменения файлов моделей; отменённое или устаревшее чтение не подменяет актуальный снимок. Превью привязаны к принятому адресу и источнику каталога.

- Отключённая передача значений полей учитывается и в контексте недавних ручных действий; ответы инструментов на границе SDK проходят очистку секретов.
- «Отменить» объединяет только последовательные шаги одного запуска помощника. При чередовании AI → ручная правка → AI первая отмена возвращается к ручной правке, а не к началу всего запуска. Повтор возвращает отменённый интервал.
- Неожиданная ошибка ручного изменения показывается сообщением; отклонения и конфликты по-прежнему показывают причину и актуальную проекцию графа.
- README и руководства описывают прямое чтение ComfyUI по его адресу и необязательный MCP для дополнительных метаданных. Удалены мёртвые ссылки STATUS/decisions; заметка о картинках для взрослых больше не обещает несуществующий отдельный урок.

## Подключение и пакеты

Запущенного ComfyUI достаточно: в «Настройки ▸ Подключение» укажите адрес из браузера. MCP-сервер необязателен и может добавить sidecar-описания моделей, README паков и отпечатки файлов, если у него есть соответствующие инструменты чтения. Приложение не запускает генерации, не загружает файлы и ничего не устанавливает в ComfyUI.

В исходниках настроены Linux x64 `.deb`, `.rpm`, AppImage и переносимый `.tar.gz` с `run.sh`, `install.sh` и `uninstall.sh`. `.rpm` требует `rpmbuild`, AppImage — `mksquashfs` и runtime AppImage. Файлы выпуска приложены к странице релиза вместе с `SHA256SUMS`, SBOM и аттестацией происхождения сборки. ARM-сборок нет. Настройки и профиль `~/.config/comfyui-graph-builder` сохраняются между обновлениями.

Новая версия в main проходит полный release workflow: E2E, обход экранов, сборку и запуск пакетов, проверку обновления, контрольных сумм и происхождения сборки. Публикация использует точный проверенный коммит и сохраняет подтверждение окружения release. Уже опубликованная версия повторно не выпускается.

## Что проверка графа не доказывает

Успех означает, что статические проверки прочитанного каталога, структуры графа, портов, значений и известных семейств не нашли проблем. Это не запуск в ComfyUI, не гарантия качества или видеопамяти. Неизвестные метаданные и неполный или устаревший каталог остаются ограничениями.

Реальные import/export в официальном интерфейсе ComfyUI, внешний корпус workflow, графы на 100/500/1000 нод, большие каталоги и конкретные GPU/ОС/keyring/DPI требуют отдельных эмпирических проверок. Тесты собственных fixtures не заменяют их.

## English

This release groups 45 lessons by topic, keeps the assistant's technical teaching subject-neutral, preserves interleaved manual edits when undoing consecutive assistant steps, and displays unexpected manual commit errors. Direct ComfyUI access is the primary connection; MCP is optional for extra metadata. Adult education remains factual, non-graphic and about lawful consensual 18+ use, with preview choices controlled by the user. Linux x64 packages cover `.deb`, `.rpm`, AppImage and portable `.tar.gz`, with checksums, an SBOM and build provenance. New main versions publish only after the existing UI/package/upgrade gates and release environment approval, from the exact tested commit. Static graph checks do not prove execution, output quality, GPU capacity or compatibility with every external workflow.

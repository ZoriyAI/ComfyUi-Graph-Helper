# Graph Helper for ComfyUI 0.9.0

A graph and subgraph editor, 45 lessons grouped by topic and more precise help: the assistant leaves the choice of
subject to you, and undoing consecutive steps of the assistant keeps the manual edits made between them.

From 1.0 the product is named NodeWise Studio; how an update from 0.9 works is in
[Updating](../wiki/start/Updating.md#from-version-09-to-10).

## Editor and learning

- Editing of native graphs and subgraphs, work with the selection and the clipboard, link checks, and a question
  before a graph that is not saved is replaced. Unknown native data is kept by the existing codec; this does not
  prove compatibility with every outside workflow.
- 45 lessons in six groups: first pictures (3), video (15), WanVideoWrapper (10), picture models (10), an anchor
  picture for video (4), packs and tools (3). Every related lesson is shown from the path metadata and what the graph
  depends on; there is no fixed course to follow.
- Copy, cut, paste and duplicate of the selection; deleting, moving and nudging several nodes is undone in one step.
  Save writes to the chosen file, Save as asks for a new one; unsaved changes are marked, and manual edits during a
  replay are limited.
- The assistant's system prompt explains graphs, subgraphs, nodes, models, LoRAs, helper tools and prompts without
  subject bans of the app's own. The chosen provider or local model answers by its own rules and abilities.
- Adult material gives factual technical explanations for lawful consensual 18+ use. The subject, and whether
  previews and examples are shown, are your choice.

## Fixes

- The catalog takes its source and changes of model files into account; a cancelled or outdated read does not replace
  the current snapshot. Previews are bound to the accepted address and the source of the catalog.
- Switching off field values to the model is also respected in the context of recent manual actions; tool answers
  are cleaned of secrets at the SDK boundary.
- Undo joins only consecutive steps of one assistant run. With AI → manual edit → AI, the first undo goes back to the
  manual edit, not to the start of the whole run. Redo brings the undone stretch back.
- An unexpected error of a manual change is shown in a message; refusals and conflicts still show the reason and
  the current graph.
- The README and the guides describe reading ComfyUI directly at its address, with MCP optional for extra metadata.

## Connection and packages

A running ComfyUI is enough: in Settings ▸ Connection, enter the address you open it at in the browser. An MCP server
is optional and can add model descriptions kept next to the files, pack READMEs and file fingerprints, when it has
the read tools for them. The app runs no generations, downloads no files and installs nothing in ComfyUI.

Linux x64 packages: `.deb`, `.rpm`, AppImage and a portable `.tar.gz` with `run.sh`, `install.sh` and
`uninstall.sh`. The release files come with `SHA256SUMS`, an SBOM and a build provenance attestation. There are no ARM
builds. Settings and the profile in `~/.config/comfyui-graph-builder` are kept across updates.

## What the graph check does not prove

Success means that the static checks of the catalog read, the graph's structure, ports, values and known families
found no problem. It is not a run in ComfyUI and no promise of quality or enough graphics memory. Unknown metadata
and an incomplete or outdated catalog remain limits.

# ComfyUI Graph Helper v0.2.0

Первый устанавливаемый выпуск: помощник, который объясняет и учит строить графы ComfyUI на живом канвасе.

- Подключение к вашему ComfyUI через MCP: вход через браузер или токен, синхронизация нод, паков, моделей и метаданных LoRA; ComfyUI не изменяется.
- Канвас: ноды с типизированными портами, призрачные предложения, карточки-описания, импульсы по связям, экскурсия, пошаговая сборка с объяснением у каждой ноды, повтор истории, субграфы и группы, отмена и повтор.
- Помощник: Anthropic, Google, OpenAI или локальная модель; видит граф и ваши действия; предлагает из того, что у вас есть; строит только в режиме «Строить».
- Встроенные знания о базовых нодах, типах связей и семействах моделей на русском и английском.
- Экспорт чистого workflow JSON с проверкой перед экспортом.
- Окно настроек: помощник, модели и ключи, подключение, синхронизация, холст, оформление, горячие клавиши, приватность.

Установка: `sudo apt install ./comfyui-graph-builder_*.deb`. Первый запуск описан в README.

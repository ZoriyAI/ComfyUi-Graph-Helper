# NodeWise Studio 1.2.4 — исправление синхронизации и управление моделями

У проблем синхронизации теперь отдельное окно **Синхронизация → Проблемы и исправление**. В нём собраны предупреждения подключения, непрочитанные и исключённые файлы, повтор и прямое чтение. Исключённый файл можно проверить сразу; успешное чтение снимает исключение.

Если сервер не читает метаданные, выберите тот же safetensors-файл на устройстве. Приложение читает только префикс и ограниченный заголовок, без загрузки и передачи весов. Проверяются имя, размер и ревизия каталога. Читаемый файл без встроенных метаданных учитывается честно; существующие описания из соседних файлов сохраняются. История объясняет большой или пустой заголовок.

В **Настройки → Помощник** вместо числового поля контекста появились автоматический и понятные режимы диалога, а также стили ответа с объяснениями. Конфигурация Ollama применяется через API, затем приложение загружает модель и проверяет реальный контекст и выбранные параметры генерации. В предупреждении чата кнопка **Настроить автоматически** также сохраняет проверенный результат. Параметры модели, шаблон и стоп-слова сохраняются, кроме явно выбранного изменения стиля.

Монитор показывает загруженные модели, выделенную память/VRAM и реальный контекст. Можно обновить статус, загрузить выбранную модель, остановить ответ помощника или выгрузить модель без удаления файла. Результат загрузки/выгрузки проверяется по состоянию сервера. На узком экране увеличены кнопки и предусмотрена прокрутка окна исправлений.

Экономный набор инструментов сохраняет оценку ресурсов и инструменты запрошенных шаблонов/субграфов. Границы режимов «Спросить» и «Строить» сохранены.

Настройка и управление загрузкой требуют native API Ollama. Обычные OpenAI-совместимые адреса и запуск/остановка служб ОС этими кнопками не управляются. Автоподбор учитывает запрос и предел модели, но возможность загрузки зависит от доступной RAM/VRAM. Неподтверждённое действие показывается как ошибка и не переключает конфигурацию помощника.

Проверено целевыми тестами, изолированными сценариями Electron для чтения файла и автоматической настройки, снимками desktop/phone, проверкой типов и Linux-сборкой. Linux x64: deb, AppImage и переносимый архив. Проверки не изменяют пользовательские модели и службы.

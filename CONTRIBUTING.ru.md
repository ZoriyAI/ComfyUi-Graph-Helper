# Как участвовать

CozyGraph это экспериментальное приложение, которое помогает учиться работать с ComfyUI и разбираться в
графах. Идеи, пожелания и вопросы ждём в [обсуждениях](../../discussions), о проблемах пишите в
[обращениях](../../issues). Pull request тоже рады. Здесь сказано, что сделать перед тем, как его отправить.

## Условия

Отправляя изменение, вы соглашаетесь, что оно публикуется на тех же условиях, что и весь проект: по
[LICENSE](LICENSE) (MIT с условием Commons Clause). Исходный код открыт, но продавать приложение нельзя; для
коммерческого использования нужно письменное разрешение правообладателя ([COMMERCIAL.ru.md](COMMERCIAL.ru.md)). Все
участники следуют [Кодексу поведения](CODE_OF_CONDUCT.ru.md).

## Прежде чем начать

- Для большого изменения сначала откройте обсуждение или обращение, чтобы договориться об идее до работы.
- Прочитайте [Архитектуру](docs/wiki/dev/Architecture.ru.md) и страницу той части, которую меняете (их перечисляет
  [документация для разработчиков](docs/wiki/dev/README.ru.md)).
- Приложение разрабатывается и проверяется на Linux. Windows и macOS не поддерживаются; можно попробовать запустить
  приложение из исходников (не проверено): [Windows](docs/wiki/dev/Building-On-Windows.ru.md), [macOS](docs/wiki/dev/Building-On-macOS.ru.md).

## Подготовка

```bash
git clone <адрес проекта> cozygraph && cd cozygraph
npm ci
npm run build
npm start
```

Нужен Node.js 22 (версия из `.nvmrc`), а для сквозных тестов ещё Xvfb. Полный список на странице
[Сборка из исходников](docs/wiki/dev/Building-From-Source.ru.md).

`npm run dev` открывает окно с сервера разработки Vite и с DevTools. Учтите: запуск для разработки берёт ту же папку
профиля, что и установленное приложение (`~/.config/cozygraph`) <!-- verify: technical rename -->. Чтобы новая версия базы не попала в ваш
настоящий профиль, запускайте с `--user-data-dir=<своя папка>` (`npx electron . --user-data-dir=/tmp/gh-dev` после
`npm run build`).

## Проверки перед pull request

```bash
npm run type-check            # main, preload, shared и окно
npx vitest run                # модульные и интеграционные тесты (около двух минут)
npm run build                 # сквозные тесты запускают собранные файлы
xvfb-run -a npx playwright test tests/e2e/<файл>.test.ts --trace off   # сквозные тесты, которых касается изменение
node scripts/changelog.js --check
node scripts/public-tree-check.js
```

Сквозные тесты запускайте по одному файлу: каждый открывает Electron, и второе окно забирает фокус у первого. Обход
экранов (`tests/e2e/layout-walk.test.ts`) проходит все экраны при нескольких размерах окна, около двадцати минут на
размер; запускайте его, когда меняете вёрстку (см. [Тесты](docs/wiki/dev/Testing.ru.md)). Каждый запрос на слияние проходит быстрые
проверки (`.github/workflows/ci.yml`); сценарий выпуска запускает всё, включая обходы экранов и пакеты.

## Тексты и языки

- Каждый текст на экране лежит в `src/shared/i18n/catalog.ts` на русском и английском с одинаковыми ключами. Тест
  падает, если ключа нет в одном из языков или шаблон не заполнен.
- Русский текст главный: простые короткие предложения, слова из словаря приложения («помощник», «приложение»,
  «версия графа»…), никаких служебных слов на экране. См. [Тексты и языки](docs/wiki/dev/Texts-And-Languages.ru.md)
  и [Слова кода и слова на экране](docs/wiki/dev/Code-Words.ru.md).
- Документация лежит в `docs/wiki`, каждая страница на английском (`Page.md`) и русском (`Page.ru.md`). См.
  [Как писать страницы справки](docs/wiki/dev/Wiki-Style.ru.md).

## Коммиты и pull request

- Одна тема на коммит, чтобы коммит можно было отменить отдельно. Первая строка: область, двоеточие и что
  изменилось простыми словами (`lessons: the LoRA lesson names the folder of the file`). В теле сказано зачем.
- Pull request описывает, что меняется для человека, который пользуется приложением, и как вы это проверили.
  Заполните шаблон.
- Ничего личного: никаких личных адресов, почты, домашних папок и ключей. Их ищет
  `node scripts/public-tree-check.js`.

## Что полезно знать

- Имя пакета `cozygraph` называет папку профиля и запись в хранилище паролей у каждой установленной копии, поэтому
  после выпуска не меняется никогда ([Слова кода и слова на экране](docs/wiki/dev/Code-Words.ru.md)). <!-- verify: technical rename -->
- Приложение только читает ComfyUI. Изменение, которое что-то записывает, устанавливает, скачивает или ставит в
  очередь в ComfyUI, принято не будет ([ComfyUI только читается](docs/wiki/trust/Read-Only.ru.md)).
- Как сделан проект: большую часть кода и текстов написали ИИ-агенты для программирования под руководством и
  проверкой сопровождающего. Изменения от людей проверяются так же.

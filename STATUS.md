# Состояние проекта

**Дата:** 2026-11-10
**Ветка:** `claude/vibrant-carson-xyza0w`; `main` содержит исходную историю Cursor.
**Проверки на этой ветке:** `npm run type-check`, vitest (unit + integration), Playwright e2e на Electron под Xvfb, сборка `.deb` со smoke-тестом в GitHub Actions на каждый пуш.

## Что ограничено

- Вход по OAuth и чтение реального каталога проверены на поддельных серверах с теми же контрактами; живой сервер владельца в этой среде недоступен.
- Ответы живых локальных моделей владельца в этой среде не проверялись: сервер Ollama отсюда недоступен. Для этого и сделан журнал общения с моделью.
- Окно контекста читается только у Ollama; другой локальный сервер его не сообщает, и приложение узнаёт о нехватке только по счёту токенов в ответе.
- Внутри определения субграфа сохраняются перемещения, значения полей, связи и слоты внутренних нод; удалять и добавлять ноды внутри пока нельзя (холст об этом говорит).
- Карточка паузы на контрольной точке не переживает перезапуск приложения.
- Описания нод и связей хранятся в базе приложения по номеру объекта, а не в файле проекта. При открытии другого графа остаются только описания объектов, которые остались теми же (тот же номер и класс); отмена открытия возвращает граф, но не стёртые описания. Внутри определения субграфа описания отдельных нод не показываются: номера там повторяют номера основного графа.
- В интернет программа ходит только по выбору человека: кнопкой в карточке модели или настройкой в «Приватности». Civitai находит файл по отпечатку точно; Hugging Face ищется по имени файла, и карточка прямо говорит, что это догадка. Картинку-пример с Hugging Face программа берёт из README модели или из её файлов; репозиторий с пометкой not-for-all-audiences закрыт, как отмеченное взрослым на Civitai. Отпечаток большого файла сервер считает минутами, при синхронизации он не считается.
- Описание пака берётся из его `pyproject.toml` и начала README; пак без этих файлов показывается только с именем и версией.
- Уроки на WanVideoWrapper ведут по графу Wan 2.2 из текста и из картинки, по VACE, Wan Animate и InfiniteTalk. Другие его возможности (MultiTalk на двух говорящих, FantasyTalking, UniAnimate, ReCamMaster, Ovi со звуком) уроками не покрыты. Модели, которые загружаются тремя отдельными нодами, в уроке о двух моделях упомянуты словами.
- Поиск без нативного инструмента провайдера идёт через HTML DuckDuckGo и может ломаться при смене вёрстки.
- Пакет только `.deb` (x64); AppImage и другие дистрибутивы не собираются.

## Как проверить

```bash
npm ci && npm test && npm run type-check && npm run build
xvfb-run -a npx playwright test --trace off --grep-invert "live-local|layout-walk"
xvfb-run -a npx playwright test tests/e2e/layout-walk.test.ts --trace off   # обход всех экранов, отдельно
npm run shots -- /tmp/shots   # скриншоты для просмотра
```

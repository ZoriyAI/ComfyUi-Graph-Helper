## 0.2.2

- Порты нигде не зашиты. Приложение больше не держит встроенный номер порта ComfyUI: адрес ComfyUI с портом берётся из ответа MCP-сервера или из поля «Адрес Comfy», адрес MCP-сервера и локальной модели — целиком из настроек. Защита чтения страниц помощником теперь закрывает именно настроенные адреса (сохранённый адрес Comfy, адрес MCP-сервера и адрес ComfyUI, который назвал сервер), на любом порту, и обновляется после каждой синхронизации. - Подсказки в настройках и README говорят, что порт — ваш: `http://127.0.0.1:<порт>` для ComfyUI, свой хост и порт для MCP и Ollama.

Заметки: [docs/releases/v0.2.2.md](docs/releases/v0.2.2.md)

## 0.2.1

- Ручной токен MCP можно сохранить в системном хранилище паролей (раздел «Модели и ключи»), и он используется после перезапуска; в памяти на один сеанс он тоже остаётся доступен. - Локальная схема: MCP-сервер на этой же машине по `http://127.0.0.1:<порт>`, чтение `object_info` напрямую по «Адресу Comfy», локальная модель через Ollama без ключа.
